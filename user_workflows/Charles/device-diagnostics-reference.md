# Device Diagnostics — Branch Reference

本檔只在 `device-diagnostics` 已建立症狀契約、診斷迴圈與活躍假設後使用。以下項目是依故障層選擇的測試候選，不是固定順序，也不是全部執行的清單。

## 網路與 Wi‑Fi

依序確認實際故障落在哪一層：

1. **Radio / discovery** — SSID 是否可見；2.4／5／6 GHz、DFS、頻道寬度、區域法規與裝置能力是否相符。
2. **Association / authentication** — 是否成功關聯；WPA2／WPA3、PMF、企業驗證、MAC 隨機化、存取控制與密碼是否吻合。
3. **Addressing** — 是否取得正確 IP、子網、閘道與 DNS；是否出現 169.254.x.x、自訂 VLAN、DHCP exhaustion 或衝突。
4. **Local path** — 能否到達閘道、同網段主機與路由器管理頁。
5. **Name resolution** — IP 可達但網域失敗時，比較 DNS 查詢與不同 resolver。
6. **Internet path** — DNS 正常後再檢查 WAN、NAT、IPv4／IPv6、MTU、ISP 與上游路由。
7. **Application** — 只有單一 App、網站、VPN、遊戲或串流失敗時，保留底層網路為 pass 對照。
8. **Performance / roaming** — 固定伺服器、位置、頻段、裝置方向與時間後量測 RSSI、PHY rate、吞吐、延遲、jitter、loss 與切換事件。

高資訊量對照：

- 問題裝置連同一 AP 的另一頻段。
- 問題裝置連另一個 AP／手機熱點。
- 已知正常裝置在同位置連同一 SSID。
- 同裝置以 IP 與網域分別測試。
- Mesh／MLO／智慧連線問題先建立單節點、單頻段、單 SSID 基線，再逐項加回功能。

## 藍牙、USB、顯示與周邊

先分辨：偵測、配對、驅動、權限、資料路徑、供電或效能。

- 交換 Port、線材、轉接器、Hub 與主機，但一次只交換一項。
- 確認線材是否只供電、支援所需 USB 速率、影像 alt mode、PD 或 Thunderbolt 能力。
- 比較直連與經 Hub／Dock；比較冷開機、喚醒後與熱插拔。
- 檢查 Device Manager／System Information／系統日誌中的裝置 ID、錯誤碼與重新枚舉事件。
- 藍牙問題分開測試 discovery、pairing、profile、codec、multipoint 與應用權限。
- 顯示問題固定解析度、更新率、色深、HDR、VRR 與線材路徑；逐項加回高頻寬功能。
- 間歇斷線記錄是否與睡眠、電源管理、Hub 負載、線材彎折或溫度相關。

## Windows、驅動與應用

優先取得：完整錯誤訊息、事件時間、版本、裝置 ID、可靠性監視器與相關日誌。

- 比較新使用者、乾淨開機、安全模式或停用非必要背景程式，以區分系統層與第三方衝突。
- 驅動測試先確認硬體 ID 與目前版本；更新、回復與乾淨重裝都要記錄前後版本。
- 只在更新時間與症狀時間吻合、且有對照證據時，把更新列為根因。
- 電源管理問題比較 AC／電池、睡眠前後、快速啟動、USB selective suspend、PCIe link state 與裝置喚醒權限。
- 效能問題記錄 CPU／GPU／RAM／VRAM／儲存／網路／溫度／時脈／功耗，找出第一個到達限制的資源。
- 系統還原、OS 重裝與 BIOS 更新屬高成本測試；先完成可逆隔離與備份。

## 音訊鏈

畫出完整路徑：來源／App → OS mixer → transport → DAC → preamp／amp → 線材／轉接 → 耳機／喇叭。

- **無聲**：逐段確認輸出裝置、取樣格式、mute、音量、輸入選擇、增益、平衡／單端路徑與保護狀態。
- **單邊異常**：交換左右通道、線材端、輸入與輸出；症狀跟著哪一段移動，就定位到哪一段。
- **雜音／底噪／嗡聲**：比較不同輸入、USB／光纖、同一電源排插、筆電電池供電、訊號線拔除與接地狀態。
- **爆音／斷續**：固定 buffer、取樣率、exclusive mode、USB Port、CPU 負載與 DPC latency；記錄是否與切換格式或睡眠喚醒相關。
- **音量或聲音改變**：先排除 DSP、EQ、loudness、crossfeed、音量正規化、增益與輸出阻抗，再做主觀比較。
- **Trigger／待機**：分開測試訊號感測、12 V trigger、auto-standby、開機順序與待機功耗；避免把「能連動開機」與「能依訊號自動喚醒」混為同一功能。

所有換線與通道交換前先降低音量；功放、耳擴與主動喇叭測試避免帶電插拔不安全的端子。

## 充電、供電、電池與待機

畫出功率路徑：插座／電源 → 充電器 → 線材 → 中介裝置 → Port → 電源管理 → 電池／負載。

- 記錄充電器額定協定、Port 能力、線材電流／e-marker、裝置協商結果與實際功率。
- 比較開機、關機、待機、不同電量、溫度與負載；充電速度必須在相近條件下比較。
- 「顯示充電」不等於淨充入；高負載時需比較輸入功率與系統消耗。
- USB-PD 問題用已知正常的充電器與線分別交叉測試，避免一次整套替換而無法定位。
- 無法開機先確認電源輸入、電池保護、長按重置與指示燈行為；反覆強制開機可能加重儲存或電池問題。
- 電池膨脹、異味、局部異常高溫、漏液或充電器火花立即停止。

## 手機、平板與行動裝置

- 記錄完整型號、區域版本、OS build、電信商設定與電池狀態。
- 區分系統層、單一 App、帳號、權限、網路、配件與硬體感測器。
- 比較另一帳號／App、另一網路、移除保護殼／磁吸配件、停用 VPN／Private Relay／省電模式等，但一次只改一項。
- 相機、麥克風、定位、通知與背景活動先檢查權限與系統狀態，再重裝 App。
- 無線問題保留「同裝置連另一 AP」與「另一裝置連同一 AP」兩個核心對照。
- 重設網路設定與整機重置會刪除狀態證據；完成基線與備份後才使用。

## 效能、熱與間歇故障

建立時間序列，而不是只記一次數值：

- 觸發到故障的時間。
- 負載、功耗、時脈、溫度、風扇、記憶體、儲存、訊號與電量。
- 故障前後的事件紀錄。
- 冷機／熱機、插電／電池、前景／背景、固定／移動位置的差異。

用固定工作負載與可重複量測比較。若問題只有長時間才出現，縮短迴圈的方法包括提高可控負載、固定溫度條件、重播相同媒體／網路流量或循環睡眠喚醒；不得超出裝置安全範圍。
