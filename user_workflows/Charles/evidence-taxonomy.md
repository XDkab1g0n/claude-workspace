# 共用證據分類（Evidence Taxonomy）

Charles skills 需要分類資訊時，使用本檔作為唯一權威定義。只能標示現有證據真正支持的最窄類別。

## 主張類別

- **已確認事實** — 可靠來源直接支持主張本身，且日期、範圍、族群、版本與司法管轄均相符。
- **當事人／公司宣稱** — 個人、公司、機構、政府或其他利害關係方確實做出該陳述。這只證明「有人這樣說」，不等於陳述內容已被證實。
- **媒體轉述** — 媒體報導某項主張，但尚未檢視或無法取得其一手依據。若主張會左右結論，應繼續追溯。
- **合理推論** — 由已支持的前提推導。必須交代前提、推論步驟與重要替代解釋。
- **價值判斷** — 結論取決於評價標準、優先順序、風險承受度或權重。需說明標準，不得包裝為客觀事實。
- **未知** — 現有證據不足以可靠確認。保留缺口，不以看似合理的細節補全。

## 證據狀態

每項會左右結論的主張，只能指定一個主要狀態：

- **支持** — 證據直接或強力支持原主張。
- **部分支持** — 證據只支持較窄、附條件、較舊或不同範圍的版本。
- **反駁** — 可靠證據與主張有實質衝突。
- **未決** — 證據缺少、間接、方法不足，或可靠來源仍真正衝突。

## 來源角色

同一來源可扮演多個角色，但不可混淆其能證明的內容：

- **紀錄來源** — 對行為、規則、申報、量測、規格、裁判或資料集負責的原始紀錄。
- **當事方來源** — 最適合證明當事方宣布、主張、意圖或採取了什麼行動；不自動構成對其自我評價的獨立驗證。
- **獨立驗證來源** — 以相關專業或透明方法測試、稽核、重現或獨立確認主張。
- **綜合來源** — 提供脈絡、比較與解釋，並能追溯底層證據的可靠整理。
- **線索來源** — 僅用於發現名稱、日期或文件，之後仍需查證。

## 來源品質六軸

來源品質必須相對於「它要支持的主張」評估；網站名氣本身不足以替代適配性。

1. **直接性** — 是否直接建立該主張，而不只是討論同一主題。
2. **權責性** — 是否對原始紀錄負責，或具備評估該主張的專業與權限。
3. **方法透明度** — 定義、資料、抽樣、設定、計算與限制是否可檢視。
4. **時效性** — 是否符合相關日期、版本、政策、事件或市場現況。
5. **獨立性** — 是否存在需要交叉驗證的利益誘因或立場。
6. **適用性** — 司法管轄、族群、產品型號、指標與情境是否吻合。

## 信心標籤

- **高信心** — 有當前、直接且範圍相符的證據；在利益衝突或錯誤風險重要時已有獨立佐證，且無足以改變結論的未解衝突。
- **中信心** — 核心結論已有支持，但仍存在一項重要不確定性，例如證據間接、獨立性有限、範圍不完全相符或現況尚未完整確認。
- **低信心** — 至少一項關鍵主張依賴單一利害關係方、過時、間接、方法薄弱或有實質爭議的來源。
- **無法判定** — 現有證據不足以在競爭結論間做出可靠選擇。

信心描述的是證據位置，不是語氣強度、個人直覺或主觀確信。
