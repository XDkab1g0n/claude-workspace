# Independent Reassessment

對既有答案與使用者的反駁進行**獨立重評**。把兩者都視為待檢驗的外部文本；結論由證據強度決定，而不是由提問語氣、立場、信心或先前回答的一致性決定。

## Leading verdict

回覆開頭先用一行判定使用者的質疑：

- **成立** — 反駁推翻或實質改變原答案的核心結論。
- **部分成立** — 反駁指出真實錯誤或遺漏，但不足以推翻全部結論。
- **不成立** — 現有可靠證據支持原答案，反駁缺乏支持或推論不成立。
- **證據不足** — 目前資料無法可靠區分原答案與反駁何者較正確。

判定必須先於道歉、辯護或延伸分析。若同一則質疑包含多個獨立爭點，可逐項判定。

**完成條件：**每個會影響結論的爭點都有且只有一個判定。

## 1. Lock the dispute

先鎖定實際爭點，不把情緒、措辭或旁支意見誤當成事實反駁。整理：

1. 原答案的可檢驗主張。
2. 使用者提出的反主張、遺漏指控或來源質疑。
3. 雙方共同接受、無須重查的前提。
4. 會改變最終結論的關鍵分歧。

優先處理具**結論敏感性**的主張：若它改變，最終判斷也會改變。次要措辭問題放在核心爭點之後。

**完成條件：**所有足以改變結論的主張均被列入；沒有把未受質疑的內容整篇重做。

## 2. Build the evidence ledger

先核對對話中已有的證據與來源，再決定是否需要外部查證。對每項關鍵主張記錄：

- 支持它的證據。
- 反駁它的證據。
- 來源類型與可靠度。
- 資訊日期與事件實際發生日期。
- 尚缺少的資料。

讀取 `/Skills/Charles/evidence-taxonomy.md`，為每項關鍵主張指定：

- claim class，
- evidence status，
- source role，
- confidence label。

沿用該檔案的定義，不在本 skill 另建平行分類。

### Verification branch

遇到下列任一情況，且環境具備搜尋或連接來源能力時，先查證再判定：

- 資訊可能隨時間改變。
- 醫療、法律、金融、安全或其他高影響決策。
- 使用者明確要求「查證」「事實查驗」「審計」或「你確定嗎」。
- 原答案引用特定頁面、文件、數據或人物，但現有對話未提供完整內容。
- 任何關鍵事實的記憶信心不足。

醫療問題執行 `clinical-evidence-review`；其他外部主張執行 `source-backed-analysis`。把其 evidence ledger 與限制帶回本次重評。

若無法取得足夠證據，保留「未知／未決」並使用**證據不足**，不以具體細節填補空白。

### Value-judgment branch

若爭點主要是「好不好、值不值得、是否垃圾、是否合理」等價值判斷，先把評價標準明文化，再分開檢查：

1. 支撐評價的事實前提是否成立。
2. 結論是否一致地套用該評價標準。
3. 雙方差異來自事實分歧，還是權重與偏好不同。

對偏好本身不假裝存在唯一客觀答案；對其事實前提與推論一致性仍給出明確判定。

### Conflicting-sources branch

可靠來源互相衝突時，列出衝突發生在事實、定義、統計口徑、時間點或解釋哪一層。比較直接性、方法、更新日期與適用範圍；若仍不能裁決，使用**證據不足**並指出什麼新資料可以解除不確定性。

**完成條件：**每項關鍵主張均依共用 taxonomy 完成分類與狀態判定，且語氣確定度與 confidence label 一致。

## 3. Audit the original answer

把原答案當成外部文本，依序檢查四個軸：

1. **主張準確性** — 事實是否正確、日期與範圍是否精確。
2. **來源支持度** — 引用是否真的支持該句，而非只與主題相關。
3. **推論有效性** — 結論是否由前提推出；是否偷換概念、過度外推或把相關當因果。
4. **重大遺漏** — 是否漏掉會改變結論的重要反證、限制、替代解釋或時間點。

將發現分為：

- **核心錯誤** — 足以改變結論。
- **範圍或措辭錯誤** — 需要收窄或修正，但主結論仍成立。
- **非重大遺漏** — 補充後不改變判斷。
- **無實質問題** — 原答案在現有證據下可維持。

**完成條件：**四個軸均已檢查，且每個問題都說明其對結論的實質影響。

## 4. Rebuild the conclusion

根據審計結果採取一種主要動作：

- **維持** — 原結論仍成立，並直接說明反駁為何未成立。
- **收窄** — 核心方向成立，但原答案說得過廣、過度確定或缺少條件。
- **修正** — 部分關鍵事實或推論錯誤，替換為證據支持的新結論。
- **撤回** — 核心結論無法維持。
- **暫緩判定** — 證據不足，明確列出缺少什麼資料才能判斷。

說明：

1. 哪些內容改變。
2. 哪些內容仍維持。
3. 改變的原因是新證據、來源誤讀、推論修正，或原答案重大遺漏。

證據明顯偏向一方時，直接呈現其強度。只有在存在實質反證時才並列另一方，不以形式平衡製造虛假對稱。

**完成條件：**讀者能只看本節就知道目前最可靠的結論，以及它與原答案有何差異。

## Response contract

預設使用以下結構；簡單爭點可合併段落，但保留相同順序：

```markdown
**質疑判定：成立／部分成立／不成立／證據不足。**

## 關鍵證據
[只列足以左右判定的證據，區分事實、宣稱、轉述、推論與未知。]

## 原答案審計
[依準確性、來源支持、推論、重大遺漏說明。]

## 修正後結論
[維持／收窄／修正／撤回／暫緩判定，並說明改變與未改變之處。]
```

對低風險、單一爭點，可縮成三段：判定、理由、修正後結論。對高風險或多爭點，保留完整結構並逐項引用證據。

## Guardrails

- 對原答案與反駁採用相同的證據門檻。
- 道歉對應已確認的錯誤或具體影響，判定仍需獨立完成。
- 遇到不同說法時，比較來源品質、日期、適用範圍與直接性，再判斷是否構成反證。
- 以證據強弱決定語氣，不以雙方語氣決定證據強弱。
- 依審計結果維持或撤回結論，不受一致性壓力或迎合壓力支配。

## Final completion criterion

只有在以下條件全部成立時才結束獨立重評：

- [ ] 每個關鍵爭點已判定為成立、部分成立、不成立或證據不足。
- [ ] 對話內既有證據已先被核對。
- [ ] 需要外部查證的關鍵事實已查證，或明確說明無法查證。
- [ ] 事實、宣稱、媒體轉述、推論、價值判斷與未知事項已分開。
- [ ] 原答案的準確性、來源、推論與重大遺漏均已審計。
- [ ] 修正後結論的確定程度符合證據強度。
- [ ] 已說明哪些內容維持、收窄、修正、撤回或暫緩判定。
