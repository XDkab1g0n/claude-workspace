# AI小說創作｜取用索引

> 最後整理：2026-10-19  
> 適用範圍：`/AI小說創作` 及其子資料夾；`/AI小說創作_封存` 不屬於現行設定範圍  
> 用途：供 AI 寫作、續寫、角色扮演、設定查核與場景設計時選擇最小且正確的文件集合。

---

## 1. 核心原則

本資料夾不是單純依版本號由新到舊覆蓋，而是依下列三個維度分工：

1. **時間軸**：十五歲第一次黃金期、十七歲喪鐘時期、十八歲現在正篇必須分開。
2. **資訊領域**：角色、組織、地點、道具各有專責文件。
3. **詳細度**：完整角色檔負責深度；蒸餾卡負責快速掛載。

每次取用前，依序確認：

1. 場景發生在哪個時期？
2. 誰是主視角或主要角色？
3. 是否涉及組織制度、正式權限或任務流程？
4. 是否需要特定地點或道具的具體描寫？
5. 需要完整角色深度，還是只需群像一致性？

### 最短版規則

> **先選時期，再選主角。完整角色檔管人，組織檔管制度，地點檔管空間，道具檔管物件，蒸餾卡只管快速一致性。**

### 封存隔離

除非使用者明確要求版本比較、設定考古或恢復舊內容，不得搜尋、讀取或引用 `/AI小說創作_封存`。封存文件不參與權威裁決。

## 2. 權威層級與衝突處理

### 2.1 依資訊領域裁決

| 問題類型 | 優先來源 |
|---|---|
| 角色人格、心理、能力、身體、語氣、關係、身份專屬穿著裝備與覆蓋範圍 | 對應時期的完整角色檔 |
| 雪奈小說的場景節奏、戰鬥呈現、人物質感與視覺描寫 | `雪奈/雪奈_新版寫作方法學.md`；只裁決寫法，不裁決角色 canon、戰力或歷史 |
| 組織制度、任務分級、指揮鏈、法律地位、契約 | 組織檔 |
| 建築布局、空間動線、光線、氣味、場景質感 | 地點檔 |
| 道具外觀、模式、操作、戰術功能 | 道具檔 |
| 群像日常、配角快速出場、聯合作戰 | 蒸餾卡或蒸餾卡合集 |
| 其他文件中的順帶提及 | 僅作輔助，不得覆蓋專責文件 |

### 2.2 不採用「全部融合」

若兩份文件出現不一致：

1. 先確認是否屬於不同時間軸。
2. 再確認哪一份對該資訊具有專責權限。
3. 若仍無法裁決，保留衝突，不自行補完。
4. 不因版本號較高，就跨時間軸全面覆蓋。

### 2.3 完整檔與蒸餾卡

- 同一角色的完整檔優先於其蒸餾卡。
- 已載入完整角色檔時，不再載入該角色蒸餾卡。
- 蒸餾卡合集與合集內單張蒸餾卡互斥。
- 角色從配角升為主視角時，移除蒸餾卡，改用完整檔。

### 2.4 雪奈身份裝備與服裝分層

- 十八歲雪奈的銀色幽靈／零夜穿著裝備、身體覆蓋範圍、分層關係與受損指稱，以 `雪奈/雪奈_現行主設定.md` 為最高權威。
- `白霰`只指零夜上半身外層的白鋼色短袖短夾克；`幽靈斗篷`只指銀色幽靈的白色 Oversized 長袖連帽長外套，不得用任一名稱泛指整套服裝。
- 描寫受擊、破損、止血、散熱或模組失效時，先確認身體部位與當下最外層，再使用具體層件名稱；不得讓醒目的專名吞併黑色作戰服、黑曜、短褲、壓力層、水手服、過膝襪或其他護具。

### 2.5 十八歲雪奈戰鬥風格與戰力尺度

- 十八歲雪奈的原生極速、變速、近身戰主軸、踢技尺度、夢魘舞者／零點與跨身份共用武裝，以 `雪奈/雪奈_現行主設定.md` 為最高權威。
- 現行設定採 **世界最快的個體戰鬥員、極速主宰** 定位：雪奈以原生極速與精密變速支配節奏，雙腿是近身戰第一主武器；雙槍、雙匕與極光是跨身份共用標準武裝，依場景獨立作戰或與其他武器、腿技自然銜接。
- 高強度戰鬥、重甲／載具交戰、能力上限、破壞力尺度或精確戰鬥分鏡，不以雪奈蒸餾卡裁決；應載入完整現行主設定。
- `/AI小說創作_封存/雪奈` 內舊版主設定不得參與現在正篇戰力裁決。

2. 主視角角色完整檔
3. 其他核心角色蒸餾卡
4. 基地場景加入 `地點_鴉巢.md`

避免：

- 只靠角色檔推導正式指揮權
- 因雪奈戰力最高就讓所有人無條件服從

---

## 10. 寫作時的最小上下文原則

每個場景原則上只載入：

- 1份主視角完整角色檔
- 0至3份配角蒸餾卡
- 1份組織檔
- 1份地點檔
- 0至1份道具檔

只有在以下情況才增加完整角色檔：

- 多人主視角切換
- 角色關係重大轉折
- 多名角色能力邊界同時決定情節
- 需要精確比較不同角色的心理或戰術選擇

不要為了「設定完整」而把全部文件一起載入。資料越多不等於一致性越高；重複資訊會造成權重混亂、時間軸污染與角色特徵過度展示。

---

## 11. 資訊不足時的處理

遇到文件未明載的日期、事件、能力、制度或人物意圖時：

1. 不自行補成正史。
2. 可提出合理方案，但必須標記為草案或推論。
3. 新設定若獲採用，應回寫至對應專責文件。
4. 若涉及多份文件，先決定哪一份是該資訊的正式歸屬。

### 建議歸檔位置

| 新資訊 | 應回寫位置 |
|---|---|
| 角色核心、能力或關係 | 對應完整角色檔 |
| 短版群像摘要 | 蒸餾卡 |
| 組織規則與正式流程 | 組織檔 |
| 建築布局與場景感官 | 地點檔 |
| 道具規格與操作 | 道具檔 |
| 雪奈跨時期事件順序與因果 | `雪奈/雪奈_歷史事件索引.md` |
