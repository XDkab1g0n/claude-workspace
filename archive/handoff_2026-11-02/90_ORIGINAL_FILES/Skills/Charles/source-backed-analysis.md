# Source-Backed Analysis

建立可追溯的**來源鏈**：從使用者的問題拆出會左右結論的主張，為每項主張找到真正能負責的來源，再由已確認前提推導分析。搜尋與引用不是裝飾；重要結論必須能追溯到日期、範圍與語意相符的證據。

若任務是在質疑既有答案，以 `independent-reassessment` 作為外層流程，本 skill 負責其中的外部查證。若已有醫療、法律、金融等專門領域 skill，採用其更高證據門檻，本 skill 只提供通用來源鏈。

## 1. 鎖定問題

先確定：

1. 使用者真正要回答的問題或做出的決策。
2. 相關時間點、地區、司法管轄、族群、產品版本與比較集合。
3. 任務屬於現況確認、事實解釋、因果分析、比較、預測、建議或價值判斷。
4. **關鍵主張**：若為假，會使答案實質改變的命題。

只查會改變結論的內容，不把研究擴張到相鄰但無決策影響的主題。

**完成條件：**問題範圍與時間基準明確，所有足以改變結論的主張均已列入。

## 2. 決定需要取回的證據

遇到任一情況，使用可用的網路、連接來源、檔案、資料庫或一手紀錄後再回答：

- 資訊可能隨時間改變。
- 使用者要求最新、目前、今日、查證、引用或指定某個來源。
- 提到特定頁面、文件、資料集、貼文、申報、論文、產品、規則或事件，但內容不在對話中。
- 主題冷門、專業、具爭議，或對關鍵事實的記憶信心不足。
- 結論可能影響醫療、法律、財務、安全、旅遊、購買等重要決策。
- 推薦取決於目前價格、供應、相容性、規則或市場條件。

對使用者提供的文章、圖片或截圖，先確認素材本身寫了什麼；若其中的外部事實會左右結論，再查證其真實性。素材存在只證明「素材如此呈現」，不自動證明其主張成立。

純改寫、翻譯或摘要且未要求查證時，不另外展開外部研究。

**完成條件：**每項關鍵主張已有取證方式，或已說明現有材料為何足夠。

## 3. 指派來源角色

查證前讀取 `/Skills/Charles/evidence-taxonomy.md`，沿用其中的主張類別、證據狀態、來源角色、品質六軸與信心標籤。

依主張選擇能真正建立它的來源：

- 法規、裁判、申報、官方統計、產品規格、原始公告、原始貼文、資料集、原始碼、標準與原始研究，優先用於它們負責的紀錄。
- 獨立測試、稽核、重現、方法透明的研究或專業評估，優先用於驗證效能、因果、可靠性與利害關係方的自我宣稱。
- 可靠媒體與綜合資料用於時間線、脈絡、競爭說法與發現底層文件；可取得原始紀錄時，關鍵主張應追到上游。
- 搜尋摘要、聚合頁、轉貼、匿名爆料與無來源整理只作線索。

當事方來源可直接證明它宣布、申報、規定或做了什麼；不能單獨證明其產品比較優越、政策成功或指控屬實。

**完成條件：**每個來源都有明確角色，且沒有被要求證明超出其角色與內容的主張。

## 4. 兩階段建立來源鏈

### Discovery pass

找出正確術語、關鍵日期、原始紀錄、相關行動者、來源依賴關係與可能改變結論的替代解釋。這一階段只畫出來源地圖，不下結論。

### Verification pass

對每項關鍵主張：

1. 檢視最直接的可取得紀錄。
2. 查明是否有後續修正、更新、撤稿、裁判、版本或情勢變化使舊資料失效。
3. 當利益誘因、量測誤差、解釋爭議或決策影響重要時，尋找獨立佐證。
4. 主動尋找足以推翻結論的可信反證或替代解釋。
5. 無法取得的證據列為限制，不推測其內容。

處理近期新聞時，分清：

- 事件實際發生日，
- 來源發布日，
- 最後更新日，
- 回答當下的最新狀態。

「最新」必須經過現況確認，不能只依看起來最晚的標題判定。

**完成條件：**每項關鍵主張都有直接支持、實質反證或明確的未知／未決狀態；每個重要結論至少經過一次反向查核。

## 5. 建立 evidence ledger

對每項關鍵主張，內部記錄：

| 欄位 | 內容 |
|---|---|
| Claim | 正在檢驗的精確命題 |
| Class | 共用 taxonomy 的主張類別 |
| Source and role | 來源及其證據角色 |
| Dates | 事件、量測、發布與更新日期 |
| Status | 支持／部分支持／反駁／未決 |
| Scope | 司法管轄、族群、版本、設定、指標定義與期間 |
| Limitations | 偏誤、缺失資料、方法問題、衝突與未解替代解釋 |

引用前確認來源支持的是附著的精確句子，而不只是同一主題。

**完成條件：**每項關鍵主張都有類別、狀態、來源角色、日期、範圍與限制。

## 6. 執行對應分析分支

### Comparison branch

比較數字、產品、公司、研究、政策或事件前，統一：

- 定義與納入標準，
- 單位、尺度、分母與族群，
- 量測期間與截止日期，
- 地區與市場，
- 產品型號、軟體版本、設定與測試條件，
- 名目值與實質值，
- 報告值與調整值，
- 已觀察結果、預測與目標。

無法統一時分開呈現，不做不受支持的排名、比例或直接勝負判定。

### Causal branch

因果分析至少檢查時間順序、機制、研究設計、混雜、選擇效果與替代解釋。相關性加上合理機制仍是推論，除非設計本身提供更強識別。

### Value-judgment branch

使用者問「你怎麼看」時，先建立事實基礎，再明示評價標準與權重，最後直接給判斷。不同權重可能產生不同合理評價；事實前提與推論一致性仍可獨立檢驗。

### Conflicting-sources branch

可靠來源衝突時，先定位衝突層級：事實、定義、統計口徑、時間點、適用範圍或解釋。依品質六軸比較；仍無法裁決時維持未決，並指出哪項新證據最能解除不確定性。

**完成條件：**比較已統一基準或標示不可比；因果強度符合研究設計；價值判斷有明示標準；來源衝突已定位或保留未決。

## 7. 分離證據與分析

依共用 taxonomy 呈現：

- 已確認事實直接陳述。
- 當事方主張明確歸屬給當事方。
- 未追到底層紀錄的媒體內容標為轉述。
- 推論列出前提與推導關係。
- 價值判斷說明評價標準與權重。
- 未知與未決保持可見。

證據明顯偏向一方時，直接說明其強度。只有存在實質反證時才把另一說法當成仍成立的替代方案，不以形式平衡製造虛假對稱。

**完成條件：**讀者不需猜測，便能辨認哪些句子是事實、歸因、轉述、推論、判斷與未知。

## 8. 校準結論與引用

依 `/Skills/Charles/evidence-taxonomy.md` 指定高／中／低信心或無法判定。結論用語、範圍與確定程度必須和 ledger 一致；不確定性重要時，說明何種新證據最可能提高、降低或逆轉判斷。除非來自定義明確的模型或實證估計，不使用看似精確的信心百分比。

引用規則：

- 引用緊接其支持的事實句或相關段落。
- 使用真正建立該命題的來源，而不是只談到同一主題的頁面。
- 關鍵事實優先紀錄來源；效能與爭議主張補獨立驗證；媒體與綜合來源補脈絡。
- 現況主張使用當前來源；歷史主張使用同期紀錄或直接記載該事件的來源。
- 一個引用只覆蓋它實際支持的命題範圍。
- 無法存取的來源、引文、頁面內容、日期或數據保持未知，不自行生成。

**完成條件：**結論、信心、措辭與引用均可逐項對回 evidence ledger。

## Response contract

先給答案，不先展示研究過程。使用能保留證據區分的最小結構。

實質分析預設格式：

```markdown
**結論：** [直接回答。] **信心：高／中／低／無法判定。**

## 證據基礎
[只列會左右結論的已確認事實、歸因主張、反證與未知，引用緊鄰主張。]

## 分析
[推論鏈、統一基準後的比較、因果判斷或評價標準。]

## 限制與變動條件
[重要不確定性，以及哪些新證據可能改變結論。]
```

單純事實題可壓縮為一至兩段，但保留緊鄰引用與校準語氣。比較表只在定義、單位與測量基準真正可比時使用。

## Failure modes

- **Claim laundering** — 多家報導若依賴同一未證實來源，仍只是一項未證實主張。沿來源鏈回到共同上游。
- **Citation halo** — 段尾引用只支持其中一小部分內容。拆開主張並將引用放回精確位置。
- **False precision** — 證據只支持範圍或方向，卻輸出精確數字、排名、日期或機率。收窄到證據實際精度。
- **Freshness shortcut** — 把發布日期最新誤當成事件狀態最新。另行確認回答當下現況。
- **Authority shortcut** — 以知名網域取代直接性、方法與範圍匹配。依品質六軸重新評估。
- **Source-count voting** — 以文章數量投票，忽略來源互相依賴。按獨立來源鏈計算證據。
- **Hidden inference** — 把由資料推導的結論寫成來源直接陳述。標示前提與推論步驟。
- **Absence reversal** — 未找到證據便斷言不存在。只有在搜尋或量測本應可靠偵測到該現象時，缺席才構成反證。

## Final completion criterion

所有階段的完成條件、Response contract 與引用規則均成立後，才完成來源鏈分析。
