# 1. 第一卷核心

## 1.1 一句話概念

東京地底的舊式災後重整系統進入緊急遷移，有限的重型機具正沿維修網向搬巢母機集結；雪奈在放學、上課與約定之間逐段拆停獵潮，完整贏下戰鬥，卻把未能完全藏住的疼痛、疲勞與失約後果帶回五個同樣有自己生活的人身邊。

## 1.2 宣傳概念

當沉睡的地下維護系統開始把東京當成待拆工地，衝進黑暗終止它的，是身高一百四十九公分的世界最強少女——只是怪物拆完了，她仍要交作業、補回失約，並設法讓五個不會被一句「沒事」敷衍的人別看見她轉身時那半拍停頓。

## 1.3 直接目標與完整收束

第一卷約十九至二十一日。雪奈一行必須在搬巢母機取得最後能源、冷卻與轉向條件，進入人口密集交通帶前：

- 切離沿途活性節點
- 阻止墓犬奪取母機服務脊與維修能力
- 保住校園、交通、蓄洪與公共供電結構
- 迫使母機在可控制的深層轉向區露出
- 由雪奈徹底摧毀主脊匯流核心

卷末母機永久失能、不復活、不二階變身；墓犬現場領隊被捕，本次重裝回收能力完整瓦解。第一卷取得真正勝利，不用新黑手搶走結局。

## 1.4 閱讀承諾

1. **雪奈真的最強**：她迅速讀懂空間、受力與敵方任務；每次關鍵命中永久拿走敵人的選項。
2. **威脅不靠五五開**：危險來自質量、承載、撤離、多線遷移與墓犬已完成的工程動作。
3. **群像不取代主角**：其他五人決定撤離、路線、時間與代價；雪奈完成最難且不可替代的終止。
4. **傷勢有肉體重量**：雪奈會痛、會受傷、會低糖；她保有判斷與主體性，但掩飾不可能毫無破綻。
5. **日常能獨立成立**：課業、料理、演出、客戶、遊戲、創作與甜食不是戰後醫療附屬品。
6. **輕百合不是排名**：親密感來自偏心、距離、等待、想留下誰，以及明知對方看懂卻不說破。

## 1.5 視角政策

- 預設採**雪奈中心的第三人稱近距離限知**。
- 他人不在場的心理與事件，不得靠全知旁白直接補完。
- 第一卷只允許兩次清楚標記的視角例外：
  1. **第六章群像短插章**：奏與小夜各一段短限知，展示生活不是等待雪奈的背景。
  2. **第七章前半**：夏音限知，直到雪奈抵達；琉璃仍透過可觀察行動呈現。

# 2. 第一卷必要世界規則

## 2.1 獵巢與獵潮

獵巢原本是深層公共設施的自動保全與災後重整系統，負責測繪、清障、支撐、拖運、維修與設備搬遷；不是兵器動物園，也沒有政治人格。

墓犬切入外圍巢庫、拆走服務脊並接入舊式維修信標後，系統同時判定「庫體破壞、路線暴露、維護權限異常」，啟動資產整併：可動機具離庫、回收殘件、建立供電與承載，向搬巢母機集結，再遷往下一封存區。這場緊急遷移稱為「獵潮」。

核心限制：

- 庫存有限；每具完整機體損失均不可逆。
- 母機只能搬運、拆解、修理與重配現有零件，不能憑空生產。
- 修好一具機體會消耗其他殘骸的可用模組。
- 系統採實體分區、本地冗餘，沒有城市級單一關機核心。
- 雪奈能快速理解已接觸的接口與受力，不能憑空知道未露出的深層路線。
- 系統不完美學習、不複製雪奈，也不以能量級無限升級。

## 2.2 共通物質語言

獵巢機具共享：灰綠陶瓷耐磨塗層、黑色玄武纖維護套、深灰骨架、六栓式模組頸圈、鏽黃維修標線、石墨潤滑粉、凸點識別碼與同規格脊背匯流排。

四種現場簡稱只代表當下功能，不是四個物種：

| 簡稱 | 原始用途 | 緊急狀態威脅 |
|---|---|---|
| 探路型 | 測繪、環境採樣、放置路標 | 標記人群、承載與可通路徑，引導更重機具 |
| 拖獵型 | 回收人員、設備與殘骸 | 多機同步錨索拖走閘門、服務節或人員 |
| 破城型 | 清障、推移巨物、開啟變形閘門 | 楔頭、支腳與巨大動量破壞城市承載 |
| 架巢型 | 架橋、支撐、供電、冷卻與維修 | 展開後改寫戰場承載並替其他機具續航 |

## 2.3 路標、母機與可操作條件

- 主幹使用硬線／光纖；末端以短距光學、低頻振動碼及實體路標交接。
- 路標只能決定下一段方向、服務優先級與回收標籤，不是萬能控制器。
- 墓犬能偽造局部服務需求，把機具引入可拖運區，不能完整駕駛母機。
- 母機是列車級分節運輸／維修平台，需要外部能源、換熱冷卻、既有承重床與可用轉向路線。
- 可破壞：路標、冷卻支路、轉向鎖、匯流排、分節耦合器。
- 可反用：探路標記、拖獵索張力、架巢支架與母機冷卻排放。
- 不能直接炸毀整片地下，因上方存在學校、住宅、鐵道、泵站與承載結構。

## 2.4 墓犬

墓犬是約十八至二十四人的重型武裝回收隊，由兩個工程班、一個機動／警戒班及領隊、駕駛、醫療組成。目標是取得母機完整服務脊與維修能力，不想統治東京。

固定作戰語法：

1. **釘住**：錨樁、輪擋、液壓撐架固定目標與地形。
2. **切開**：切斷承載、能源、耦合或撤離線。
3. **拖走**：履帶拖台、吊架與纜索快速搬運。
4. **棄置**：成本失衡時立即丟棄假目標、普通設備與暴露路線。

設備有真實限制：錨固需時間與合適基材；切割器耗電、耗刀頭並產熱；拖台受坡度、轉彎與拖重限制；吊架展開後無法高速撤離。

優先序為：可撤人員＞完整服務脊／維修硬體＞稀有重裝＞普通設備。領隊不為機器自殺，也不派普通槍手和雪奈證明勇氣。其鮮明選擇是：**高潮時先放棄最昂貴吊架，命令受傷隊員撤離，再嘗試帶走唯一仍完整的服務脊**；這讓他是冷靜估價的人，而非只會說工程術語的介面。

墓犬痕跡：三角錨孔、保留吊點的乾淨切口、重心箭頭、分類綁帶，以及撤離時直接切斷而非回收的昂貴纜索。

# 3. 戰鬥、群像與關係

## 3.1 戰鬥語言

- 每場只讓讀者掌握一個核心工程問題；雪奈讀懂後迅速轉入爽快拆解。
- 關鍵命中必須永久減少感測、轉向、承載、牽引、冷卻或逃離選項。
- 雪奈可在安全餘裕充足時玩弄、欺敵與走漂亮路線；倒數、平民或傷勢成立後立即刪掉多餘動作。
- 其他角色不是替雪奈上狀態；她們改變誰能撤離、哪條路可用、哪個代價可接受。
- 不讓每次合作都變成「大家造好窗口，雪奈在門外等待必殺」。

合作節奏差異：

- 第四章：標準指揮窗口，潔西卡明確給雪奈進場時間。
- 第八章：奏與小夜已完成收網與主要勝利；雪奈只封死突發護衛風險，不奪走核心。
- 第十一章：雪奈已在管廊內移動，隊友持續更新真實路徑與流量；五秒是動態交會，不是等門開。

6. 第十一章：在戰場內依照他人的即時更新調整，不把合作等同等待。

# 4. 雪奈主要傷勢與恢復

## 4.1 定案傷勢

第九章採用：**左後胸廓／肩胛帶中度偏輕鈍挫、肋間肌拉傷、左上臂小範圍割傷**。

排除：骨折、氣胸、內出血、頭頸傷與咳血。

成因：墓犬預切蓄洪旁路上層平台並設置低破片定向裝藥，企圖讓平台與服務節落入下層拖台。雪奈能獨自完全避開，但撤離線與未穩定支柱會承受翻落。她先卸主受力、改變坍塌方向並降低能量，仍被提前起爆的餘波掀飛，左後胸廓撞上弧壁。

## 4.2 當場表現

- 空中失衡，完成半個保護性旋身，避免頭頸正撞。
- 落地膝手著地，第一口氣吸不進，只漏出短促痛音與生理性顫抖。
- 痛覺過濾只壓低干擾，不讓呼吸與組織立即恢復。
- 她依序確認意識、胸腹、骨盆、四肢力量與出血。
- 右手壓迫並固定左上臂，左臂貼身，主武器換右，刪除雙手重武器、高抬左臂與大幅旋轉。
- 她用整體步法轉向，擊毀切割泵與拖台轉向，確認撤離、武器與現場安全後才坐下交接。
- 不昏倒、不被抱走；令人心疼的是流程熟練得沒有一個多餘步驟。

## 4.3 恢復軌跡

| 階段 | 可做 | 不可做／明顯後果 |
|---|---|---|
| 當夜 | 清醒報受力、影像檢查、清創 | 不能騎夜巡者、不能高衝擊、重型雙手武器與大幅旋轉 |
| 第1–3日 | 一般行走、上課與思考 | 深呼吸、咳嗽、翻身、背書包、抬臂與側睡疼；體育課改觀察 |
| 第4–5日 | 低幅度腳步、右手射擊、短距低輸出零點 | 不能完整彗星、強力懸吊或急劇抗旋轉 |
| 第7–9日 | 活動度明顯回升；依檢查進行次最大動作 | 深呼吸與左後肩撞擊仍可能疼；夜巡者與高衝擊未自動解禁 |
| 卷末 | 一般上課恢復，急性期結束 | 尚未完全痊癒；重訓、夜巡者與完整負荷需再評估 |

## 4.4 完整彗星的出勤門檻

最終戰日期可於第十八日前後浮動一至三日。只有以下條件均通過，才能使用完整彗星：

1. 深吸氣與強力呼氣不出現保護性縮胸或明顯功能下降。
2. 軀幹抗旋轉、屈伸與核心固定達到可維持動力鏈的程度。
3. 重複短距衝刺、單腳起落與制動沒有左右代償或疼痛惡化。
4. 以次最大強度完成彗星乾跑與慣性回收，左肩胛／胸廓沒有失穩。
5. 靜流確認不存在結構性禁忌；夏音確認承帶與裝備不把負荷集中到傷處。

若任何一項不通過，應延後高潮一至三日，而不是假裝傷勢不影響動力鏈。故事預設她最終通過門檻，但命中後仍有正常能量空洞、腿部／核心發熱與短暫麻木，不追加新結構傷。

- **結果**：母機、主脊與墓犬本次重裝永久失能；雪奈無第二次結構傷，只有正常高輸出代價。

## 第14章〈地面上的未完成事項〉

- **日／地點**：戰後第2–3日；學校、工坊、宅邸與普通生活路線。

- **場景二——失去與交還**：夏音以METEOR名義向客戶交還系統；被毀服務脊與工坊成本不會神奇恢復。琉璃／小夜／夏音的聲光物件只作背景完成，不讓雪奈評審。
- **場景三——小夜的失約**：雪奈道歉，小夜接受她有理由，卻不假裝演出收入與合作損失不存在。兩人不必當場完全修復。
- **場景四——下一次排程**：奏帶回料理試作而不為未守床邊道歉；潔西卡的指揮認可透過正式紀錄存在，不安排成長演說。雪奈在新的共同事項出現前先問每個人的課表、演出與交件。
- **結尾**：第一獵潮完整結束。可留下「另一封存區曾物理切離」的非急迫事實，也可由六人的生活線引出完全不同的新威脅；不亮紅眼、不接終極黑手電話。

# 6. 第一章執行包

## 6.1 開場與功能

開場畫面：三年C班安靜到能聽見觸控聲。雪奈面前是進路希望調查，筆尖停在第一志願欄；桌上水杯先於地面出現一圈極細波紋。

第一章必須完成：

- 證明雪奈把普通學生生活當成真實選擇，而非偽裝。
- 自然建立雪奈、琉璃、潔西卡的同班關係。
- 讓奏、小夜、夏音以不可被臨時挪用的行程存在，不作群組點名介紹。
- 以低規模捕捉展示雪奈的非凡判斷，把完整王牌戰留給第二章。

## 6.2 場景節拍

1. 進路表與水杯微振。
2. 雪奈以手指、鞋底與桌腳確認頻率，仍保持學生模式。
3. 琉璃比對合法校內記錄，潔西卡處理教師與走廊人流。
4. 雪奈以領教材／設備確認的普通理由移動，先疏開清潔人員與學生。
5. 發現鏽黃路標、石墨粉與灰綠機具。
6. 由振動停頓看出它正在等待路標回覆；先觀察，不立即攻擊。
7. 確認一條可清空、可封鎖、遠離主承載的施工坑路線，改寫下一段方向。
8. 探路型進入死角，設備門與維修網封住退路。
9. 一次切掉感測桅桿，卡住六栓頸圈，保留證物。
10. 琉璃／潔西卡完成表面善後；雪奈回教室，進路表仍未替自己填完。
11. 章末更重機具循假路線接近施工坑。

## 6.3 感官與關係

- 觸覺：水面圈紋、桌腳、鞋底、舊牆的不同傳振。
- 聲音：智慧教室低噪與地下間歇回覆；不使用怪獸吼叫。
- 視覺：現代校園銀灰材質對上磨舊灰綠陶瓷、鏽黃標線與黑色粉塵。
- 琉璃把普通筆遞給雪奈，不替她填答案。
- 潔西卡在公開場合提供合法理由，私下要求她回來說真話。
- 夏音若收到接頭照片，先問能否存檔；只保存局部，不取得私人資料。

## 6.4 不應解釋或落入的問題

- 不解釋獵巢建造史、四類完整分類、母機全貌或墓犬目的。
- 不回顧雪奈全部過去與裝備表。

# 7. 寫作硬規則與可變細節

## 7.1 八項硬規則

1. 雪奈始終是絕對主角，且最難核心終止不可被替代。
2. 其他角色必須能作出雪奈未安排、甚至令她不舒服的有效選擇。
3. 每場戰鬥只有一個主要工程問題，讀懂後進入爽快執行。
4. 關鍵命中後敵方狀態永久改變，不反覆重置。
5. 第一卷只有一次主要中傷與一次獨立低糖；最終不追加重傷。
6. 傷勢必須進入課業、睡姿、交通、裝備與戰術，不能隔章消失。
7. 至少數個日常場景完全不處理任務或傷勢；甜食既可以是生理需求，也可以純粹是喜歡。
8. 不以官配競賽、五人同場爭寵、集體照顧會議或終極黑手維持吸引力。

## 7.2 正文時可自然決定

- 真實日期、路線名、施工單位與精確深度
- 獵獸序號與作者端庫存數
- 墓犬領隊姓名、外貌、性別與少量個性細節
- 奏料理菜色、小夜曲目、夏音客戶型號、聲光物件外觀
- 夢菓限定甜點與雪奈進路表最終答案

以上細節只需在相關章節保持前後一致，不另立設定檔。
