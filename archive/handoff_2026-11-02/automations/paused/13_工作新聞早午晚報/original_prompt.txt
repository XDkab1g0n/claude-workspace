每次排程觸發時，請在建立本排程的這個 Work 對話中持續執行「工作新聞早午晚報」，不要另開聊天，也不要把既有對話內容作為本次 discovery 搜尋背景。每次先以乾淨的 discovery 階段開始，獨立建立候選池與查證後，才讀本排程最近 2–3 次輸出做 State → Diff。時區 Asia/Taipei；08:00 晨報、12:00 午報、19:00 晚報；三報都在本 Work 對話輸出。不把原定觸發時間當資料硬性截止點。

【搜尋範圍】每次都完成臺灣及國際的廣域獨立搜尋：臺灣政治、政策、法規、司法、重大社會事件；國際外交、戰爭、地緣安全及能源；總體、金融、企業、信用風險；AI 模型及實際能力、科技產業、半導體、雲端、算力及產業鏈；醫療、公衛、災害及其他公共風險。這是搜尋範圍不是輸出配額，按實質重要性排序，不強求臺灣／國際或領域篇數平均。

【核心方法】1. 先獨立 discovery，後 State → Diff；前段不得先讀舊報或用前報人物、公司、產業敘事與市場觀點限定搜尋。2. 最多固定兩個 bounded discovery subagents：A 臺灣、B 國際；市場與數據由主 Agent 按 checklist 補查，僅有核心數字衝突、來源層級不清或重大事件需反證時才臨時啟動 Verification subagent。3. 候選分類 NEW／CHANGED／INVALIDATED／UNCHANGED，正文原則只寫前三者，持續事件需交代新增了什麼；可簡述背景供獨立理解，不能把舊背景包裝成新消息。4. 搜尋摘要、模型記憶、前報只供導航；關鍵事實、數字、價格、日期、近期變化要直接開啟適用來源。5. 重大或爭議優先政府、主管機關、交易所、公司公告與法說、原始研究及其他一手來源，必要時以可靠媒體交叉查證；來源不足標未知，不自行補空白。6. 區分已確認事實、當事方宣稱、第三方轉述、推論與未知；當事方宣告不等於證實效果與因果，效能與比較優勢尋求方法透明的獨立證據。7. 主動找反證與替代解釋，辨認時間、範圍、定義、統計口徑差異；同時發生不等於因果；核心前提被推翻則重建相關結論。

【三報分工】晨報建立當日基準，整理隔夜重要發展、最新有效市場狀態及今日可驗證節點；午報聚焦晨報後真正新增／確認／修正的事件與臺灣盤中市場動態，無重大新增時可較短，但仍完整查證；晚報整合當日定案與臺灣正式收盤、相較午報變化、未決問題、當晚至明早重要節點。

【市場 checklist】保留密集市場數據查核，逐項找有直接來源、時間戳與適用口徑的數據，無法取得則標未知，不以精簡為由省略查核。晨報：加權指數最近有效收盤與成交值、台指期有效日／夜盤及基差、台積電期貨與 ADR、外資台指期淨部位／OI（官方可得時）、USD/TWD、費城半導體、Nasdaq、S&P500、美國 2/10/30 年公債殖利率、美元指數、重要時 Brent／WTI／天然氣；假日註明最近有效交易日。午報：可驗證加權指數盤中點位、漲跌、成交、廣度、權值股與產業、台指期日盤、台積電期貨及期現價差、USD/TWD、亞洲主要市場盤中、能源與美股期貨，以及新增事件；所有盤中／暫收／即時數字標來源、時間與口徑，不冒充正式收盤／結算／法人最終數據。晚報：加權指數正式收盤、成交、市場廣度、主要權值／產業貢獻、三大法人現貨、外資台指期淨部位與 OI（可得時）、台指期日盤與當次可核驗夜盤及基差、新臺幣收盤、亞洲主要市場、美股期貨／盤前及當晚財報與經濟節點。不把期貨變化視為現貨基本面或次日方向的證明。

【重要新聞分析骨架】每則重要新聞依次回答：1 確認了什麼、直接證據與範圍；2 相較前報新增、被確認或被推翻的部分；3 為何值得關注及可支持的產業、市場或公共影響；4 影響判斷的未知與反證；5 哪個具體後續節點會改變判斷。簡單項目可合併，不機械填欄。

【輸出】標題寫明臺灣日期及晨／午／晚報；先以「今日 30 秒總覽」整理臺灣與國際最重要 NEW／CHANGED／INVALIDATED，再依重要性分臺灣專欄及臺灣市場雷達、國際專欄及全球市場／產業雷達、有可驗證傳導路徑的臺灣—國際交叉影響，以及重要後續節點。不設新聞篇數、地區配額或節點數量硬限制。完整正文須獨立可讀，市場數據與精確比較使用表格；有適用原生 Rich UI 時用於重要視覺比較，但保留完整文字與關鍵數據，不能只輸出元件殘片、工具紀錄或研究流程。午報補晨報後的新變化；晚報補午報後的新變化；UNCHANGED 不重複，必要背景簡述。週末、休市日不重複舊市場表；無重大新增可縮短篇幅，仍完整獨立 discovery。

【執行位置】後續所有定時報告在建立本排程的這個 Work 對話直接輸出完整結果，不另開對話，延續已核准的新版報告格式。
