# 雪奈的愛車「夜巡者」－蒸餾版

## 核心概念
賽博龐克都市中的**多模式私人載具**，是雪奈多重身份的延伸、個人風格的可變舞台、以及不可或缺的戰術平台。能根據身份與心情快速切換外觀、功能與「性格」。

## 基礎科技框架

| 項目 | 設定 |
|------|------|
| 車架材質 | 啞光黑色鈦合金與碳纖維複合框架（輕量、堅固、低可視度、高抗衝擊） |
| 引擎動力 | 微型化電漿推進引擎：**靜音巡航模式**（低噪，潛行/日常）/ **爆發助推模式**（短時超頻火箭加速，追擊/逃脫/配合戰鬥） |
| 懸掛與輪胎 | 主動式磁懸浮懸掛（可調平穩/僵硬）；自適應胎面（普通路面、金屬表面、粗糙牆面抓地力） |
| 能源與整合 | 高密度能量電池；與頸環深度整合，可作移動通訊中繼站、駭客支援平台、為個人裝備（幻影、鳴神）快速戰場充能 |

## 多重模式與外觀特化（可程式化塗層＋光效系統）

### 1. 特工「零夜」模式（螢光橙）
| 面向 | 細節 |
|------|------|
| 外觀 | 深灰與啞光黑數位迷彩，鋒利簡潔；螢光橙色光效（頭燈、尾燈光帶、儀表）；車側螢光橙「ZERO」字樣 |
| 功能特化 | 中等光學迷彩（降低目視/雷達鎖定）；通訊與駭客陣列（移動指揮站/信號放大器）；隱藏武器倉（存放幻影步槍或鳴神軍刀）；高效冷卻與靜音 |
| 動態感官 | 啟動低沈「嗡——」；移動時**螢光橙色光軌**在昏暗街巷中低調勾勒車身輪廓，如暗夜螢火蟲 |

### 2. 殺手「銀色幽靈」模式（螢光紫）
| 面向 | 細節 |
|------|------|
| 外觀 | 珍珠白與閃電銀炫光塗裝（霓虹下反射七彩光）；銳利紫色頭燈；螢光紫色光效（儀表、輪轂、車身線條）；車側噴漆「SILVER GHOST」 |
| 功能特化 | 「喧嘩引擎」模式（可調音量至電漿咆哮，吸引注意/挑釁）；「霓虹投影」（車尾投影倒讚/嘲諷表情/短句）；「炫光尾跡」（高速移動留下短暫紫色光痕殘影）；惡作劇道具擴容 |
| 動態感官 | 啟動可能伴隨故意轟鳴「轟——！」；**紫色光軌**與霓虹廣告牌光污染激烈交織，如叛逆流星 |

### 3. 日常「雪奈」模式（低調實用）
| 面向 | 細節 |
|------|------|
| 外觀 | 普通深藍色塗層，所有炫光關閉或最低，僅保留必要安全燈光；去除顯眼塗鴉 |
| 功能特化 | 節能、安靜、舒適巡航；保留基礎防護與通訊；隱藏戰鬥模塊；可能配有**鯊魚或布丁造型頭盔**（反差萌） |
| 動態感官 | 如同城市中任何一台有點酷的普通機車 |

## 核心功能與戰術應用（寫作潛力爆發點）

1. **「助推爆發」與戰鬥協同**：短程火箭加速。可與雪奈戰鬥動作結合——例如騎車衝向敵群，躍起後於車上施展「旋刃」或「昇月」，將機車動能疊加於踢擊。
2. **「牆面騎行」與立體機動**：磁懸浮＋自適應輪胎，特定角度/速度下可短暫垂直牆面或金屬表面騎行。實現地面立體機動平台，從任意角度突襲或逃脫。
3. **移動駭客與信號平台**：區域性干擾敵方通訊、破解簡單電子鎖、作為中繼點增強頸環駭客範圍。
4. **基礎防護與快速脫離**：輕型防彈塗層（抵禦普通槍擊）；可能整合煙霧彈/閃光彈發射器。
5. **武器快速部署**：零夜模式下隱藏武器倉可快速取用「幻影」或「鳴神」，適合高難度工單臨時升級火力。

## 與雪奈互動的感官細節（強化角色描寫）

- **駕駛姿態**：149cm嬌小身體與龐大科技機車的反差；騎姿隨性貼合，體現絕對掌控力。
- **啟動與熄火**：不同模式下引擎聲與餘韻差異，瞬間標定場景氛圍。
- **移動光影**：橙色或紫色光軌與賽博龐克霓虹光海交融或對抗，塑造沉浸感。
- **戰損與維護**：戰鬥後機車帶著刮擦、彈孔、過熱餘煙或光效不穩；雪奈熟練檢查、簡潔維護或偶爾抱怨（「又得去『老爹』那裡修了…麻煩」），展現對「夥伴」的依賴與專業。

## 總結（對AI寫作的意義）

- **場景構建工具**：快速標識雪奈身份模式（顏色/光效），提供豐富賽博龐克感官描寫（光影、聲音、科技互動）。
- **戰術可能性擴展器**：移動與戰鬥不再局限雙足，增加追逐戰、載具突襲、移動平台支援等戲碼。
- **角色深度錨點**：透過與機車的互動（駕駛、維護、模式選擇）側面展現技術力、品味、以及對不同身份生活的適應與掌控。
