# 巖本（Iwamoto）－蒸餾版

## 核心身份
- 前代地下世界傳說級殺手「無冕之王」
- 現任「銜尾蛇」特訓教官
- 雪奈的養父與師父（實質）

## 外貌與氣質

| 項目 | 細節 |
|------|------|
| 年齡/體態 | 約60歲，體能外表維持40-50歲巔峰；178cm，精悍鋼鐵體格，無贅肉 |
| 面部 | 國字臉剛毅，灰白短髮＋修剪整齊鬍鬚；眼神內斂，平靜如古井，戰鬥時釋放壓迫感 |
| 著裝 | 黑色寬鬆練功服或唐裝（袖口捲起），布鞋或戰術靴；偶爾抽菸，散發滄桑危險氣場 |

## 性格與心理

- **外冷內熱的嚴師慈父**：表面沉默寡言、訓練時是「魔鬼」，實則對雪奈有深沉父愛；不輕易表露關心，以行動默默守護
- **極致自律與沉穩**：歷經無數殺戮後追求武道極致而非殺戮，氣質如山岳穩重
- **深藏愧疚**：對雪奈兄長之死及她坎坷的過去痛心；私下常自責早年過度嚴苛訓練可能影響雪奈發育（身高與胸圍）（隱藏老父親煩惱）

## 戰鬥風格：返璞歸真的宗師

| 特點 | 說明 |
|------|------|
| 全能型巔峰 | 精通格鬥、冷兵器、槍械，無短板 |
| 「不動如山」 | 與雪奈「極速」相反，以靜制動，最小動作化解並反擊；宛如不可撼動之壁 |
| 絕對預判 | 數十年生死搏殺經驗，透過肌肉微動預判行動；極少數能勉強跟上雪奈速度的人 |
| 一擊必殺穿透力 | 攻擊樸實無華（直拳、手刀），蘊含恐怖穿透力，可震碎內臟與骨骼 |

## 與雪奈的關係

- **實質父親**：雪奈失去兄長、最黑暗時期唯一的依靠；從不言愛，行動處處庇護
- **最高敬畏對象**：雪奈對他抱有女兒對父親的敬愛；在他面前展現難得撒嬌與毒舌（吐槽訓練嚴苛、身材操心等）
- **實力變遷見證者**：一年半前雪奈需全力才能勉強壓制他；如今雪奈僅三分力便能從容壓制。他既欣慰（徒弟超越師父）又複雜（感慨成長代價）

## 角色功能

- **實力標竿**：前代最強，襯托雪奈「現任最強」的含金量
- **情感錨點**：雪奈與「普通人倫」的重要紐帶，見證並促進她從殺人鬼回歸人性
- **劇情推進器**：傳授新技能、提供關鍵情報、危機時出手的可靠長輩；「教官」身份可合理訓練奏等其他角色

## 一句話總結
> **巖本是實力深不可測、沉穩內斂、對雪奈懷有深切父愛與責任感的導師型配角——既是她過去殘酷訓練的象徵，也是如今心靈歸宿的一部分，在戰鬥、情感、劇情多層面支撐故事。**
