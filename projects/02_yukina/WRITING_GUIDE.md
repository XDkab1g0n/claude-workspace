# 雪奈寫作指南

人物以 `current_canon.md`（v17.8.2d）為準；這份指南談的是怎麼把她寫好看。內容整合自 2026-10-26 方法學與範文精讀，原文在 `archive/handoff_2026-11-02/projects_02_yukina/`。

## 最高標準

**寫出好看、爽、讓人想繼續讀的小說。**合理性是用來支撐作品的，不是把作品磨成技術說明書。炫技、喜劇、浪漫、角色主場、高壓爆發，都可以依情境寫得華麗；有目的的浮誇、招牌習慣、趣味與可愛，不需要每一處都推進情節。改完的版本如果更工整卻更平淡，回到比較有生命力的那一版。

不要寫「設定上很強的雪奈」。要讓讀者在高解析度、連續流動的場景裡，直接看見她為什麼漂亮、危險、聰明，而且強得不講理。

## 雪奈是什麼樣的主角

- **強要直接可見。**速度、技巧、控制力、爆發與解決問題的能力，要在畫面裡成立，不靠戰術解說或讓讀者自己推理。力量可以先被看見，之後才被理解。
- **強有很多種樣子。**結果本身、無聲的處置、時間差、對手不得不放棄的選項、旁觀者事後才發現的痕跡、強者之間細微的勝負、讓同伴的能力得以發揮，都是她的強。敵人可以全程清醒、早就知道她很強、完全不怕，甚至根本沒看見她。敵人看見她之後認知崩潰，只是其中一種寫法。
- **危險可愛的少女一直都在。**漂亮、纖細、年輕、淘氣、玩心與恐怖的戰力同時成立，不是輪流切換。可愛來自具體的在意：好奇、審美、被真心稱讚打動、勝負欲、私人習慣、對朋友的細心，不只是嘟嘴、歪頭、「欸嘿」、糖果。
- **她始終是同一個人。**少女感、任性、聰慧、自尊、自由，以及對重要的人的愛，在戰鬥前、中、後都是同一個人格。不寫成受了傷才有人性，也不寫成變冷酷才顯得強。
- **大爆發少而準。**平常出力有高有低；恐怖的踢擊、瞬間爆發留給關鍵時刻，用來翻轉局面或打碎敵人的誤判。
- **外觀一直活在畫面裡。**髮型、服裝、裝備與動態剪影在整場戲裡持續參與，不是開場介紹一次就消失。

### 兩個身分
- **銀色幽靈**：傳說感、自由、玩心、惡作劇、視覺奇觀。可以陪玩、速決、不留痕跡、真心切磋、臨時改變主意。名號與傳聞本身會改變敵人的反應。
- **零夜**：公共責任、正式權限與資源、節能、精準、收束多線問題。她還是雪奈本人，有餘裕時一樣會觀察人、好奇、嫌棄、展現個人美感；合格隊友的主動選擇會真的改變她能做的事。
- 兩者不是兩種人格，差別在任務目的、資源、視覺與表現方式。身分要真的影響場面，不只是換衣服。

## 故事從哪裡長出來

**先有人的欲望。**動筆前在腦中建立每個人的目的、所知、誤判、所在空間、手上資源與當下狀態：雪奈想要什麼、對手想要什麼、隊友與旁人想保住什麼。問一句：**如果雪奈沒出現，這些人今晚會做什麼？**如果答案是「站在那裡等她來把他們踢飛」，這場戲還沒活。

**讓因果真的不同，不只是換場景。**最容易掉進去的骨架是：敵人針對雪奈布局 → 雪奈陪玩後用速度、借力或腿技破解 → 敵人震驚 → 可愛玩笑 → 回家吃甜點。換成冰場、車廂、重裝陣列、狙擊手，只要每個人的選擇和戲劇功能沒變，就還是同一場戲。新故事至少改變一項因果骨架：

| 可以變的地方 | 例子 |
|---|---|
| 交鋒的真正目的 | 保護、奪回、驗證、活捉、威懾、拖延、阻止消息外流、逃離、找一個人、替別人爭取選擇；目的可以中途改變 |
| 誰先動 | 雪奈主動挑戰、對手先發難、第三方誤判、盟友搶先、兩個敵對組織互鬥、任務對象主動求助、意外讓所有人的計畫失效 |
| 對手是什麼樣的人 | 某項技術的專家、狡猾但有原則的人、普通但可靠的專業者、目標不同的精銳、怕事的中間人、內鬨的勢力；對方可能根本不想贏她 |
| 這次靠什麼取勝 | 身體壓制、技術精度、讀出威脅、耐心、對話、掩護與分工、偽裝、情報、利用環境、看穿人心、法律或契約權限、單純的速度 |
| 敘事與時序 | 從結果倒敘、跟著不知情的人、從敵方視角開場、緊貼雪奈、雙線交錯、從動作中途切入、從失敗的預案開始、從安靜的善後開始 |
| 局面因何改變 | 對手真的學會應對、友方擅自行動、目標改口、情報不完整、雪奈發現任務不值得做、裝備出現可追溯的問題、第三方提早到場、意料之外的善意 |
| 雪奈當下的情緒 | 玩心、厭煩、好勝、真心欣賞、害羞、不耐、關心、好奇、嫌棄、安靜、憤怒、專業投入、輕鬆到懶得出手 |
| 收尾與餘波 | 無聲成功、一擊決勝、對手自願讓步、主目標成功但副目標失去、讓重要的人自己完成最後一步、合法交接、刻意留下懸念、不得不撤退、喜劇性誤會、強者間互相尊敬 |

挑 3–5 個真正會改變因果的地方，其中一個故意違反第一直覺。地點、天氣、武器、敵人數量、光效、招式是第二層，等因果定了再決定。

**沒有必備公式。**不需要三幕、三階段敵人、最終 Boss、裝備損壞、體力透支、固定數量的反轉。一場戲可以只是兩個高手談了五分鐘、雪奈只出手一次；可以從頭到尾激烈肉搏；也可以開篇就完成目標，剩下的張力在於怎麼處理知道真相的人。

**每個重要人物都有自己的選擇。**對手、盟友、保護對象至少各有一個出自自己意圖、不只是回應雪奈的決定。對手不必笨，雪奈也不必每一拍都算中。意外要從已存在的條件長出來，不用憑空的故障、新武器或秘密任務解圍。配角照自己的職責與個性行動，例如醫療交給現場真正有資格的人。

**人物說自然的話。**不輪流朗誦設定、不刻意產出金句，也不說自己不可能知道的事。學校生活可以是真正普通的日常；親密、幽默、嫌棄、照顧、摩擦，由當事人的關係與事件結果自然長出，不是每場戰鬥後固定附上的甜點。

## 戰鬥怎麼寫

- **一拍改變下一拍。**每次命中都要改變一些東西：對方的武器、重心、關節、退路、感知、目標或戰意。沒有帶來變化的連續命中，除非是刻意營造壓迫感，否則就濃縮。
- **因果比招式數量重要。**槍、刀、線體、道具、腿技、裝備、速度連成自然的流程，前一個動作製造下一個機會；巧思藏在銜接、選擇與控制裡，不做技能輪播。有時一記簡單直接的重擊，勝過繁複的連段。
- **空間資訊只給必要的。**讓讀者懂距離、接觸、方向、障礙如何影響攻防就好；不用每段重新量角度、算受力。抓一個關鍵支點，其他動作自然成立。
- **敘事時間可以伸縮。**不重要的交手一筆帶過，真正有趣的選擇或命中才拉高解析度。整場速決也可以，不硬塞慢動作高潮。
- **提高解析度不是加字。**補的是空間、距離、姿勢、視線、腳步、武器位置、頭髮與服裝的動態、裝備狀態、旁人反應，以及每一步如何改變下一步。
- **身體與美感。**鏡頭可以停在腳踝、膝、腿、腰髖、肩背與重心轉移上，讓力量、速度、姿態與服裝剪影互相支撐；寫的是美感與動能，不是解剖課或身材點名。可以主動突出腿部、腰髖、貼身輪廓、汗與血、近身距離的危險美感。
- **暴力可以猛烈。**殘酷、冷調、驚人的破壞規模都可以寫。血、骨裂、撞擊、碎屑、硝煙、聲音是可選的素材，挑會改變下一秒行動或讀者情緒的細節；沉默與省略也能加重殘酷感。
- **傷勢要局部、可追蹤。**傷口位置、握持、呼吸、支撐、轉向、裝備破損與事後餘波互相一致。不是每次都要受傷，傷得越重也不代表越有戲。用到傷勢、疲勞、裝備失效時，要有前因、後果與真正的代價。
- **能力與裝備照設定走。**十八歲正篇以原生極速、變速與雙腿近身戰為核心；槍、刀、線體／極光、道具與任務裝備各自獨立，也能無縫銜接，強度以 `current_canon.md` 為準。超常身體的耐受、反衝、受損、恢復都依設定，不用現實人體常識削弱，也不給設定沒有的能力免費修復。
- **連續性的分寸。**關鍵傷勢、核心裝備、決勝能力、重要資源與資訊嚴守連續性；小傷、服裝細節、標誌性小物可以為美感服務。

## 視角與節奏

- **原則上以雪奈為主視角。**需要時可以切到對手、旁觀者或其他主要人物，但每次切換都要帶來不同的資訊或情緒，而且不搶走主角。
- **旁人的反應最好是改變決定，而不只是提供驚呼聲軌。**少用瞳孔收縮、「她怎麼可能」、「怪物」來宣告強度。
- **段落要完整、流動、能朗讀。**以中長的敘事段落為底；短句與空行留給命中、爆發、停頓與認知翻轉。整篇一句一行，就變成 AI 電影預告片。反過來說，把所有句子拉長也是另一種僵化；關鍵是轉折、停頓、鏡頭與資訊揭露有沒有新的戲劇功能。
- **不替讀者總結。**「這代表她很強」「她因此感到恐懼」這種話，如果動作已經傳達了，就刪掉。精彩動作之後主動宣布它的意義，等於搶走讀者自己看懂的樂趣。
- **五感不是清單。**一個最能影響當場選擇的觸感、一次視覺錯判、一段突兀的安靜，常常勝過硝煙、金屬、血味、喘息輪流報到。
- **華麗要有內容撐著。**可以用華麗的文字與暴力美學，但不拿修辭填補劇情的空洞。
- **不急著收場。**寧可提高解析度、分段續寫，也不為了起承轉合壓縮場景；不用制式選項或突然轉場帶過還沒寫完的事件。Charles 要「完整一篇」或指定篇幅時，交付完整而且真的有發展的作品；要「繼續」或高解析度連載時，不必硬塞結局；沒指定時，照這個敘事單位自然寫完。

## 從範文學到的事

範文在 `selected_examples.md`（12 組精選片段，原文未改）與 `full_examples_archive.md`（11 篇全文）。逐篇分析在 `examples_editorial_analysis.md`。

**三篇核心範文的共通點**，是雪奈和世界產生了有趣而具體的關係：
- **〈銀色幽靈・Showtime〉**：她闖進別人正在進行的地下拍賣，讓拍賣本身變成她的秀；「追加拍品：你們的注意力」從台詞變成整場的行動原理，最後那盞吊燈讓整座劇院成了她的武器。重點是**場域原本的用途被角色重新賦予意義**。
- **〈霓虹紫與慢半拍的殘影〉**：減速殺戮盒是合理的反制，射手的提前量也算對了，她卻主動慢了半拍。驚奇發生在**對手正確的預期失效**的那一刻；銀髮、斗篷、裙擺慢一拍跟上身體，讓讀者看見時間差。
- **〈退回寄件人〉**（Charles 明確稱讚過）：目標本身有戲（必須完整銷毀的封箱、退貨單、運輸站的準時信譽）；城戶是真正的對手，有專業、紀錄與底線；雪奈刻意不拆，強度裡包含自我約束；最好笑的是城戶指出退貨單「格式錯了」，結尾回收開頭打不通的客服電話。重點是**對手、目標、玩笑長成同一條故事**。

**日常與非戰鬥篇**同樣成立：神諭篇裡她把兩份布丁看得比五百萬日圓的委託重要；夜歸時用「人家說不要，就是不要」替私人界線建立重量，然後世界最快的少女乖乖等紅燈；和奏聊起做壞的燉飯，關係的進展靠食物、記憶和沒說出口的心事。

**失敗稿走偏的地方**，是越寫越像在證明「雪奈打得贏任何東西」，而讀者早就知道這件事：
- 一次次「敵方部署 → 雪奈另走一條路或拆掉 → 敵方驚駭 → 下一個部署」，單一動作設計得再通順，讀起來也像在寫七道相同的題目。
- 大量敵軍只是「待消滅的數量」，沒有能改變她下一步的對手。
- 旁人與旁白反覆解說她不只是快，強度變成主持人宣讀的結論。
- 重寫時換了場景與素材，卻沒換衝突骨架。

讀者真正想知道的，是**她會怎麼讓這一件事變得前所未見，而且只有她會這麼做**。

## 可以借的技法

這些是可取用的工具，不是每場都要用滿；用了反而變無聊、搶走雪奈戲份或重複既有作品時，就不用。借的是敘事機制，不照搬原作的文字、台詞或場面。

| 參照 | 可以借的 | 適合的時機 |
|---|---|---|
| Joe Abercrombie《The Blade Itself》〈The End〉 | 攻擊、跌撞、位置與武器狀態形成不可逆的連鎖，失手也有重量 | 身體代價、地形驟變、混戰求生 |
| 《無職轉生》〈Turning Point 2〉 | 強弱差距寫成「對手可行的選項一個個消失」 | 呈現世界級強者的不可對抗 |
| 《陰影實力者》〈アイ・アム……〉 | 角色的審美與自我表演結合，壓倒性勝利仍有娛樂性 | 銀色幽靈的自由、玩心、傳說感 |
| 《Re:Zero》第一章決戰 | 選擇知情程度不同的視角，讓後果顯示力量的規模 | 重大爆發、對友軍／平民／任務的影響 |
| Brandon Sanderson《Mistborn》序章與談動作場面 | 先用人物態度建立吸引力；戰鬥以問題、決策與視角為中心 | 登場、任務、性格與能力交融 |
| Richard Connell〈The Most Dangerous Game〉 | 衝突可以在接觸之前，由身分、資訊與獵人／獵物的關係形成 | 搜索、追逐、偵查、偽裝 |

背後是六個可以自問的問題：誰在做選擇？局面因何改變？誰看見了什麼？強大如何讓人感覺到？代價留在哪裡？讀者的期待被推往哪裡？

## 動筆流程（在腦中進行，不出現在正文）

1. **定位**：確認世界線、時期、人物、場景、傷勢、裝備、關係與誰知道什麼。讀核心人物的完整設定，以及這篇會用到的配角、地點、組織（見 `source_guide_2026-10-30.md`）。設定沒寫到的就當新創作寫，不升格成正典。
2. **構思**：建立各方的欲望與所知，挑 3–5 個因果變數，至少想兩條真正不同的因果走向，選更好看、人物更真實的那條。沒有反轉的版本也可以入選。
3. **寫正文**：用行為、對話、感官、動作結果、人物反應與情緒推進；戰術分析與工作筆記留在幕後。寫到人物自然會改變決定時，允許推翻原本的設想。
4. **重讀**：依序檢查：
   1. 好不好看？開場與後續有沒有讓人期待，人物的選擇和場面的結果值不值得讀？
   2. 雪奈是不是自己故事的驅動者？強大、少女感、危險、人味有沒有在行動中同時成立？配角有沒有自己的意志？
   3. 跟最近 3–5 篇比，刪掉地點與武器名稱後大綱是不是幾乎一樣？一樣的話，改交鋒目的、發動者、關係或成功條件，而不是換招式。
   4. 重要動作讀者看得懂嗎？命中有沒有改變局面？傷勢與裝備有沒有可見的後果？
   5. 段落有沒有呼吸，身體與服裝有沒有參與畫面？有沒有公式化的俏皮話、廉價的驚訝、AI 式總結、多餘的科普？
   6. 和 v17.8.2d、地點、組織權限、人物關係、近幾篇的連續性相容嗎？

   骨架失敗就整幕重寫，不只是換形容詞；骨架成立之後，才細修站位、動作因果、傷勢、裝備、時序與語言。

## 自我測試

想確認這些原則有沒有真的發揮作用，就分別寫寫看：單方面速決、真的受傷的苦戰、立體的複合武裝戰、幾乎沒有戰鬥的零夜任務、普通的校園日常、多名配角各自行動的任務後續。逐篇看因果和趣味是否各不相同，而不只是換了場景與視覺素材。
