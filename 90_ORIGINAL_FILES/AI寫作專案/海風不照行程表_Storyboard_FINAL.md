### POV

全篇使用雪奈的限制型第三人稱近距離視角。可以描寫她根據表情、停頓、動作與既有了解所作的判斷，但不得直接進入其餘五人的內心，也不得讓琉璃或小夜具備讀心式理解。

### Tone

### Episode-local Facts

- **汐見岬**：不屬於既有組織或任務體系的私人度假地。兩層別墅面海側是相連的客廳、開放廚房與有簷木平臺；平臺旁有戶外淡水沖洗區，石階直達封閉小海灣。海灣由緩坡沙床、左側低矮巖岸與右側短防波堤構成，遊玩區視線完整、沒有公眾人流。
- **天氣**：上午晴朗；午後海平線上逐步形成積雲，風向與浪況先改變；約傍晚五時驟雨抵達。六人依更新資訊主動撤收，無人遇險。雨只切斷舊行程，不替角色完成轉折。雨後留下深藍暮色、濕沙與零碎雲縫光，沒有原訂金色夕陽。
- **海水防護**：琉璃與夏音的機械部位可承受本篇所需的短時間海水浸泡；上岸後仍須淡水沖洗、乾燥、檢查接口。這是本篇裁定，不代表無限制深潛或全域規格。
- **琉璃浮力框架**：琉璃與夏音共同設計的大體積透明承重框架，以環繞腰背的多個密封浮力艙提供足夠排水量；不是普通救生圈，也不靠他人持續扶持。框架只連接琉璃指定的外部接口，不開啟機體、不讀取韌體；最終鎖定、解鎖、配重與姿態校準均由琉璃確認。她只在本次測試中第一次使用這套框架達成「不必持續施力便能停留於浪中」，不得擴寫成生平第一次下海。
- **水中裝備**：雪奈在下水前親手取下「樞紐」並放進乾燥盒；離線不影響她的人格、判斷或原生能力。小夜把「響核」與「心嘯」留在岸上，只使用獨立防水錄音器。琉璃的觸手使用精密手／鈍性划水末端，不掛武器。夏音採無武裝基礎右臂與海水防護的輕量休閒外骨骼設定，不搭載疾風、狙月、爆裂或其他戰鬥模組。
- **夏音游泳**：夏音能自主正常參與，但左腿舊傷並未消失；水中不做無代價的長時間高速踢水，浮力與輕量支援降低負荷。故事不需要把疼痛變成戲劇焦點，事後沖洗與保養必須存在。
- **兩種照片**：原行程中的「夕陽正式照」屬夏音可公開使用的 METEOR 夏日影像；雪奈真正想要的是完全私人、六人全入鏡、沒有攝影者／照顧者／指揮者／補位者、也沒有人為公開內容表演的一張照片。
- **影像同意**：拍攝、保存與公開是三個分開的同意層。正式玩水時，夏音除把相機留岸，也主動關閉義眼錄影與自動保存。最終照片由獨立相機倒數拍攝，六人同意私人保存、禁止公開；不得另留未交代的義眼側錄或自動備份。
- **聲音同意**：小夜若使用琉璃的機械振動，必須由琉璃主動選擇並同意錄製的聲響樣本；兩人是共同創作者，琉璃不是可任意取樣的設備。
- **活動規則**：海中遊戲與排球只使用娛樂安全尺度的身體能力。潔西卡不用電能力；琉璃不用炮、刃、EMP與腿部推進；夏音不用武裝、錨鉤或推進；雪奈不用外置裝備，也不得以超出普通運動安全的爆發硬追球。所有人遵守規則不是能力遺忘，而是主動選擇共同遊戲的成立條件。

### Global Character Controls

- 雪奈的精密行程出於真誠照顧與她擅長整合限制，不是突然變成控制狂，也不是「切換成零夜人格」。學生、私人雪奈、銀色幽靈與零夜始終是同一人格。
- 行程表一開始確實有用：它處理潮汐、紫外線、午餐、器材與每個人的偏好，五人因此自願試行。問題在於表上每個人都有專屬時段，雪奈自己的欄位只有協調、搬運、緩衝與安全確認。
- 奏被拉進水後，必須由她主動選擇留下；她短暫休息不等於不再喜歡照顧。
- 琉璃下沉是她主導、有停止條件的浮力校準，不是受難或救援笑話。她的提問來自行程內容的可觀察證據，不替雪奈診斷心理。
- 潔西卡的正式勝利由琉璃一傳、她自身強攻威脅與奏的觀察共同成立；不靠雪奈失智、放水或偶然浪頭。
- 小夜接受生活雜音不等於放棄作品標準；雨後短曲只是私人粗稿，不是突然完成代表作。
- 夏音放棄這次公開影片不等於放棄 METEOR、表演慾或追星；她仍然元氣，只是在這次選擇本人參與與私人保存。
- 雨後活動不得變成另一套完美分工。沒有人分派工作，各活動可以交錯、停頓或只做到粗糙版本；唯一需要六人共同協調的是倒數合照。

### Illustration Style Anchor

所有插圖統一為高品質日系動畫電影風：清楚自然的身高差與肢體重量、乾淨線條、細緻水光與材質、群像動作優先、明亮健康的夏日日常鏡頭語言。六套泳裝必須依上表保留各自輪廓：雪奈纖細夢幻、奏復古溫柔、琉璃空靈近未來、潔西卡燦爛健康、小夜暗色系可愛、夏音流行華麗；不可再統一成高領防曬衣或角色配色運動服。岸上外搭只在離水活動時出現，正式玩水與排球皆已留在岸上。構圖焦點落在表情、關係與動作，不以胸、臀、濕衣透視、人工身體或義體作視覺賣點。琉璃的透明浮力框架必須具有足以提供排水量的可見體積，不畫成普通小泳圈；夏音只保留基礎義體與支援外骨骼，不出現武器。

## Scene 01｜十五分鐘的假期

### Story Function

建立六人的當日慾望、汐見岬空間與行程表的實際價值；以「五人的願望全被列入，雪奈自己只被列為功能」埋下核心缺口。

### Time / Location

第一天 09:10–10:00；汐見岬別墅入口、客廳、面海平臺。

### POV

雪奈限制型第三人稱。

### Entry State

- 六人剛抵達，穿便服，所有海水裝備乾燥未拆。
- 奏帶保冷箱、食材、防曬與急救；琉璃帶浮力框架模組與環境資料；潔西卡帶軟式水上排球與浮網；小夜帶獨立防水錄音器、浮標與收納箱；夏音帶相機、腳架、低功率燈與維修工具。
- 雪奈已掌握潮汐、紫外線、風況與五人的偏好，手機中有精確到十五分鐘的行程。
- 六人情緒輕快，但每個人都本能地準備先做自己的事。

### Scene Goal

雪奈想在不讓任何人覺得被犧牲的前提下，讓六種假期同時開始運作。

### Beat Sequence

1. 以車門、行李與第一眼海景建立身高差、物件量與空間：別墅面海平臺在前，沖洗區與石階通往下方海灣，遠方天氣晴朗。
2. 行李逐件暴露每人的慾望。奏先確認冰箱與廚房；潔西卡已經抱球往海邊；小夜在聽平臺下的迴音；夏音尋找逆光機位；琉璃核對潮位與浮具組件。雪奈先不阻止，觀察五條動線即將互撞。
3. 夏音先分開詢問「能否拍攝」「能否保存」「是否可能公開」，並把不同人的回答記成三層權限；這不是笑點，也不一律預設同意。
4. 雪奈拿出行程表。它並非荒謬清單：浮力測試對應最低浪況，玩水避開最高紫外線時段，錄音與影像有各自窗口，奏的備餐時間也有緩衝。
5. 五人各自確認自己的需求確實被納入，因此選擇試行。吐槽集中在精確到十五分鐘、像聯合行動簡報的形式，而不是否定雪奈的關心或能力。
6. 奏或琉璃在掃過表格時察覺：每個人的名字都有「想做的事」，雪奈名下卻只有搬運、協調、安全確認、備援與拍照前架機。她們此刻不點破，只留下視線或短停頓。
7. 六人依表分頭把食材入冷藏、器材移到平臺並換上表列的個人泳裝；雪奈、奏、潔西卡與夏音再穿好各自岸上外搭。更衣只作時間過場，不描寫身體或濕衣。
8. 雪奈站在平臺看見五人準時就位，對自己安排的成功真心滿意；六人帶著過於完整的裝備下階梯，剪影像一支正在執行多階段聯合任務的小隊。

### Character Notes

- 雪奈語氣慵懶、帶乾式得意，不用軍令腔；她是在分享一份自認貼心的答案。
- 奏先處理食材不是因為被命令，而是她確實在意；她對雪奈表上沒有私人時段的發現只表現在停頓。
- 潔西卡吐槽要直率而非反智；她承認潮汐與備餐限制合理。
- 夏音的同意流程簡潔專業，不能變成偷拍笑料。

### Action / Combat Logic

無戰鬥。空間軸線固定為「別墅室內 → 面海平臺 → 沖洗區 → 下行石階 → 海灣」，後續撤收沿相反方向進行。重型浮力模組由多人搬運，但沒有人接管琉璃身體或私自接駁。

### Sensory Anchors

- 推開落地門時灌入的鹹熱海風。
- 保冷箱輪子壓過木平臺接縫的規律震動。
- 晴光在尚未充氣的透明浮力艙上折出碎白光。

### Must Happen

- 五人自願接受一份起初確實有效的行程。
- 行程表明確包含五人的慾望，卻沒有雪奈自己的私人活動。
- 夏音建立拍攝／保存／公開的分層同意。
- 汐見岬的主要空間與撤收路線被清楚建立。

### Do Not Distort

- 不把雪奈寫成控制慾發作、焦慮崩潰或命令下屬。
- 不讓五人從一開始就厭惡行程；後面的拒絕必須來自條件與人物選擇逐步改變。
- 不用泳裝更衣或未成年角色身體作笑點、凝視或插圖理由。

### Exit State

## Scene 04｜正式的一局

### Story Function

雪奈想在天氣變化前，把每個人尚未完成的項目全部追回，證明延誤沒有讓任何人的願望被犧牲。

### Beat Sequence

1. 六人先完成必要的淡水沖洗：人與泳裝去鹽，琉璃框架和觸手外表面、夏音右臂與左腿外骨骼依本人程序沖洗。回到遮陽棚後，雪奈、奏、潔西卡與夏音重新穿上各自岸上外搭；琉璃與小夜留在遮蔭範圍並補擦防曬。這不是故障戲；確認完成後才進入遲到午餐。
2. 奏重新站回分餐、遞水、收濕毛巾的位置，自己總是最後才拿食物。雪奈看見她忙，卻把「讓奏休息」也加成另一個待完成項目，沒有真正讓她退出功能。
3. 雪奈重排下午，把小夜收音、夏音拍攝與琉璃尋找海玻璃壓進同一個東側窗口；她的計算在紙面合理，卻抹掉每件事需要沉浸與自行選擇的時間。
4. 小夜開始尋找乾淨浪聲，夏音已獲拍攝同意的低空攝影器與口頭提示卻進入同一聲場；小夜要求短暫安靜，夏音則發現若所有人只為收音靜止，影像也失去她要的生命力。
5. 琉璃在退潮線看見一塊令她停步的海玻璃。她沒有立刻為它證明用途；但新的拍攝走位需要她回到框內，她先說「可以稍後」，再次讓自己的慾望成為最佳方案的緩衝。
6. 小夜明確表示乾淨素材可以不收，夏音也說公開影片拍不到便算了；雪奈把兩句話理解為她們在體諒自己的延誤，反而更堅持替她們補回成果。
7. 雪奈的句子縮短、開始用「先完成」「下一區」「剩九分鐘」等任務式語法；不是人格切換，而是她以最熟悉的解題方法補償失去控制感。五人配合得越勉強，活動越不像她們原先想做的事。
8. 風向首先改變，東側浮標繩角偏移；遠方西南海面出現可見雨幕。雪奈與琉璃各自確認更新後得出同一結論：驟雨比原估提前，現在撤收才保有完整安全餘量。
9. 六人立即停止「追回行程」，沿已建立的路線收各自與鄰近器材：小夜取浮標；夏音關閉並收攝影器；琉璃與潔西卡撤浮網和框架；奏收食物、毛巾與急救箱；雪奈作最後交叉檢查但不替所有人重做一次。
10. 最後一箱越過平臺門檻後，雨勢才完整落下。四件被零星雨滴與撤收動作弄濕的岸上外搭在入口掛起，六人改披乾毛巾；原訂夕陽、戶外晚餐、公開用正式影像與合照都失效，沒有人受困、受傷或需要救援。

### Character Notes

- 雪奈不是責怪別人超時。她知道自己同樣喊了「再一球」，因此把未完成項目當成自己欠五人的債。
- 小夜與夏音的衝突是兩種真實創作需求不相容，不是一方不尊重規則。夏音只拍已同意內容。
- 琉璃的「可以稍後」應讓雪奈感到放心，讓讀者看出問題；此刻不能由旁白直接講解她在壓抑慾望。
- 撤收展示六人的成熟與效率，但不升格成危機高潮。

### Action / Combat Logic

無戰鬥。午後活動是一條連續失敗鏈，不拆成五個獨立小品。天氣變化依「積雲 → 風向 → 浮標偏角 → 可見雨幕 → 資訊確認」逐步成立。撤收沿海灣南側往北上平臺，器材分區已在 Scene 01 建立；雨在所有人進屋後才加劇。

### Sensory Anchors

- 淡水沖掉鹽膜後，機械表面由黏澀恢復乾淨滑順。
- 午後風把防曬味、食物冷香與遠處濕土味混在一起。
- 第一滴雨落在透明浮力艙上，比落沙聲更空、更響。

### Must Happen

- 奏重新落回照顧位置；小夜、夏音、琉璃的需求因同一套壓縮安排互相擠壓。
- 至少小夜與夏音明確說某項可以放棄，雪奈仍試圖替她們追回。
- 琉璃在雨前看見海玻璃但選擇稍後。
- 雨被提前鋪陳；六人主動、安全、完整撤收，無英雄式救援。

### Do Not Distort

- 不把夏音寫成無視同意的偷拍者，也不把小夜寫成要求所有人為她保持絕對安靜的暴君。
- 不讓雨突然憑空出現，或用設備被沖走、人物滑倒等巧合製造刺激。
- 不讓雪奈的任務式語氣成為另一人格、創傷發作或零夜模式切換。

### Exit State

- 六人與所有器材安全進入別墅一樓；海灘留空。
- 浮力框架已卸下，琉璃可自行活動；相機、浮標、浮網與食物封妥。
- 六人仍穿濕泳裝、披乾毛巾；四件岸上外搭掛在入口，樞紐、響核與心嘯仍在乾燥盒，尚未重新佩戴。
- 夕陽正式照與戶外晚餐明確取消；雪奈在餐桌上打開雨天備案。

## Scene 06｜雨天備案

### Story Function

讓五人的拒絕依各自理由逐一發生，而非聯手教育雪奈；琉璃只根據行程中可見的缺口提問，雪奈則主動選擇說出一項具體、私人且可完成的願望。

### Time / Location

第一天 17:05–17:35；別墅一樓客餐廳。北端接內室，南面落地窗外是暴雨中的海。

### POV

雪奈限制型第三人稱。

### Entry State

- 六人安全但尚未完全換洗，仍穿濕泳裝、披毛巾；四件岸上外搭已掛在入口，地面有沿撤收路線留下的少量水跡。
- 所有設備關機或封箱；夏音相機包扣合、義眼錄影關閉；小夜控制器仍在手中但外置響核不在頸上；琉璃無浮力框架。
- 雪奈無樞紐，以手機／平板顯示雨天備案。她相信只要迅速重排，仍能交付每個人的假期成果。
- 奏有能力立刻去廚房，小夜可以繼續取樣，夏音可以重新架機；她們尚未行動。

### Scene Goal

雪奈先想讓雨天備案立刻運作；在這套目標停止成立後，她必須回答自己真正想保留什麼。

### Beat Sequence

1. 雪奈站在餐桌北端，快速分派室內拍攝、晚餐、音檔整理、海玻璃替代燈景與設備乾燥；句法像高效簡報。話說完後，空間只剩雨打玻璃的聲音。
2. 沒有人事前串通，也沒有整齊拒絕。每個人先看向自己本來會拿起的東西，發現那已不是此刻想做的事。
3. 潔西卡第一個正面說她不要另一張表。她拒絕的是繼續假裝工作等於休息，不是要奪取領導權或否定雪奈整天的心意。
4. 小夜親手關掉仍亮著的控制器，明確放棄追那段排定的乾淨素材；提示音消失後，雨聲變得完整。
5. 夏音把原本可能重新開啟的相機包推回牆邊，保持扣合；她不以「至少拍點能公開的」替自己圓場。
6. 奏沒有去廚房、沒有收毛巾，也沒有替雪奈把尷尬轉成家務。她坐下，安靜留在場內，第一次不替雪奈完成下一步。
7. 琉璃掃過行程表中五人的名字與活動，只問：「這些都是我們想做的。妳自己想要什麼？」問題來自表上沒有雪奈私人欄位，不附帶人格分析。
8. 雪奈先用「大家都玩到就好」與玩笑繞過。五人不追問她的過去，也不輪流說理，只讓答案保持不完整。
9. 她最後說出：「……我想要一張六個人都在，而且沒有人正在工作的照片。」必要時再補充：只給六人私人保存，不屬於 METEOR 作品，也沒有誰留在鏡頭外。
10. 夏音先以專業方式確認私人保存與不公開，其餘人逐一同意；這不是立刻啟動新拍攝任務。雨勢在對話完成後自然轉弱，六人先去沖洗、換乾衣、喘息。

### Placement

插在 Beat 6–7 之間：潔西卡、小夜、夏音與奏已各自停止，琉璃正抬眼準備問話。

### Narrative Purpose

以靜止對照前一張競技高動態；讓「沒有人動」看起來是五個各有理由的主動選擇，而不是五人排成審判席冷落雪奈。

### Moment

雪奈手仍停在亮著行程表的平板上；小夜指尖剛離開熄滅的控制器，奏已經坐下，潔西卡正面站著，夏音的相機包保持扣合，琉璃的異色瞳看向雪奈。

### Composition

- 16:9 室內廣角，鏡頭位於雪奈後側略低處；她的小小背影與桌上冷光介面在前景。
- 五人分散於不同深度：奏坐在左側餐椅，小夜靠南窗，潔西卡站在右側桌邊，琉璃在中景正面，夏音靠封好的器材箱。
- 五人不排成一列；桌面只形成短暫距離，不構成敵我對峙。
- 視覺焦點由行程冷光穿過空桌面，落到琉璃左紅右藍的眼睛；暴雨海面在背景。

### Character Invariants

- 六人仍穿各自表列泳裝並披毛巾，四件岸上外搭已掛在入口，不出現在人物身上；泳裝材質保持正常不透明，鏡頭以群像距離與停止動作為重點。
- 雪奈：珍珠白／淡藤紫方領連身泳衣，背後淡紫交叉細帶與固定小蝴蝶結可見；銀髮低雙馬尾、無樞紐。
- 奏：奶油白／深墨綠小花高腰兩件式與單層短荷葉裙襬；小夜：午夜靛藍星點荷葉邊兩件式與短層疊泳裙、無響核。
- 潔西卡：白底鈷藍／橘紅熱帶花卉繫頸兩件式；琉璃：冰藍珠光花瓣領上衣與珍珠銀高腰泳褲，無框架且恰好六觸手低收。
- 夏音：莓果粉單肩連身泳衣、左肩薄荷綠荷葉邊與腰側白色星形扣；義體右臂及左腿外骨骼可見，相機已封包、無武裝。所有人安全無傷。

### Environment

面海別墅客餐廳、長桌、落地窗、灰藍暴雨與遠處模糊海灣；封箱器材沿牆堆放，地板只有少量撤收水跡。

### Lighting / Atmosphere

傍晚暴雨的灰藍漫射光、室內低暖燈與平板冷白光；濕髮、毛巾與水跡增加真實感。情緒安靜而堅定，沒有崩潰或審判感。

### Image Prompt

### Character Notes

- 潔西卡的拒絕直接但不羞辱；她不說長篇正論。
- 奏「坐下、不圓場」比任何告白都重要。
- 琉璃只問一次，不接著解釋雪奈的創傷、動機或人生課題。
- 雪奈可以停頓、嘴硬、試圖用玩笑轉向；她最後仍是自己決定回答。

### Action / Combat Logic

無戰鬥。拒絕按「潔西卡 → 小夜 → 夏音 → 奏 → 琉璃」逐一發生，每一步都改變室內聲音或物件狀態，不能剪成同時停工的戲劇隊形。雨聲一直存在，轉弱不與雪奈說完那句話精確同步成天意。

### Sensory Anchors

- 關掉控制器後，設備風扇與提示音消失，雨聲突然佔滿房間。
- 濕毛巾在椅背上滴下固定間隔的水聲。
- 平板冷光照在雪奈沒有頸環的頸側，顯得少了一道平常的黑線。

### Must Happen

- 五人各自停止，不是預謀的集體靜坐。
- 琉璃問出鎖定問題；雪奈說出鎖定願望。
- 照片條件包含私人保存、六人全入鏡與無人在工作。
- 任何人都不替雪奈作創傷解說。

### Do Not Distort

- 不寫成五人聯手治療、責備或逼供雪奈。
- 不讓雪奈崩潰、人格切換、突然否定規劃或為整天道歉。
- 不在願望說出後立刻讓所有人像接到新任務般分工。

### Exit State

- 雨天備案仍留在桌上但停止執行；雪奈的私人願望已被五人知曉。
- 六人已同意照片只供私人保存、不公開；相機尚未重新架設。
- 六人先去完整沖洗與換衣；Scene 07 開始前，琉璃、夏音完成必要淡水沖洗乾燥，雪奈重新佩戴樞紐。

## Scene 07｜不恢復原行程

### Story Function

讓六人各自選擇此刻仍想做的事，活動在同一空間自然交錯卻不被統整成新表；以粗糙短曲、無性能意義的海玻璃、未完成晚餐與私人相機共同準備最後一張照片。

### Time / Location

第一天 17:55–18:50；北側開放廚房、客廳窗邊、面海平臺與東側雨後濕沙。

### POV

雪奈限制型第三人稱，以她在室內、門檻與平臺間的自然移動串起多層活動，不切換內心。

### Entry State

- 六人已換上表列乾衣；雪奈銀髮披散並重新佩戴樞紐。小夜未佩戴響核或心嘯，只用便攜混音器。
- 琉璃與夏音機械部位已淡水沖洗、擦乾、功能正常；浮力框架在平臺維護架瀝乾，不在琉璃身上。
- 雨縮成零星水滴，天空由灰轉深藍；東側退潮線與海玻璃位置仍可安全抵達。
- 沒有人持有新行程，也沒有分派工作；晚餐、短曲、燈光與相機都尚未完成。

### Scene Goal

## Appendix D｜Writer Handoff Limits

Writer 可以自由決定句子、段落、小型肢體動作、自然對話、少量環境細節與不改變因果的過場；但不得：

- 改變八場的入口、核心結果或出口。
- 新增敵人、任務、危機救援、受傷、綁架、被捕、陰謀或重大反轉。
- 讓雪奈以降智、放水、能力消失或偶然浪頭輸掉排球。
- 讓琉璃被扶著玩、被未經同意拆裝、被小夜單向取樣，或把本篇框架升格全域 Canon。
- 讓夏音偷拍、保留未同意側錄、留在最終鏡頭外，或把這次選擇寫成永久放棄 METEOR。
- 性化未成年角色、濕衣、人工身體、義體、泳裝或任何插圖構圖。
- 以創傷解說、說教對話、完美夕陽、第二張照片或「不完美才完美」臺詞替代雪奈不重拍的選擇。

若 Writer 發現真正 Canon 衝突，停止該部分 prose realization 並指出衝突，不得自行改寫 Canon 或鎖定大綱。
