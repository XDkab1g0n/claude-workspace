# 星野夏音／「流星」｜蒸餾卡 v3

> **用途**：神諭、黑市委託、義體企業線、高機動重火力、技術工作、追星與核心群像。  
> **正史優先級**：若與本卡衝突，以《角色_夏音_v3》完整設定為準。

## 1. 當前身份

* 18歲，158cm。
* 獨立賞金獵人、義體與無人機維修技師、黑市裝備測試／情報交換／護送自由承包者。
* 代號「流星」；與銜尾蛇、八咫烏以合約與人情合作；神諭常客與工作夥伴。

* 戰術：高機動重火力、反無人機、反輕中型裝甲、精密遠射、空間牽引與快速救援。
* 技術：能拆解、維修、校準、改寫韌體、製作彈藥與處理企業後門。

## 2. 視覺辨識

* 櫻粉狼尾短髮＋薄荷綠挑染；左眼自然，右眼軍用義眼平時擬真為薄荷綠；左耳上方有螢光紫「幽靈」髮夾。

* 日常：黑色高科技連帽上衣、GHOST或METEOR圖樣、深灰百褶短裙與LED燈帶、右腿黑色大腿襪、左腿外骨骼視狀態外露，腰掛痛包與工具袋。
* 喜歡櫻粉、薄荷綠、透明材料、LED與Q版圖案；風格是御宅文化、街頭技術與義體改裝的混合。
* 戰鬥服以耐熱／防彈內層、模組化胸背承力架、完全展開的左腿外骨骼與右臂武器空間為核心；燈效可關閉、低亮度或全演出模式。

## 3. 人格與欲望

* 元氣、外向、直球、表演慾強；情緒很容易寫在臉上與HUD上。
* 擅長把危險變成熱鬧、把尷尬變笑點；喜歡錄影、剪輯、打Call與製造記憶點。
* 對銀色幽靈的崇拜是真實人格的一部分；她是真正會分析公開影像、裝備世代、戰術演化與剪輯偽造的研究型粉絲。
* 真正想要：身體硬體／軟體／維修／資料由自己掌握；以星野夏音／流星自己的名字被記住；證明受損、義體化與需要維修不等於失去魅力或自由；建立不受企業訂閱與後門綁定的技術網路；保留痛包、追星與煙火的快樂；在不演出、不輸出火力時也被認真看待。
* 核心缺陷：把被看見、記錄與喝采當成存在價值證明；會為畫面、品牌或偶像認可增加風險；用追星逃避自己真正想成為什麼；用玩笑掩蓋義體故障、疼痛、維修費與普通感。
* 最怕被看見義體拆下、電池耗盡、左腿疼痛、維修費不足與工作失敗的狀態。
* 成長軸：不是停止追星，而是讓METEOR逐漸擁有自己的標誌、戰術與技術道路。

## 4. 形成背景與工作

* 出身神奈川臨海工業區的機械維修家庭，從小接觸無人機、工業機械、電池、廢棄義體、貨運與港區設備。
* 14歲時因非法軍規能源模組與武裝無人機事故失去右臂與右眼，左腿重傷；賠償不足，初期商用義體受專有韌體、遠端診斷、零件鎖定與高額訂閱控制。
* 復健期間自學維修、破解原廠限制並與地下技師交換零件，將右臂改造成由本人掌握最高權限的模組平台。
* 最初接案是為維修費、追查事故責任並取得被企業壟斷的技術與證據；之後靠技術、遠射、無人機、高機動與宣傳建立「流星」名號。
* 收入高但支出也極高：義體零件、電池、彈藥、飛彈、冷卻、外骨骼、醫療、工作室租金與銀色幽靈周邊都會吃掉預算。

## 5. 「追星者」平台

* 追星者同時是日常右臂、武器平台、維修工具與個人品牌核心。
* 不是一條手臂同時塞入全部武器；大型槍管、彈匣與支撐模組需要外部攜行，任務前必須選擇配置與負重。
* 模式切換需要機械展開、武器校準、彈藥／電源確認。
* 日常模式具五指精細操作、觸覺回饋、工具接口、資料連接、小型焊接與螺絲工具，可做飯、維修、握手與畫圖。

## 6. 武器構型

* **疾風**：六管電驅旋轉機槍；中近距壓制、反無人機、輕裝甲與密集目標。彈藥與熱消耗極高，長時間射擊需要支點。
* **狙月**：電磁狙擊構型；外接延長槍管、肩托／胸背支撐與專用彈匣。中遠至超遠距精密射擊與反器材；需充能，電磁特徵與後座明顯。
* **爆裂**：肩背／腰側十二聯裝微型飛彈；可配破片、穿甲、EMP、煙霧、標記或非致命震撼。彈藥昂貴、附帶破壞風險高。
* **錨鉤**：攀爬、高速位移、急停、牽引傷員／裝備、限制敵人與建立重武器支點；受錨點承重、纜索長度與肩背負荷限制。

## 7. 義眼、外骨骼與支援

* 義眼：多光譜、低光／熱成像、高速目標追蹤、彈道預測、無人機資料整合、影像錄製與裝備辨識；可被干擾、欺騙與入侵。
* 左腿外骨骼：補足伸膝、踝部穩定、爆發與落地緩衝，具短距推進與姿態修正；不消除疼痛、疲勞、腫脹、神經異常與復健需求。
* 動作刻意利用義體右臂重量、自然左手精密、左腿外骨骼推力與自然右腿穩定，形成不對稱個人風格。
* 偵察無人機用於標記、視野中繼、彈道／飛彈導引與搜救；數量有限，可被EMP與防空摧毀。
* 會使用手槍、衝鋒槍與維修刀具；失去義體武裝後仍是受過完整傭兵訓練的戰鬥員。

## 8. 戰鬥哲學「追星式機動火力」

> **移動、標記、切換火力，讓敵人的注意永遠追不上下一個爆點。**

* 流程：無人機與義眼建立視野 → 選模組 → 錨鉤與外骨骼取位 → 疾風／爆裂迫使敵人改隊形 → 狙月處理高價值節點 → 牽引隊友、平民或裝備 → 在能源與彈藥低於安全線前撤離或降級。
* **演出模式**：彩色尾焰、HUD、語音與Q版動畫，適合公開救援、威懾與吸引注意。
* **專業模式**：關閉非必要燈效與錄影，以最低有效火力和任務交付為優先。
* 她能關閉演出；真正的缺陷是有時不願意關。

## 9. 弱點

* 模組負重、彈藥成本、能源與熱、右肩承力、左腿舊傷、電磁干擾、維修依賴、企業追蹤、高調品牌、演出慾、粉絲偏差與財務都是實際限制。
* 重武器後座會回到自然肩帶、頸背與脊柱。
* 義體、義眼與外骨骼共同爭用電池與冷卻。
* 斷電與故障不等於完全失能：她仍有自然左手、自然右腿、傭兵訓練、維修知識與普通武器。
