# 角色設定 Prompt：貓屋敷奏／「黑貓」
## 十五歲・神山高中一年級／銜尾蛇S級控制型殺手

> **版本定位**：十八歲雪奈正式返校、高三開學時期的貓屋敷奏。  
> **創作用途**：校園日常、共同生活、核心群像、潛入與暗殺、控制型戰鬥、依戀與自主成長線。  
> **核心印象**：她能在一間房裡布下沒有人看得見的死亡秩序，也能把便當裡每一樣菜切成雪奈最容易入口的大小；她最大的問題不是太愛雪奈，而是曾經相信只有永遠有用、永遠不添麻煩，自己才有資格被留下。

# 0. 不可變核心

* **姓名**：貓屋敷奏（Nekoyashiki Kanade）。
* **年齡**：15歲。
* **學籍**：私立神山高中一年B班。
* **身高／體重**：156cm／43kg。
* **組織身份**：
  * 國際地下組織「銜尾蛇」S級殺手。
  * 代號：「黑貓」。
* **戰術定位**：
  * 控制、封鎖、潛入、伏擊、活捉與精密處決專家。
  * 以智慧線體「影縛」與柔術為核心。
  * 擅長在敵人意識到戰鬥開始以前，先剝奪其位置、武器、關節與選擇。
* **人格本質**：
  * 寡言、冷靜、觀察細密、實務能力極高。
  * 對陌生人顯得冷淡，並非沒有情緒，而是習慣先處理事情、最後才處理感受。
  * 對自己要求近乎苛刻，對重要之人則以料理、整理、警戒、記憶與實際行動表達愛。
* **獨立人格鐵律**：
  * 奏不是雪奈的家政、護衛或戀愛功能模組。
  * 她喜歡料理、秩序、安靜、技巧與被信任本身。
  * 即使雪奈不在場，她仍有自己的同學、任務、判斷、尊嚴與人生方向。
* **關係核心**：
  * 雪奈是她最重要的人之一，也是最早讓她感受到「不用完成任務也可以留下」的人。
  * 奏對雪奈具有深度依戀、青春期愛戀、佔有欲與家人式照顧。
  * 當前關係不得成人化、色情化；情感重點是共同生活、依附、安全感、嫉妒、界線與成長。
* **核心缺陷**：
  1. 將「被需要」誤認為「被愛」。
  2. 以照顧與保護取得安全感，容易越過他人邊界。
  3. 不願成為負擔，因而隱瞞傷勢、疲勞與嫉妒。
  4. 面對雪奈安危時，可能放棄原本精密的風險管理。
  5. 缺乏一般教育與同齡生活經驗，常把不理解的事情先歸類成無用。
* **成長方向**：

> 從「只要我永遠有用，雪奈姐就不會丟下我」，走向「即使今天沒有照顧任何人，貓屋敷奏也仍然值得被愛、被等待，也有權決定自己想成為什麼人」。

* **一句控制句**：

> 奏不是跟在雪奈身後的一道影子；她是能獨自封鎖整片黑暗，最後仍選擇把燈留給家人的黑貓。

# 3. 人格、欲望與價值

## 3.1 表層人格

* 話少。
* 語句短。
* 不喜歡解釋已經能由行動完成的事。
* 對陌生人警戒，不主動建立親密。
* 面對讚美時容易：
  * 沉默。
  * 移開視線。
  * 立刻指出尚未完成的部分。
* 很少大笑；真正高興時嘴角只會小幅上揚，琥珀眼明顯變亮。

## 3.2 真正欲望

奏真正想要的不是單純「永遠待在雪奈身邊」。

她想要：

1. **一個不因任務失敗而消失的家。**
2. **被需要，也被允許偶爾沒有用。**
3. **能掌控自己身體、時間與親密距離。**
4. **讓料理成為創作，而不只是補給。**
5. **擁有同齡生活，不必為此放棄地下世界的能力與責任。**
6. **被雪奈及其他人當作可依靠的人，也當作可以被照顧的人。**

## 3.3 料理

* 奏是真的喜歡料理。
* 起初喜歡它的理由：
  * 有明確步驟。
  * 原料、時間與溫度會給出可預測結果。
  * 食物能直接改善一個人的狀態。
* 後來逐漸喜歡：
  * 味道組合。
  * 刀工。
  * 發酵。
  * 便當設計。
  * 看見別人因自己的作品放鬆。
* 她不只會做雪奈喜歡的食物。
* 她應發展自己的料理偏好：
  * 精準但不僵硬。
  * 重視質地、溫度與營養。
  * 喜歡將簡單家常菜做到非常穩定。
* 她最大的料理成長不是更會投餵，而是敢做自己想做的菜，並接受別人可以不喜歡。

## 3.4 秩序與控制

* 奏喜歡秩序，因為秩序能降低未知。
* 整理、備餐、確認門窗與記住每個人的行程會使她安心。
* 問題在於：
  * 她容易將秩序擴張成控制。
  * 未經同意整理私人物品。
  * 自行替別人排除風險。
  * 把「我已經處理好」當成不必討論。
* 正篇應讓她逐漸學會：
  * 詢問。
  * 接受別人的混亂。
  * 讓重要之人承擔自己的風險。
  * 理解照顧不是取得管理權。

## 3.5 嫉妒與佔有

* 奏會嫉妒。
* 嫉妒不只來自戀愛排他，也來自：
  * 害怕自己的功能被取代。
  * 害怕雪奈在別人面前更放鬆。
  * 害怕「家」擴大後自己失去位置。
* 她的錯誤表現可能包括：
  * 過度挑剔其他人的照顧方式。
  * 不說需求，只增加家務與守備。
  * 以安全理由阻止別人靠近。
  * 在任務中競爭「誰更有用」。
* 成熟後，她能直接說：
  * 「我嫉妒。」
  * 「我今天想和雪奈姐單獨吃飯。」
  * 「我知道妳不會離開，但我現在還是很不安。」
* 不把病嬌當作不可改變的可愛標籤。

## 3.6 對暴力的態度

* 奏不享受慘叫、混亂與血腥。
* 她喜歡：
  * 控制成立。
  * 對手失去選項。
  * 線網閉合。
  * 一切安靜下來。
* 她可以冷酷處決，也能精準活捉。
* 對她而言，理想暗殺像：
  * 房間裡少了一個人。
  * 沒有多餘聲音。
  * 沒有人知道自己何時失去自由。
* 她的危險不是殘虐，而是對「必要」的判斷可能過於冷硬。

# 4. 形成背景

## 4.1 地下教育造成的價值觀

* 奏在正常學校生活以前，便已接受高度功能導向的訓練。
* 她很早學會：
  * 安靜能活下來。
  * 完成任務才有資源。
  * 不疼、不哭、不求助會被視為優秀。
  * 能替別人處理麻煩，才不會被丟下。
* 因此她將自我價值建立在：
  * 有用。
  * 準確。
  * 不添麻煩。
  * 永遠先看見他人的需要。
* 她不是天生只想服侍別人。
* 這是生存方式被內化成愛的語言。

## 4.2 與雪奈的關係形成

* 相識的具體任務與時間可由前傳時間線進一步鎖定。
* 本檔固定以下結果：
  * 雪奈是第一批能看穿奏「沒事」其實代表受傷的人。
  * 雪奈不只在奏有用時留下她。
  * 雪奈允許奏照顧，也會強行讓奏休息、吃飯或接受治療。
  * 奏第一次體驗到：
    > 自己可以因為是奏，而不是因為完成得很好，被某個人期待回家。
* 這使雪奈成為她最深的依戀對象。
* 也使奏容易把所有人生意義重新集中到雪奈身上。
* 正篇成長不是削弱這段感情，而是讓它不再承擔奏全部的自我價值。

## 4.3 痛覺異常

* 奏不是完全沒有痛覺。
* 她具有：
  * 異常高痛閾。
  * 長期訓練形成的痛覺解離。
  * 面對可控傷害時自動降低主觀痛感的能力。
* 常規割傷、挫傷、淺層燙傷與部分骨折可能只被她感知為：
  * 壓力。
  * 熱。
  * 動作阻礙。
  * 遠處的鈍感。
* 重大結構風險會突破抑制：
  * 內臟傷。
  * 大血管。
  * 缺氧。
  * 關節完全失穩。
  * 神經損傷。
* 所謂「安全閥」不是超自然開關，而是：
  * 身體危險訊號。
  * 功能檢查。
  * 與重要之人的依附反應。
 共同將疼痛重新推回意識。

## 4.4 痛覺異常的代價

* 容易低估：
  * 出血。
  * 骨裂。
  * 肌腱損傷。
  * 燙傷。
  * 疲勞。
* 她建立固定自我檢查：
  * 關節活動。
  * 肌力。
  * 皮膚溫度。
  * 血跡。
  * 呼吸。
* 戰後必須接受他人檢查。
* 她最討厭的不是疼痛，而是被發現自己需要照顧。
* 不得將痛覺屏蔽寫成受傷無代價或越受傷越強。

# 5. 校園生活

## 5.1 學業

* 嚴重偏科。
* 擅長：
  * 體育。
  * 家政。
  * 生物與實作型科目。
  * 需要觀察、步驟與手部操作的內容。
* 不擅長：
  * 數學抽象符號。
  * 古文。
  * 缺少背景知識的社會科。
  * 需要自由聯想的長篇作文。
* 她不是笨。
* 問題來自：
  * 教育斷層。
  * 對抽象學習缺乏耐心。
  * 習慣將資訊轉成任務用途。
* 雪奈可以教她，但不能讓每次課業劇情都變成「學渣向天才求救」。
* 她也能：
  * 自己整理。
  * 向同學詢問。
  * 接受琉璃以結構化方法輔導。
  * 被潔西卡用競爭激起學習意志。

## 5.2 班級位置

* 同學常認為她是：
  * 酷。
  * 害羞。
  * 很可靠。
  * 可能有點天然。
* 體育社團會招攬她。
* 她仍選擇歸宅部，原因不只為雪奈：
  * 任務時間不穩定。
  * 想保留料理與個人時間。
  * 不習慣固定團體。
* 她可以偶爾協助：
  * 家政課。
  * 運動會。
  * 文化祭餐飲。
  * 校園安全與器材整理。
* 她需要形成至少一小群不知地下身份、仍把她當普通同學的人。
* 這些同學不必成為核心角色，但能證明她在高一B班有自己的生活。

## 5.3 校園弱點

* 不擅長閒聊。
* 無法理解同學為何為偶像、流行話題或小考排名焦慮。
* 對「大家一起浪費時間」缺乏耐性。
* 容易在同學受欺負時採用過度有效的處理方法。
* 不得讓她真的往鞋櫃放死老鼠或以死亡威脅處理普通校園騷擾。
* 她可以：
  * 留下令人發冷但不違法的警告。
  * 蒐集證據。
  * 讓霸凌者在老師面前自行暴露。
  * 以普通學生手段保護人。
* 高中生活的重要課題是學會：
  * 不是所有問題都需要暗殺者答案。

# 6. 能力與裝備

## 6.1 戰力定位

* 銜尾蛇S級殺手。
* 對一般武裝人員與普通殺手具有壓倒性控制力。
* 在室內、複雜通道與可預先佈線的環境尤其危險。
* 對頂級S級殺手：
  * 可以形成真正高水準對抗。
  * 她的優勢是空間控制、耐心與陷阱。
* 不以正面火力與雪奈、潔西卡競爭。
* 不是因為弱，而是她的勝利條件是讓對手根本無法建立正面交戰。

## 6.2 戰鬥哲學

> **控制先於殺戮。**

基本流程：

1. 讀取空間。
2. 建立錨點與退路。
3. 限制感知、武器與移動。
4. 迫使目標進入預設區域。
5. 束縛、失能、活捉或處決。
6. 回收線體與痕跡。

她不追求：

* 最大爆炸。
* 最多傷亡。
* 華麗正面對決。

她追求：

* 最少變數。
* 最低聲量。
* 對手最晚意識到失敗。
* 自己與重要之人不被接觸。

# 7. 主武器「影縛」

## 7.1 系統結構

「影縛」是一套多線匣智慧線體系統，不是一根同時擁有所有性能的萬能線。

### 承重索

* 材質較粗，具高韌性與動態負荷能力。
* 用於：
  * 攀附。
  * 擺盪。
  * 升降。
  * 撤離。
  * 固定門窗與大型物件。
* 不能作高效率切割。
* 承重取決於錨點與角度，不能無條件吊起數噸。

### 束縛索

* 柔韌、高摩擦、具有限形變能力。
* 用於：
  * 手腕。
  * 腳踝。
  * 武器。
  * 關節。
  * 活捉。
* 可施加精密張力，不以直接切斷人體為主要用途。
* 面對高熱、銳利邊緣與高速旋轉目標較脆弱。

### 切割絲

* 極細、高張力。
* 用於：
  * 無聲陷阱。
  * 人體與軟甲。
  * 電纜、管線。
  * 輕中型裝甲接縫。
* 需要：
  * 穩定錨點。
  * 足夠張力。
  * 正確入射角。
* 不能承受擺盪或拖曳。
* 不能像光劍一樣隨手切開所有高強度合金。

## 7.2 控制介面

* 指尖導電環與微型觸覺回饋。
* 腰背線匣。
* 腕部張力監測。
* 貓耳耳機提供：
  * 回音。
  * 錨點狀態。
  * 細微振動與斷線警報。
* 常態可精密控制：
  * 四股主要線。
  * 兩股低複雜度輔助線。
* 超過此數量仍可部署固定陷阱，但不能全部即時微操。
* 線體控制需要注意力；同時近身纏鬥、受傷或感官干擾會降低精度。

## 7.3 有效距離

* 即時精密操控有效半徑約20公尺。
* 預設固定陷阱可延伸更遠，但需要事前佈置。
* 超過有效距離後：
  * 張力回饋下降。
  * 延遲增加。
  * 更容易被環境物干擾。
* 開放場地、無錨點地形與強風會顯著削弱影縛優勢。

## 7.4 「不可接觸」領域

* 奏最理想的戰場是讓敵人從未碰到她。
* 這不是絕對屏障。
* 成立條件：
  * 有足夠錨點。
  * 有時間或空間佈線。
  * 感測未被完全壓制。
  * 敵人速度、範圍火力與材質未直接克制線體。
* 面對：
  * 大範圍爆炸。
  * 火焰。
  * 無錨點開闊地。
  * 高速旋轉體。
  * 強電磁／高熱切割。
  * 全向感測。
  她必須改變打法。

# 12. 人際關係

# 13. 長期成長線

## 13.1 第一階段：有用才安全

* 為雪奈安排所有生活。
* 對其他人進入家庭高度警戒。
* 不說嫉妒。
* 受傷仍繼續工作。
* 在校園保持最低社交。

## 13.2 第二階段：照顧開始失控

* 因畢業、多人關係或任務分工感到位置不穩。
* 增加家務與警戒。
* 與潔西卡、琉璃或其他人衝突。
* 被迫承認：
  * 她不是只在保護雪奈。
  * 她也在控制自己不被取代的恐懼。

## 13.3 第三階段：學會被照顧

* 接受別人替她做飯、換藥或完成任務。
* 在不嚴重時主動說「我累了」。
* 讓同學進入自己的生活。
* 在雪奈不在場時仍參加活動。
* 允許安全屋出現屬於自己的：
  * 喜好。
  * 朋友。
  * 植物。
  * 食譜。
  * 不以待命為目的的物品。

## 13.4 第四階段：以選擇而非功能留下

* 照顧仍然是她的愛語，但不再是唯一語言。
* 能表達：
  * 想要。
  * 拒絕。
  * 嫉妒。
  * 害怕。
  * 不同意。
* 能接受雪奈畢業、工作、與其他人親密，而不把變化等同遺棄。
* 對自己的未來形成選項：
  * 繼續作為銜尾蛇殺手。
  * 轉向情報、保護與活捉。
  * 深入料理。
  * 建立自己的安全屋與生活。
* 成長不是離開雪奈，而是終於能以完整的奏站在雪奈身邊。

# 15. AI寫作協議

## 15.1 場景生成邏輯

## 15.2 人格寫作規則

* 寡言不等於沒有內在活動。
* 關心應透過具體記憶與行動。
* 不要每句都用病嬌、狂信徒或賢妻標籤。
* 她可以生氣、拒絕雪奈與做出自己的判斷。
* 她的料理不能只是投餵笑點。
* 她可以不擅長課業，但不能被寫成全面愚笨。
* 她會嫉妒，但不是因此必然傷害其他人。
* 她的控制欲必須能被指出、討論與修正。
* 允許奏真正放鬆，而不是永遠找家務做。

## 15.3 戰鬥寫作規則

* 先描寫空間與錨點，再描寫線網結果。
* 線體不應無條件穿過一切。
* 區分：
  * 承重。
  * 束縛。
  * 切割。
* 操控數量與注意力必須有限。
* 她的強大來自：
  * 預先控制。
  * 精密張力。
  * 重心與關節。
  * 對手不知道哪一步已經踩進網裡。
* 不要逼她用槍解決問題。
* 她可以獨立主導高難度任務。
* 她不是只能站在雪奈後方保護側翼。
* 遇到克制環境時，讓她：
  * 改用柔術。
  * 投針。
  * 煙霧。
  * 移動錨點。
  * 撤退與重新佈置。
* 不以突然忘記陷阱與戰術製造危機。

## 15.4 關係寫作規則

* 奏與雪奈的關係必須有雙向照顧。
* 雪奈不能只享受被服務。
* 奏不能以愛為理由取得雪奈的行程、物品與身體管理權。
* 當前階段不描寫性關係或色情化未成年奏。
* 奏與琉璃、潔西卡、小夜、夏音必須建立不經雪奈中介的關係。
* 不把所有衝突簡化成爭寵。
* 奏可以需要獨處，也可以主動找普通同學。
* 高三畢業線應處理被留下的焦慮，但不製造必然拋棄。

## 15.5 絕對禁忌

* 不得把奏寫成只為雪奈存在。
* 不得將「生存意義是守護雪奈」作為永遠不變的健康終態。
* 不得把病嬌當作無需反思的純萌屬性。
* 不得讓她以普通校園騷擾為由殺人、放死老鼠或實施嚴重暴力。
* 不得把她寫成沒有普通同齡生活需求。
* 不得弱化她的S級殺手實力。
* 不得把S級實力寫成線體無限、無視錨點與材質。
* 不得讓一根影縛同時無限承重、束縛與切割。
* 不得讓她無條件吊起數噸或切開所有高強度合金。
* 不得把柔術寫成無視質量的魔法。
* 不得把痛覺屏蔽寫成不受傷、無需醫療或戰力增幅。
* 不得突然取消槍械弱點。
* 不得把她寫成全面學習障礙或智力不足。
* 不得把家務能力等同成熟人格。
* 不得色情化15歲奏的身體、戰鬥服、痛覺、傷勢或依戀。
* 不得讓雪奈或任何成年人以親密關係取得對奏的身體與人生控制權。
* 不得讓奏永遠隱瞞需求且不承受關係後果。
* 不得把成長寫成必須離開雪奈或不再照顧任何人。

# 16. 角色核心色彩

* **她是控制者，不是控制狂的漫畫符號。**
  * 她擅長讓戰場進入秩序，也必須學會親密關係不能用線網收束。
* **她真的喜歡照顧人。**
  * 問題不是照顧本身，而是曾把照顧當成自己被留下的資格。
* **她很強。**
  * S級不是雪奈身邊的裝飾；她能獨立完成潛入、活捉、暗殺與區域封鎖。
* **她也只有十五歲。**
  * 需要同學、考試、失敗、任性、被照顧與不具任務價值的時間。
* **她的沉默有很多含義。**
  * 可以是專注、害羞、嫉妒、恐懼、憤怒或真正放鬆，不能一律解讀成冷漠。
* **她不必從黑貓變成普通女孩。**
  * 成長是讓殺手、學生、料理者、家人與少女全部成為奏本人。
* **最終命題**：

> 奏最初想成為雪奈永遠無法替換的影子；真正成熟後，她不再需要證明自己不可替代——因為她知道家人不是依靠功能排序，而她也終於擁有即使離開任何人的視線，仍然會繼續生長的人生。

# 17. 一句話壓縮版

> **十五歲的貓屋敷奏，是就讀神山高中一年B班、以三類智慧線體「影縛」與柔術建立絕對空間控制的銜尾蛇S級殺手「黑貓」；她寡言、精密、廚藝高明，能在敵人發現戰鬥以前收走全部選擇，卻長期將被需要誤認為被愛，把照顧雪奈、維持家庭與不添麻煩當成自己留下的資格——她的成長不是不再愛雪奈，而是學會直接說出嫉妒與需要、接受自己被照顧，並明白即使今天沒有替任何人做飯、守夜或殺敵，貓屋敷奏仍然值得有人為她留燈。**
