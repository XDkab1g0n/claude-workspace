# 散席

宴會廳裡只剩一盞水晶燈還亮著。

雪奈推開員工通道的門時，踩到了一顆葡萄。鞋底微微一滑，她低頭看了看，順勢把腳在地毯邊緣蹭乾淨。

電梯前的四個男人都轉過頭來。

其中一人抱著銀灰色公事箱，另一隻手還在反覆按上行鍵。兩名穿西裝的護衛分站左右，靠近吧檯的那個已經掀開外套。最後一人沒有穿西裝。黑色裝甲從肩頸一路包到小腿，左臂外側覆著一面厚盾；他朝她轉身時，腳下的木地板響了一聲。

雪奈的視線越過他，落在公事箱上。

「箱子留下。你們搭你們的。」

抱箱子的男人怔了半秒，伸手去拉重裝護衛的背甲。

「攔住她。」

最近的西裝護衛拔出手槍。

雪奈向前跨了一步，左手壓住他尚未抬平的槍管，鞋跟從側面短短一撞，撞進膝彎。他跪下去時，她已繞到他肩後，握著他的持槍手往桌沿一磕。

槍掉進盛著融冰的銀桶裡。

吧檯邊傳來衣料撕扯般的拉栓聲。

她鬆開手，矮身退到圓桌另一側。霰彈隨即掃過她剛才站的位置，桌上的香檳杯一排炸開，濕冷的酒液潑上她後頸。

「……還有半瓶耶。」

第二槍沒能接上。

雪奈勾起身旁餐椅的橫檔，把椅子踢向槍口。護衛偏開肩，槍托砸碎了迎面翻來的椅背；木片還在往下掉，她已從桌邊切進去，一腳蹬上他的胸口。

男人背撞吧檯，整排酒瓶在他身後跳了一下。他張著嘴滑坐下去，霰彈槍橫在腿上，一時竟沒掉。

雪奈剛收回膝蓋，桌面便從右側朝她翻了過來。

她向後仰身，鼻尖幾乎擦過桌沿。白色斗篷揚起，瓷盤和餐刀從她眼前飛過。重裝護衛直接推著桌子逼進來，左臂厚盾藏在桌面後，沒給她從正面落腳的空間。

雪奈退出桌沿，右腳剛沾地便蹬向側方。桌子擦著她砸上吧檯，碎成兩半。

她落在護衛右側，鞋尖掠過地面，掃向他腳踝後方。

那條腿只挪了半寸。

裝甲腳跟咬住木板，膝側的支架發出一聲低沉的嗡鳴。他借著這一下站穩，右手已抓向她的肩。

雪奈抬眼。

那隻手抓空了。她貼著他的手臂轉進內側，左腳落到他兩腳之間，腰髖擰回，右膝撞在胸甲下緣。

沉悶的一響，把頭頂水晶燈的細碎碰撞聲都壓了下去。

護衛雙腳離地，背部撞上後方餐桌，連人帶桌翻倒。餐巾、殘花和銀餐具往四面滑開。他落地後立刻抬起盾，遮住頸部，另一隻手撐地起身。

還能起來。

雪奈甩掉指尖上的酒，嘴角稍稍彎了一下。

電梯上的數字由二十一跳成二十二。

抱箱子的男人又按了一次按鈕。

「你快點！」

重裝護衛沒有理他。他站起時，胸甲下方多了一道凹折，呼吸聲從面罩裡粗重地漏出來，但這次不再向前猛衝。他把盾壓低，側身擋在雪奈與電梯之間。

雪奈朝左晃了半步。

盾沒跟著走。他盯的是她的腰。

她笑意更深，鞋底一蹬，真的從左側切了進去。

厚盾斜著攔下來。她收住原本要踏出的腳，掌心在盾上輕輕一搭，身體借力翻過他的左肩。銀色雙馬尾甩出一道弧，鞋尖已掃向面罩側邊。

護衛猛地偏頭，肩甲向上頂。

這一腳擦過耳側裝甲，留下長長的白痕。他沒有追她的腿，盾緣卻向後一壓，把尚未落下的白色衣襬釘在吧檯斷口上。

布料驟然繃緊。

雪奈半空中的身體被扯得一偏，右手先摸到了領口。她縮肩，抽臂，整件敞開的斗篷留在盾下，人已從衣服裡滑出去。

重拳砸穿了她頭側的酒櫃。

玻璃落下來時，她正蹲在他身旁，銀髮掃過濺滿酒液的地板。一塊碎片劃開上臂，涼意之後才有一線刺痛。

她看了一眼掛在盾邊的衣服。

「喂，那件——」

護衛抬膝，頂向她胸口。

雪奈側身讓過，手掌順著他膝甲往外一推。他的腳落進滿地碎玻璃，仍穩穩踩住；盾也收了回來，白色布料在金屬斷口上撕出刺耳的一聲。

她把後半句吞了回去。

耳機裡，導航的聲音很平靜。

「二十四樓。」

雪奈餘光掃過電梯。抱箱子的男人幾乎貼在門上，空出來的手正在鬆領帶。

她朝他走了一步。

護衛橫移，重新堵住去路。盾在前，右拳收在肋側，受損的胸腹藏得很嚴。

雪奈沒有再繞。

她左腳踩上地毯外露出的木地板，鞋底短促地喀了一聲。護衛看見她沉下重心，盾緣立刻往地面壓，裝甲右腳也向後撤去。

還沒踩實。

她的右腿已經踹了出去。

鞋底正中盾面。那聲巨響近得像在她胸腔裡炸開，支撐腳下的木板同時迸裂。盾先凹下去，緊接著撞回護衛自己的胸口，他整個人倒飛出去，腳跟犁過地面，又完全離地。

抱箱子的男人尖叫著撲向旁邊。

黑色裝甲撞上電梯門，兩扇金屬門板向內深陷，門框上方噴出一小串火花。轎廂抵達的提示音在變形的門後響起，清清脆脆。

護衛跪落下來，盾垂在身側。他想撐住地面，左臂卻沒能伸直，肩膀一沉，側倒在門前。

雪奈落下右腳。

左腳掌有些發麻。她把重量移到另一邊，抬了抬鞋跟，鞋側排出的熱氣捲起一小撮地毯絨毛。

廳裡剩下酒液滴落的聲音。

抱箱子的男人坐在地上，背抵牆角，看著她走近。他把箱子往懷裡收了一下，又慢慢推了出來。

「我不知道他們拿這個做什麼。」

雪奈蹲下，轉過箱側，核對鎖扣旁那道月牙形刮痕。

「那就別替他們抱那麼緊。」

她提起箱子。他的手還搭在提把上，聞言趕緊鬆開。

走回吧檯時，先前被她打跪的護衛動了動，目光落向地上的霰彈槍。雪奈用鞋尖把槍撥進吧檯底下，朝他看了一眼。

他把手放回膝上。

她從破木頭裡抽出斗篷，抖開。右側衣襬裂了一大段，沾著紅酒，袖子倒還完整。

「能補嗎？」

「能。妳先別穿，背上有玻璃。」

雪奈把衣服翻過來，細小碎片嘩啦啦落了一地。她摸到領口內側，確認沒有殘渣，才將它搭上沒受傷的肩膀。

員工通道旁停著一輛收餐車，最上層還有半盒獨立包裝的薄荷糖。她拿走一顆，咬開包裝，把糖含進嘴裡。

身後傳來電梯徒勞開門的摩擦聲。

雪奈回頭瞥了一眼。抱箱子的男人已經爬起來，兩手扒住門縫，像是還想把那兩扇凹進去的門掰開。

「樓梯在那邊。」她含著糖，替他指了一下。

然後推開員工通道的門，帶著箱子走了。
