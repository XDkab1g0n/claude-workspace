# 雪奈故事框架｜《請勿觸碰》

本篇要留下的印象：她靠近時很柔軟，碰到人的那一瞬間卻足以致命；而她仍有餘裕，對剛才成功的小惡作劇偷偷高興。

## 定位與依據

- 時期：十八歲高三現在正篇。
- 身份：銀色幽靈，全篇保持同一身份及其裝備。
- 角色正典：`雪奈_現行主設定.md` v17.8.2d。
- 寫法：2026-10-26 正式《雪奈_新版寫作方法學.md》。
- 形式：一篇可獨立完成的中篇；雪奈為主視角，主戰鬥連續展開。
- 本文只提供故事大綱、設定取用與寫作方向，不包含小說正文。
- 以下預展事件、新角色、原型與場地均為本篇創作提案，尚未增訂為既有世界正史。

## 一、故事核心

一名地下贓物仲介，準備在改裝劇院的私人預展中出售偷來的義體穩定器原型。雪奈接下經真希驗證、完成託管的回收委託：完整取回原型，並活捉仲介，以追查同批失竊物的去向。

雪奈先一步潛入，佔了賣方休息室最舒服的位置。待仲介與貨物同時到場，她便開始接收自己的目標。賣方要保住交易，買方要避免人財兩失，受雇鑑定師要帶走自己的技術助理；這場原本與雪奈無關的生意，因她的介入而迅速分裂。

故事的主要懸念是：在不同人同時撤退、反擊、轉移貨物的情況下，她會如何選擇接觸誰、放過誰，又以什麼方式把任務完成得漂亮。戰力差距從第一次交鋒就成立。

她的玩心不是額外拖延任務。她可以在抵達目標的途中順手惡作劇，也可以突然對某個人的漂亮應對感興趣；真正會危及貨物、旁人與任務的威脅，則立即處理。

## 二、人物與場地

### 主要人物

| 人物 | 當下目的 | 必須保留的自主行動 |
|---|---|---|
| 雪奈 | 完整回收原型、活捉仲介，也想享受這次行動 | 自己決定何時暴露、如何分配注意、誰需要被殺死、誰可以離開 |
| 贓物仲介／新角色 | 完成交易；失敗後保住自己與可變現的貨物 | 主動提出交易、試圖換取買方掩護；遭拒後帶貨從後台撤走 |
| 買方護衛長／新角色 | 讓雇主活著離開 | 辨認銀色幽靈後調整任務，撤離雇主而非替賣方死戰；會用自己的判斷回應雪奈的挑釁 |
| 成年女鑑定師／新角色 | 完成專業工作，保住自己與兩名助理 | 主動終止驗貨、帶助理走服務通道；在確認人員通過後降下舞台防火幕，隔開交火區 |
| 真希 | 讓委託完成並守住契約與報酬 | 接受事前簡短聯絡、安排交接；不在場指揮雪奈作戰 |
| 導航員 | 提供雪奈需要的情報與設備支援 | 保持自己的判斷；回報買方撤離及通道狀態，不替雪奈選擇動作 |

賣方護衛是有經驗的私人武裝，保護貨物與雇主是其本來的工作。他們有隊形、撤離預案與真實殺傷力，但不為克制雪奈而存在，也不全部戰鬥到死。

### 場地：改裝劇院的封閉預展廳

這是私人商業場所，不是銜尾蛇中立據點。來賓是少數買家與護衛，另有鑑定人員；沒有需要額外處理的大量公眾。

空間只維持三個清楚區域：

1. **側廳與二樓包廂**：休息沙發、展品目錄、可看見主廳的開口。用來建立慵懶與惡作劇。
2. **主廳及舞台前緣**：驗貨台、看台落差、固定欄杆與通往上層的側梯。用來展現近身壓制與立體變速。
3. **後台與貨梯**：舞台側門、防火幕、固定工作平台和裝卸通道。用來完成貨物回收與活捉。

主廳至後台有舞台正面與側門兩條已知路徑。防火幕只隔開舞台口，不封死人員逃生出口。可承重的固定結構應在首次描寫時建立；布幕、移動布景與裝飾燈具不默認可承受高速拉扯。

## 三、分段大綱與各段寫作指引

### 第一段｜賣方的座位被佔了

**事件**

雪奈已潛入側廳，窩在原本替賣方準備的沙發裡。她等待的是尚未同時到場的仲介與原型；兩者到齊後便動手，不為玩樂憑空延誤。

她把自己的入場座號和賣方席位標示對調，將送來的目錄墊在手肘下，舒服得像真的受邀。仲介循指示走到錯誤位置，才發現有人佔了自己的座位。雪奈先觀察他怎麼處理這件小事，再表明來意。

**段落功能**

讓讀者先喜歡這個有點壞、很會找舒服位置的少女。惡作劇直接作用在當事人的體面上，與這場預展相連。

**寫作方向**

- 慵懶透過身體如何窩住、袖口如何遮住手背、她願不願意起身呈現。
- 保留真實小情緒：她對對方居然照錯誤標示走過去感到好笑，也可能覺得沙發扶手比想像中舒服。
- 讓護衛從她的裝備與外觀逐漸辨認身份。低調潛入階段束起衣擺、關閉光效；此時才自然露出高雙馬尾與白紫剪影。

**必讀設定**

主設定第2、3、4、5.3、6、13章；方法學第1–14條與8.4。若保留真希的事前聯絡，另讀完整`角色_黑岩真希.md`與銜尾蛇委託制度。

### 第二段｜她第一次碰到人

**事件**

賣方貼身護衛試圖控制她，另一名護衛同步準備射擊。雪奈在起身的過程中穿入兩人的動作間隙，以近身腿技結束第一人的攻勢，再處理第二人的射擊威脅。

第一場交鋒就留下不可逆結果：其中一名持續施加致命威脅的護衛死亡，另一人失去持械與追擊能力。不要把這段改成全員摔倒後隨即爬起。

**段落功能**

把前一段的柔軟姿態直接接上真實殺傷力，建立全篇可信的危險尺度。

**寫作方向**

- 選一個接觸瞬間提高解析度：她貼近時的輕、關節收放的流暢，以及命中後完全不相稱的沉重結果。
- 重點是短促、準確、完成後迅速回到鬆弛。她不需要蓄力宣告，也不需要換成另一種聲線。
- 第一名護衛的倒下須改變第二人的射線、站位或退路，使兩次處置屬於同一條事件。
- 幽默留在此前的互動；這一瞬間給死亡本身足夠重量。

**必讀設定**

主設定2.4–2.6、3.1、8–10、13章；方法學8.2、8.3、8.5。

### 第三段｜同一個房間，開始往不同方向逃

**事件**

買方護衛長認出銀色幽靈，立即護送雇主撤離。他清楚表明不參與賣方的爭端，雪奈留出離開的通道。賣方試圖以降價及原型換取掩護，護衛長仍拒絕，帶著自己的人走。

與此同時，賣方主力一面射擊、一面向後台移動貨物；鑑定師帶助理往另一條服務通道撤離。雪奈跨越主廳與上層落差，攔截真正威脅任務的人。

**段落功能**

展現她能支配一場多人交戰：有人得以完整撤離，有人的下一次動作卻來不及成立。名號已經改變專業人士的決策，實際速度則繼續證明那個決策正確。

**寫作方向**

- 這是主要戰鬥篇幅。各方同時行動，寫作時選取一條讀者可跟隨的雪奈路徑，不逐人介紹後輪流擊倒。
- 慢、快與突然停留交錯：她可以輕巧地停在某個窄支點上看清新局面，隨即在敵人把槍口移過來以前改變高度與距離。
- 槍械處理跨距離威脅，腿技主導接近後的交鋒；極光只在需要新支點或回收物件時使用。
- 可安排一個戰鬥中的惡作劇：短暫交錯時，她順走某名護衛的賣方通行牌，借此先一步通過後台門。他追到門前才發現卡不在身上。動作與入場玩笑呼應，但不演成連續道具喜劇。
- 一次真正投入力量的命中須留下明確破壞與失能；其餘處置用時間差、位置和短促結果呈現，避免每擊同等音量。

**必讀設定**

主設定2.3–2.6、4.3、6、8–10、13、15、16章；方法學第七章與8.2–8.5。

### 第四段｜別人關了一扇門，她換一條路

**事件**

鑑定師確認助理離開後，操作防火幕隔開交火區。這是她保護自己人的決定。幕落下時，雪奈原本從主廳直切後台的路徑消失，仲介則繼續向貨梯撤退。

雪奈沒有預知這個決定。她當場轉向已建立的側門與固定工作平台，利用高度差追上。仲介仍試圖把貨箱交給最後的護衛帶走，自己往另一方向跑；雪奈改變處置順序，先穩住貨物，再截住人。

**段落功能**

讓她真正即興一次，並集中呈現柔軟、靈巧與輕盈。局勢改變了，她卻仍能自在選擇。

**寫作方向**

- 保留一段有起點、接觸與落點的連續立體動作：固定支點出發、收身穿過平台空隙、轉髖改向、落腳截斷撤離。
- 承重的極光須先完成擺盪與卸載，才能另行牽引貨箱；不能同一條線同時高能切割又承受身體。
- 貨箱有防震運輸外殼，不是隨手拋擲也不會壞的魔法物件。雪奈的精度表現在穩定回收與避開撞擊。
- 衣擺與銀髮的延遲動態挑關鍵轉向描寫。身體已改向，衣料仍帶出上一段運動，讓快與柔軟同時可見。
- 仲介分開人貨的行動確實迫使她改變順序，但不能因此讓他突然跑得比她快。

**必讀設定**

主設定2.4–2.6、6.2–6.4、8.3、9、13.2–13.6、16、19.3；方法學7.4、8.2、8.3。

### 第五段｜她決定到此為止

**事件**

最後一名賣方護衛試圖掩護仲介逃走。雪奈完成一次極短的決定性交鋒，徹底解除他的戰鬥能力，接著在仲介真正離開裝卸區前將其制伏，保持活口。

仲介被留下，是因為他是活捉目標。已放下武器的人不再被追擊，仍在製造致命威脅的人則可能當場死亡。這些不同結果，都由雪奈清楚選擇。

**段落功能**

收回節奏，讓銀色幽靈的壓制力落在結果上：她完整取得人與物，而且沒有任何人能迫使她照自己的節拍完成這件事。

**寫作方向**

- 收尾可以比前面的立體戰鬥簡潔。保留有效的一次命中，迅速完成活捉。
- 交鋒後用仍在運動的環境顯示時間差，例如尚未合攏的貨梯門或仍在滑動的空推車；開戰前須先交代其狀態。
- 雪奈收束玩心，來自任務進入需要完成的當口，不必改成冰冷機器。
- 本篇不需要彗星；末段尺度由普通私人武裝與局部強化護衛決定。

**必讀設定**

主設定3.1、6、8.2、8.4、8.5、9、13、16章；方法學第2、5、9條及8.2。

### 第六段｜驗貨比打架慢

**事件**

現場安全後，雪奈讓鑑定師自行決定是否留下完成原型確認；對方同意做完已收費的專業工作，要求保留完整檢查時間。雪奈只好等。

她把檢查台旁的椅子勾過來，托著下巴看對方工作；對精密操作有真正興趣，又明顯嫌流程慢。她把先前順走的通行牌放到被制伏的仲介面前，連同原先對調的席位牌一起還給他。

原型確認、活口交接安排完成。結尾停在現場，不另接回家與甜點場景。

**段落功能**

讓十八歲少女的日常質地從剛才那個人身上自然延續。她能在幾個呼吸間處理武裝隊伍，卻願意等別人把真正需要時間的事做好。

**寫作方向**

- 柔軟也可以是克制自己的催促、把空間留給專業人士；不用陌生人突然親近她來表現溫柔。
- 她對機械和技術的好奇是真實喜好，不能只拿原型當沒有內容的任務箱。
- 死傷仍然留在現場和善後工作裡，喜劇只落在雪奈與仍活著的仲介之間。
- 真希若出聲，只處理交接與契約，不替讀者總結雪奈多麼強大。

**必讀設定**

主設定3.2–3.5、4、6.1、15、19.1；完整`角色_黑岩真希.md`；方法學7.5、8.4、8.5。

## 四、整篇寫作方向

| 指定質感 | 具體落點 | 寫作重點 |
|---|---|---|
| 致命壓制力 | 第一次接觸即產生死亡；後續讓敵方射擊、撤運與追擊相繼失去效果 | 命中有不可逆後果，活捉與放行同樣出於她的選擇 |
| 慵懶 | 佔沙發、少做無用動作、等驗貨時重新坐下 | 放鬆是真實狀態；感知與判斷仍有餘裕 |
| 惡作劇 | 對調席位、順走通行牌、最後歸還 | 來自當場的人際互動；完成工作時順手得意，不延誤重要處置 |
| 柔軟 | 接觸前的貼近、肩髖收放、命中後的鬆開，以及對旁人的精細收力 | 靜態與動態皆可見，具體描述動作質地 |
| 靈巧 | 改變處置順序、接續回收物件、避開交疊射線 | 讀者看得見她如何臨時改變選擇 |
| 輕盈 | 窄支點、短暫停留、衣髮延遲、落點精確 | 與敵人失衡、貨物重量、沉重命中並置，仍維持真實接觸 |

全文以雪奈的感知、偏好與即時決策為中心。若切到護衛長視角，只用短段交代撤離決策及其資訊，隨後回到雪奈，避免她成為別人眼中的展示品。

美感可以華麗，但描寫應附著在正在發生的事上：她為何貼近、如何收腿、何時放慢、哪一處真的命中。對台詞保留彈性，不先排好每一擊的俏皮話。中長段落承擔連續動作，短句留給真正的接觸、死亡與局面改變。

### 正文前後的驗收

- 起稿前讀取當時最近3–5篇相關作品，核對真實的衝突、動作、台詞與收束重複；本次框架設計依據的是已載入方法學內的重複案例與對話回饋，未宣稱已逐篇讀完近期小說全文。
- 確認買方撤離、鑑定師護送助理、仲介人貨分流皆依各自目的發生。
- 確認雪奈沒有因為要延長戰鬥而忘記任務或放任已知危險。
- 確認每次重要命中都有後果，同一人不在重傷後無影響地繼續作戰。
- 確認轉向、落地與極光使用都有成立的支點；裝備不新增能力。
- 確認銀色幽靈服裝維持白／黑／紫，未混入零夜的橙色、白霰、零點或軍用配套。
- 確認玩心與致命性在同一個連續人格中可見，沒有用冷酷／可愛開關代替人物。
- 最後先讀故事是否有趣、她是否令人想繼續看，再修正語句；招式可改，人物目的與因果必須留住。
