# 零夜｜風的另一邊

風洞裡的雨是橫著下的。

細白的水霧從試驗段上方數百個噴嘴吐出，還沒來得及向地面落下一寸，就被二百二十公里的時速扯成筆直的銀線。那些銀線在藍色測量光裡層層交疊，顯出平時肉眼看不見的亂流、渦旋與風切。六十公尺高的鋼製大廳像一條被剖開的暴風雨雲；而雲的正中央，有個女人正在飛。

葉山透子背後的兩片複合翼幾乎與肩同高，向外張開四公尺。她的身體被黑色飛行甲牢牢包覆，翼尖掠過一道向上翻捲的氣流時，整個人跟著傾斜、翻身、拔高，動作利落得如同拿筆在空氣裡寫字。右翼下方掛著一只拳頭大小的白色圓筒，紅燈每隔三秒閃一次。

她今年二十八歲，離開軍方試飛隊時帶走了一身傷，也帶走了某些人以為可以永遠藏在測試報告底下的本事。今夜她從承包商的保險庫裡偷出一枚離線火控母鑰，打算將它賣給海上等候的接應者；沒想到半途殺出另一批想白拿貨物的武裝傭兵。

四十二公尺外，那些追兵已經第三次失去落腳處。

「停止射擊！」有人在下方的維修平台大喊。那名穿灰甲的傭兵抱著一條斷裂的安全索，半個身體吊在護欄之外，「你們想把風道射穿嗎！」

透子連頭都沒有回。她將左翼向內折了一小截，借風壓側滑，袖口彈出一把緊湊的自動手槍。三發子彈沿平台邊緣排開，將兩名正準備抬槍的追兵逼回承重柱後；接著她收槍，順著一道上升氣流悠然掠過他們頭頂。

「你們追了我二十公里，」她的聲音在公用頻道裡響起，帶著笑，「到現在還沒學會別站在風口？」

整座風洞忽然響起另一個聲音。

「借過一下。」

不是通訊器。

是從大廳頂部、那道負責固定風速探針的狹窄檢修樑上傳來的。透子仰起頭，先看見兩束被氣流扯得筆直的銀色長髮，才看見一雙短得有些不像話的白色戰術短褲，以及它們下面被黑色壓力層包裹的纖細雙腿。

少女正蹲在橫樑邊緣，一手扶著橘燄風鏡，另一手捏著一截被風吹得啪啪作響的薄紙。

「你們這裡寫著『請勿從上方進入』。」她把那張皺巴巴的安全告示舉起來，語氣不太高興，「但我從下面走了七分鐘，都沒找到門耶。」

透子的瞳孔縮了一下。

銀髮。白鋼短夾克，敞開的前襟下是一身黑色高領作戰服。白色短褲，大腿側的電漿橙腿環，靴踝上低低流動的橙光。即使隔著滿場霧流，那個過分嬌小的剪影也不可能認錯。

「零夜。」

「欸，妳認識我呀。」雪奈順手把告示貼回橫樑，沒有貼牢，紙片立刻被風撕走。「啊，糟糕。」

她追著紙片看了一眼，像是真的有點可惜。風一轉，那張紙被捲向遠處的主風道，轉眼就沒了影子。

透子沒有浪費這一眼。左翼猛地翻起，飛行甲背後的短促推進把她送進一條高速主流；四公尺寬的機翼在空中立成鋒利的十字，刃狀前緣正對橫樑上的少女。

她沒打算正面撞人。只要逼零夜離開那根金屬樑，在這片沒有可靠落腳點、風速處處不同的空間裡，透子就能把距離重新拉開。

雪奈卻還在看那張紙。

「算了，等一下再——」

當翼尖切過橫樑的位置，她已經不在上面。透子聽見一聲極短的金屬輕響，像有人用指節彈了一下玻璃杯；緊接著，自己的左翼忽然往下沉了半寸。

雪奈站在那上面。

不是吊著，也不是攀住翼根。她的一隻戰鬥靴正穩穩踩在高速飛行的翼面上，右手扶住透子肩頭的裝甲，白霰的短袖被風壓向後撐開，兩條銀色雙馬尾在身後翻成幾近水平的長弧。

「這個好漂亮。」少女低頭望著足下的翼面，眼睛忽然亮起來。「妳自己做的？」

「這副翼通過了七百一十六次試飛。」透子把聲音從齒縫裡擠出來，「沒有人試過在上面踩鞋印！」

「喔。」雪奈低頭看了一眼腳底，十分體貼地把重心往後移了一點。「那我輕一點。」

「我叫妳下去！」

透子右肩向前一沉，整副飛行甲沿長軸驟然翻滾。這不是慌亂，而是她練過千百次的脫附動作：人若站在左翼上，旋轉會先把他甩離翼面，再由主流直接捲走。

雪奈果然被甩了出去。

只是透子旋過半圈才發現，少女鬆手前順便在她肩甲上輕輕一按，身體已經借力飛向上方，靴踝兩道電漿橙推力細小得幾乎看不見。她在半空收腿，像一隻折起翅膀的白鳥，輕巧地落回三公尺外另一根檢修樑。

「欸，真的會翻耶。」雪奈笑了，「可以再一次嗎？」

透子咬住了牙。

「妳以為這是遊樂設施？」

「我還沒買票呀。」

下方忽然響起連續槍聲。

兩名傭兵趁著她們交手，已沿檢修梯爬上第二層。他們的槍口沒有追向零夜，而是鎖住透子的下一條上升氣流。透子注意到時，第一串曳光彈已經把她前方的霧切成一道灼亮的斜線。

她收翼、俯衝，貼著平台底面閃過彈幕。下一瞬，一隻銀白色的手套從上方垂下，在她翼梢旁邊打了個響指。

「左邊。」

透子本能地向右偏轉。

一道銳利的白光從她原本的位置穿過，打碎了平台邊緣的自動炮座。雪奈倒懸在頭頂的梁架下，右手白夜的槍口尚有一縷熱氣，左手已握著極光投出的細銀線。她輕輕一拉，整個人便沿著橫梁飛掠而去，白霰敞開的前襟和高雙馬尾一前一後掠過透子的視野。

「喂！」透子喊，「那是追我的人！」

「我知道啊。」雪奈沒有回頭，「我今天要帶走的是妳，不是妳的屍體。」

透子忽然不知道該怎麼接話。

『主人，東側出口距離兩百一十四公尺。』樞紐裡的導航員以冷靜的女聲報出數據，『目標翼下掛載物確認為離線火控母鑰。風洞內另有六名非法武裝者，正在同時追逐您與葉山透子。』

「六個？」雪奈問。

『現在是四個。您剛才打壞的炮座屬於自動防禦系統，不計入人數。』

「喔，好煩。還以為可以快點回去。」

『您今晚本來就沒有別的行程。』

「有呀。我要洗頭。」

導航員安靜了零點二秒。

『我開始理解您對此處風速的不滿了。』

雪奈抬手摸了摸被吹得亂七八糟的瀏海，表情突然更嫌棄了一點。

透子聽不見她們的私語。她只看見銀髮少女側著身，在下方密集而刺眼的火線間穿行。零點的鞋底偶爾擦過檢修梁或金屬護網，一觸即走，身體早已折向下一個位置，銀色長髮才在原處劃出滯後的波浪。數發射向她的子彈撞碎樑架上層的水霧，她連肩膀都沒沾濕。

這不是透子想像中的飛行。

她自己必須閱讀風，順應風，從氣流微小的震顫裡猜出下一個上升和下降的間隙。那個女孩卻像在和風吵架：主流把她往左帶，她轉身借過那道力，從右側出去；翼尖掀起的亂流剛把她往下扯，下一道橙光便讓她擦著樑架重新升高。每次都只借一點，每次又都不肯完全順從，彷彿整座風洞對她而言不是一條河，而是一千條可以挑選的路。

「真討厭。」透子低低說了一句。

下一秒，她看見雪奈落在自己前方六公尺的空中。

空的。

四面都沒有支點。

透子猛地展開雙翼，背部推進器連續噴出兩道淡藍尾焰。她知道那名少女的腳很快、也很重；所以她沒有試圖硬碰，而是讓機翼在少女附近的紊流區突然抬升，用激起的側向渦流將她捲離。

雪奈被吹得翻過一個倒轉的半圈。

透子的右手已經抬起槍口，對準少女即將被甩往的方向。

然而，她沒來得及扣下扳機。

雪奈在半空中忽然把雙腿收進身前，腰腹一縮，身體由倒轉改成向後旋開；原本垂直迎風的白霰短外套在這一瞬間被風壓撐成一片斜斜的白色，反倒替她帶出一點側移。透子看見對方的視線先落在自己的腕部，隨後，那隻小小的黑手套已經按住槍套的扣環。

喀。

扣環閉上了。

「不要用槍打我的臉啦。」少女輕聲抱怨。

透子瞪大眼睛，右肘立刻反撞。雪奈放開手，右腳在透子的胸甲上輕輕一蹬，藉反作用退出半個身位。她沒有繼續追擊，因為上方第三層的平台突然斷了。

不是被擊中。

是兩名傭兵切斷了平台吊索。

將近四噸的檢修台連同鋼網與工具箱翻落下來，正在風場裡翻滾。它直接切進兩名少女之間，在半空掃出一堵斜斜墜落的鐵牆，逼得透子不得不向下收翼。那東西要是撞上試驗段底部的感測架，整組下方維修通道都會跟著塌。

「搞什麼！」透子怒罵。她認得那些傭兵臂上的黑色臂章——那不是自己的接應人，而是買家派來的清道夫。對方顯然已經放棄與她交易，只準備把她和母鑰一起拿走。

雪奈已經在下落的檢修台側邊。

她踩住翻轉中的鋼框，白霰衣角被風扯成筆直的白線，腳踝的電漿橙光忽然猛烈亮起。整個人沿著斜墜的金屬邊緣跑出三步，左手極光射向頭頂尚未斷裂的主樑；鋼絲繃緊的一瞬，她的右腳狠狠踹進檢修台外側的承力框架。

一聲震耳欲聾的金屬重響。

四噸重的檢修台沒有被她踢回天上。它在強烈的側向衝擊下猛然轉過一個角度，撞向旁邊的承重護網；極光拖出長長一線橙光，護網與上方主樑承受住剩餘下墜力，整片鋼架在風裡劇烈震顫，卻終究沒有砸向下方的維修通道。

雪奈順著反衝翻離框架，膝蓋擦過一截彎曲的鋼片。黑色壓力層外面劃開一道細白傷痕，橘燄鏡片上流過一串熱警示。她沒有去看，已在半空中重新調整身體，向平台殘骸上方掠去。

剛才割斷吊索的傭兵正趴在頂層缺口邊緣，準備補射。

他只看見一隻白灰色戰鬥靴從風霧中伸出，踏上自己手裡那柄步槍的槍管。槍身向下一沉，男人的手指被迫鬆開；少女另一條腿已繞過槍身，足跟短促而猛烈地掃中他的護甲側緣。連槍帶人一起飛進後方的檢修門，厚重的門板轟地撞上牆，鉸鏈扭曲，震得整層平台發顫。

第二名傭兵從背後抽刀刺來。雪奈甚至沒有看他，左手抬起，夜影的啞黑刀背貼住對方的手腕，將那道刀鋒順勢帶向頭頂護欄。男人驚覺不對，已經來不及改變方向；他的手被迫卡在鋼管之間，右膝剛要頂起，雪奈的鞋底便從他側腰一擦而過，將整個人踢得橫著翻進一張安全網裡。

她落在護欄頂上，雙馬尾被氣流扯得高高揚起，忽然偏頭望向下方。

「咦？」

透子不見了。

她一怔，隨即聽見頂部主風道深處傳來一聲尖銳的金屬嘯鳴。

那個女人沒有趁亂朝出口逃跑。她拉開了右翼下方一條鮮紅色的緊急索，將掛著母鑰的翼尖模組整塊拋了出去。模組張開兩片小型滑翔片，被主流帶著向東端飛去；透子本人則收攏雙翼，轉身撲向上方的灰色風柵。

她要用自己攔住零夜，讓母鑰先出去。

「喔。」雪奈望著那一人一物分開的方向，像終於對這位對手有了明確的評價，「妳真的很會飛嘛。」

『主人，母鑰接近風道出口，十二秒後將進入外部接應範圍。』導航員說。

「我知道。」

『是否啟動外側攔截？』

「叫他們把網準備好就好。先別射，下面有玻璃屋頂。」

她蹲低。

對面的透子已經藏進風柵的陰影裡。那裡沒有任何平坦的走道，只有大型導風片與直徑數公尺的拱形加強肋；她熟悉風速最可怕、也最容易讓外來者失去方向的區域，先前還靠著同一段亂流在試驗中完成過不可能的急轉。

所以當零夜朝她追來時，她沒有開槍。

她把整副複合翼張到最開，踩住導風片的側緣，以身體和機翼共同截住那道狹窄的主風流。風壓一瞬間將她拋上五公尺，她反過來利用這股上升勢頭俯衝，像一柄四公尺寬的黑色彎刀，朝銀髮少女腰側斬落。

這一次，雪奈沒有立刻避開。

透子忽然看見對方笑了。

不是那種嘲弄人的笑。她好像真的很高興，終於看懂自己剛才精心藏起來的路。

「對嘛。」雪奈說，「這樣才漂亮。」

兩人迎面接觸的瞬間，黑色翼鋒擦過白霰左側衣襬，劃出一道細長的裂口。透子趁勢將雙翼向內折起，反手鉤住少女肩頭的黑曜束帶，企圖帶著她一同衝入後方渦流。她知道零夜很難被打中，卻不信那麼輕的身體能在這道風裡穩住方向。

雪奈的手掌按上她的手背。

一瞬間，透子感覺自己的飛行甲像被某種不可抗拒的力量從中間折了一下。少女沒有與狂風較勁。她只讓自己的身體沿著翼面的傾斜角度旋進透子近身，右腳勾住對方腿後方的輔助推進器外殼，左腳則在下方導風片上輕輕一點；風替她把兩人的身體托起，下一刻，卻是她用腰腹與腿部那股令人難以置信的短促力量，將透子整個人翻轉過來。

透子的眼前驟然變成下方的測量燈。

她拼命張開右翼，想藉風把身體擺正。但雪奈順著她的動作又轉了半圈，黑色戰術手套扣住左肩的翼根快拆鈕。她正要按下去，卻發現安全銷早已被透子手動鎖死；那女人甚至在失衡中抬頭，朝她露出一個幾乎得意的笑。

「我知道妳會找這裡。」

「真的？」雪奈眨了眨眼，「那妳應該也知道下一步吧。」

透子忽然不笑了。

雪奈鬆開肩甲，身體貼著翼背向後折去，左腳的零點牢牢咬住右翼根部的金屬結構。黑色壓力層下，纖細的腰腹瞬間繃緊；她把右腿收到幾乎碰上肩頭的位置，隨即展開，戰鬥靴踝側噴出一束炙亮的電漿橙，足跟斜斜轟進左翼的承重肋。

那一擊的聲音把滿場風嘯都壓下去半拍。

透子首先聽見的不是外殼碎裂，而是自己造了七百一十六次試飛的機翼，從裡面發出一聲極難聽的悲鳴。金屬肋骨折彎，翼根被整個踢離肩架，左側四十幾公斤的複合翼猛地向外彈起，帶著扯斷的電纜和白色霧流翻向大廳上方，像一片折斷的黑色羽毛。

透子的升力在一瞬間失去平衡，整個人向下墜落。

雪奈卻也沒有抓住她。

透子在墜落中看見少女踩上自己的右肩，借著短短一瞬的接觸，再次向東端加速。兩條銀色長髮在半空劃出一道迅疾的弧線，白霰短袖的裂口翻出薄薄一片布料，右側零點噴口連續兩次吐出耀眼的電漿橙。

她竟然把透子當成最後一個起跳的支點。

「妳——！」

透子下意識地大喊，聲音立刻被狂風撕碎。

『主人，目標正在下墜。』

「我知道。」

雪奈左手腕一抖。極光向後射出，從透子的右臂下繞過，張開束縛模式，將她連同仍能工作的單側機翼一併固定在側面的檢修加強肋上。被甩斷的左翼早已飛得不見蹤影，剩餘翼面受風猛然抖動，透子在半空晃了個趔趄，終於被牢牢吊住。

她氣得幾乎想咬斷那根線。

可在她張口之前，一道橙光已經越過遠處的測量光幕。

那是零夜。

而母鑰的小型翼片剛剛掠到出口前方。

透子看了看綁住自己的細銀線，又看向東端那道愈來愈細的橙光。她早已把兩條路分開，準備讓追兵二選一；現在卻被人掛在半空，眼睜睜看著那個少女連頭都不回地追向自己最不想失去的東西。

「……這怎麼可能。」

她不是在問速度。

東側出口的風聲突然變了。

透子抬頭。

一個本來應該毫無阻礙地飛出風洞的白色圓筒，忽然在空中停住。

不對。

它不是停住。

一隻纖細的手已經在出口前方穩穩握住了它。雪奈倒懸在最末端的鋼製環梁下，另一手扶著梁架，白霰衣角在兩百公里的風裡獵獵作響。她沒有立刻將圓筒收進胸掛，而是低頭看了一眼上面的固定卡扣，確認封條與指示燈都保持完整，這才漫不經心地將它扣進黑曜的收納艙。

「拿到了。」

『海上接應機已遭海上保安廳扣留。外側攔截組正在待命。』

「跟他們說不用啦。」

『您確定嗎？』

雪奈抬頭看向前方。緊急出口之外，晨光將海面染成灰青色，遠處一群白色海鳥正逆風盤旋。她看了一眼，像想起什麼似的，忽然笑了。

「不過，幫我留一張網。」

『用途？』

「兩張也可以。比較保險。」

她放開橫樑。

下一刻，零夜沒有回頭，而是沿著風向直直飛了出去。

風洞之外是幾乎沒有遮蔽的東京灣上空。剛才的主風流忽然失去四壁約束，向四面散開，雪奈的身體也因此被往下扯。她在空中舒展雙腿，零點的兩側推進器接連亮起，纖細的腰身與肩背伴隨著一個極其漂亮的翻轉重新找回姿態。

她沒有追趕任何人。

只是在無邊的晨風裡，為自己畫出最後一個弧線。

下方的攔截組仰起頭，看見那名身高一百四十九公分的少女從數十公尺高處掠過，銀色雙馬尾被天光染得近乎透明，白鋼短夾克的衣角在身後掀起。她沿著空氣中誰也看不見的一條路飛了出去，繞過一座氣象塔，最後穩穩落在離岸平台最外側的欄杆上。

她竟然真的沒有碰到攔截網。

「……那她剛才叫我們留網做什麼？」一名隊員喃喃說。

另一人抬頭望著她，半天才回答：「我怎麼知道。」

耳機裡，導航員的聲音傳來。

『主人，葉山透子已由現場單位安全接回平台。其餘非法武裝者全數控制。』

雪奈坐在欄杆上，彎腰拍了拍鞋幫，從胸掛裡取出那只白色圓筒，轉了半圈。

「真會玩。」她說。

『您指對方的飛行裝置？』

「嗯。她剛才那個轉身，真的很漂亮。」

『您把她的左翼拆掉了。』

「因為她再不放手就會撞到鋼架嘛。」

『您也可以用比較溫和的方式告訴她。』

「我有說喔。」

『您說的是「這樣才漂亮」。』

雪奈一時語塞，隨即噗哧笑了。

平台門開了。兩名警備員扶著透子走出來；她左肩只剩扭曲的翼根，尚存的右翼折在背後，胸甲上有幾道明顯撞痕，左手腕被束縛帶固定，臉色很難看。看見坐在欄杆上的零夜時，她更是一副想把人從欄杆上拽下來的表情。

「妳這個人——」

「嗨。」雪奈朝她揮了揮手，露出小小的虎牙，「我幫妳留了網耶。」

透子望向下方。

離岸平台外側，兩張大型救援網正緩緩收起，工作人員還在確認固定點。她忽然意識到，零夜追著母鑰飛出去之前，明明已經用極光把自己綁在安全的承重肋上；後來那句「留一張網」，根本不是為了她。

「……妳留網幹嘛？」

雪奈想了想。

「因為我沒試過那麼大的風呀。」

透子怔住。

「萬一摔下來呢？」少女說得理直氣壯，「下面可是海耶。我又不想全身濕答答地回去。」

透子盯著她。半晌，她忍不住低聲笑了一下。

「妳這傢伙，真的知道自己剛才在做什麼嗎？」

「知道啊。」

「那妳還敢往外跳？」

雪奈看了一眼那片泛著晨光的海，伸手理了理被風吹亂的銀色瀏海。

「因為很好看嘛。」

她說完，又瞄了一眼透子背後殘存的單側機翼，眼睛微微彎起。

「而且下次，妳可以教我怎麼不用靴子飛嗎？」

透子一口氣差點沒上來。

「妳把我的翼拆了，還敢叫我教妳？」

「可以修呀。」

「那個很貴！」

「……唔。」

「光是翼尖一片就三百萬！」

「日圓？」

「美元！」

雪奈低頭，看了一眼自己腳下仍在微微散熱的零點，忽然覺得有點心虛。

「那我還是先請妳喝草莓牛奶好了。」

「妳故意氣我是不是？」

「沒有呀。」雪奈眨眨眼，「而且妳不是被捕了嗎？我現在偷偷幫妳修裝備會被椿姊罵的。」

透子終於忍不住笑出聲。

海面吹來一陣涼風，將欄杆上那兩束銀色長髮輕輕往後送去。少女的橘燄風鏡仍反著遠處的晨光，樞紐上的電漿橙脈動逐漸暗下來；她伸手摸了摸自己有些發熱的右腳踝，下一秒便又若無其事地晃起雙腿。

風還很大。

不過，總算不必再迎著它跑了。
