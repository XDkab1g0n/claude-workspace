# 少了一件廢鐵

雪奈先把袖口捲了起來。

回收廠的工作台上有油，欄杆上有油，連掛著「請保持清潔」的牌子都黑得只剩一個「請」字。她在門邊找到一件橘色工作背心，拎著肩線抖開，看了看，又掛回原處。

「這件比我還髒。」

「它的用途不是保護外套。」導航員說。

「那它對我沒有用。」

她把白色長外套的後襬固定在腰側，敞開的前襟下露出紫色領巾。銀色雙馬尾晃過門框，耳罩上的光環尚未亮起；她沿著兩排堆高的廢機殼往裡走，厚底鞋落在滿地鐵屑之間，竟沒有發出多餘的摩擦聲。

廠房深處有人正在工作。

那人背對入口，穿灰色工裝，右臂套著一具從肩膀延伸到手指的外置動力架。架子末端不是手掌，而是一把厚重的液壓剪。他把黑色運輸箱放上推車，用剪口咬住提把，短促一壓，提把便落在地上。

雪奈停在機殼後方。

箱子的正面朝著她。兩道黃色封條，右下角一道燒灼痕，與委託照片完全相同。裡面是港區私人貨運公司的離線結算核心；公司的人把它偷出來，準備在改組前銷掉幾年的分帳紀錄。銜尾蛇的仲介確認過貨物去向、委託人的身分與託管款，她才接下這份回收工作。

原機要能讀，資料不能抹。箱子本身倒沒有那麼金貴。

她原本打算從屋頂進來，在運輸車卸貨時拿走。車卻早到了一刻鐘，現在空車已停在外面，司機不在，廠房的員工也全走了，只剩這個把門牌翻成「休業」的人。

男人撿起斷掉的提把，放進金屬桶，再推著箱子往壓縮機走。

雪奈的視線越過他，看見開著的方形壓室、推出來的承料抽盤，以及一旁尚未熄滅的壓力表。她沒有喊停。

黑影從機殼之間滑過。

男人聽見聲音時，雪奈已經踩上推車下方的橫桿。她的右腳從箱底一勾，將箱子送離車面；左手接住側邊，身體隨之向後轉，白色衣袖在男人眼前翻出一道弧。

液壓剪猛地合上。

喀的一聲，她剛握過的箱角被咬凹，男人沒有去追她的頭或胸口，直接將剪口往箱子中央送。雪奈鬆開左手，讓箱子落向地面，足尖順勢一撥，黑箱便沿水泥地滑進一排鐵架底下。剪刃擦著她收回的袖口掠過。

下一瞬，她的鞋底撞上男人胸前。

那不是試探。工裝下的胸部護板發出沉重悶響，男人連退幾步，後背撞得推車整個翻倒。他抓住壓縮機側柱才沒有摔下去，嘴角已滲出血，眼睛卻先看向鐵架。

雪奈落在他與黑箱之間，把右袖又往上捲了一折。

「你反應滿快的。」

男人用舌尖抵了抵口腔，吐掉一口血。他看見她的銀髮、紫電與那雙鞋，沒有問名字，只抬手摸向腰後。

白夜已經指著他的眉心。

「如果是槍，」雪奈說，「先不要拿。」

他的手停住，慢慢移開。

「遙控器。」他說。

雪奈望向他的腰後。那裡確實掛著一只黃色控制器，粗短天線，兩排控制鈕，標籤上分別畫著吊鉤與鐵門。

頭頂的天車吊鉤正懸在兩人之間。

「那也先不要。」

＊

男人自稱陣內。

他不是公司的人，也不打算替那些帳目辯護。他收了錢，要讓一台指定設備變成任何人都讀不出來的東西；攝影機已架在壓縮機旁，鏡頭對著承料抽盤，連收工後裝碎料的桶都準備好了。

雪奈一邊聽，一邊用左腳把鐵架底下的箱子勾出來。

「你可以拍別的。」

「序號要拍，開箱要拍，壓碎也要拍。」

「要求好多喔。」

「給得不少。」

她低頭看看那個被剪壞的箱角。外殼咬穿一小塊，內側還有防震層，封條完整；她將箱子翻到沒受損的一面，才重新抬眼。

「所以你願意做到哪裡？」

陣內沒有立刻回答。他的視線從白夜移到雪奈腰側，再落到她腳邊。雪奈看見那一眼，將槍口壓低了些，正好指住他胸口。

「不要把『殺掉我』算進去，會算錯。」

男人笑了一聲，牽動嘴裡的傷，笑意又很快消失。

「我知道妳是誰。」

「那就好談了。」

「我的槍不是拿來打妳的。」

他左手突然勾起翻倒的推車。

車架向雪奈撞來，空心鐵管遮住了他半邊身體。她沒有退，白夜的槍口一偏，子彈穿過車架間的空隙，打進他正抽槍的左前臂。男人悶哼，槍掉了，右臂的液壓剪卻同時向下掃去。

它也不是衝她來的。

雪奈腳邊的黑箱剛被她踢離地面，剪刃便砸進水泥，碎屑打上黑色過膝襪。她在空中用膝側把箱子托高，左臂接住，右腳已踏上斜過來的車架，踩得薄壁鋼管向內折彎。

男人沒有和她搶那支掉落的槍。他把動力剪從地上拔起，連著被掀起的水泥碎塊一起甩向她抱著的箱子。

雪奈的眼睛亮了一點。

她側身讓開，抱箱的左臂貼住肋側，右腿從車架上猛然抽起。厚底鞋側面擊中動力架的肘部，整條右臂被踢得向外甩開，剪口砸上旁邊鐵櫃，厚鋼門當場凹進去。她已從他的右側掠過，腳尖在地上一點，帶著箱子落到另一排料架後方。

白色衣角才從他視線裡消失，她的聲音已從側面傳來。

「你真的很討厭這個箱子耶。」

陣內靠著機柱，將受傷的左臂壓在胸前。他沒有回話，用右側剪口夾住黃色遙控器，抵著機柱先後壓下兩個按鍵。

廠房裡響起低沉的蜂鳴。

雪奈身後，原本敞開的卸貨門開始下降。天車也動了，吊鉤拖著一束垂在半空的鏈條，朝她所在的料架掃過來。她抱著箱子跳上架頂，鐵鏈從下方撞進空機殼，聲音像一大袋餐具被倒在地上。

「正門要關了。」導航員說。

「看到了。」

雪奈沿料架快步走到末端，抬眼看向剩下的門縫。她能出去，抱著這個箱子也能。可陣內已退回壓縮機旁，右臂垂著，剪口貼地，視線一直追著她手裡的東西。

他不打算追上她。他只需要她為了穿過門縫，把箱子放低一次，或在落地時露出沒有身體遮住的那一面。地上還有那把槍，距離他的右腳只有兩步。

雪奈蹲在料架上，看了他一會兒。

「你等門關上，就不怕自己也出不去？」

「旁邊有小門。」

「喔。」

她真的朝旁邊看了一眼。

陣內也在那一刻移動。液壓剪將地上的槍撥到腳邊，他俯身用受傷的左手撿起，架在右側剪臂上。血順著指縫淌進握柄，他沒有瞄準銀色頭髮，只把槍口對準黑箱。

雪奈從架頂消失。

槍聲撞滿廠房。子彈打穿空機殼，又從後方牆面彈起一串火星；陣內還沒來得及壓低手臂，雪奈已落在另一側的機柱後。箱子被她穩穩放在柱腳，她伸手拍了拍箱蓋，像要它乖乖待著。

「等我一下。」

她站直，將白夜收回腿側。

陣內望著她空下來的雙手。

雪奈從腰側解開固定後襬的扣件。白色長衣擺散下，遮住她身後那只黑箱；兩束銀髮垂在肩旁，她偏過頭，把剛才滑出耳罩的一綹頭髮塞好。

「現在可以專心找你了。」

＊

陣內朝機柱後方開槍。

雪奈沒有站在原地替箱子擋。她踏出的第一步很輕，第二步已越過那截滿是碎屑的空地。槍口追不上她，便固執地留在原處；男人只想逼她回去，讓她繼續抱著東西打。

她的右腳先到了。

鞋底踹中液壓剪的下側，整具沉重工具向上翻起，撞開架在上面的槍。槍聲打進屋頂，雪奈已貼進他右臂內側，左腳在機柱上一踏，身體橫過他的肩前。她沒有停下來扭那具力量遠比普通手臂大的動力架，右腿收回，膝尖撞進他的下顎。

牙齒合攏的聲音很脆。

陣內的頭向後仰，血從嘴角濺在肩上。他卻沒有倒，右臂猛地往內夾，鋼製支架擦著雪奈的腰側收攏，試圖把她和機柱鎖在一起。

她落腳以前便鬆開了距離。

厚底鞋在他胸前短短一蹬，少女倒掠出去，白袖與裙褶一同翻起。陣內的鉗臂撞在自己胸口，左腿向後踏進推出的承料抽盤；他借那個低矮邊緣穩住身體，右肩一沉，將整具剪具壓到身前。

雪奈落在兩步之外，沒有立即衝回去。

她看見他的左手鬆了。手槍落進抽盤，沿斜面滑到壓室深處；陣內無法再用那隻手握住它，便把右臂轉過來，將兩片厚刃張到最大。機柱保護了他的左側，背後則是承料抽盤。他把能被繞到的地方縮得很小，剪口停在她膝蓋的高度，正好擋住直入的路。

雪奈的呼吸仍很輕，嘴角卻慢慢彎起來。

「你平常也用這個打架？」

陣內吐出一顆斷牙。

「偶爾。」

「難怪。」

她往前，忽然又慢下來。

陣內沒有咬那個節拍。他把剪具留在原處，讓她自己選擇要從哪邊進；雪奈便從他最希望她走的右側跨入，白色衣袖貼著剪臂掠過。液壓剪驟然抬起，兩片刃口在她腰前合攏，卻只咬住一截被她甩過來的衣擺。

布料撕裂。

那一小片白色尚未從刃間掉下，雪奈已俯低身體，從動力架下方鑽進去。她的手掌在抽盤邊緣一按，腰髖旋轉，黑色過膝襪包覆的雙腿從狹窄空間中展開，右腳先抵住男人的髖側，左腳跟著踏上他的胸部護板。

夢魘舞者迸出一聲短促爆震。

陣內整個人被轟進壓室。

抽盤向裡猛滑，鋼輪撞過導軌接縫，沉響震得攝影機支架跳了一下。他的背部撞上壓室後壁，胸前護板裂開一道白痕，右臂的剪具卻仍卡在入口外側，把身體扯成斜躺的姿勢。

雪奈借反衝落回地面，鞋底劃出兩道深痕。熱氣從踝側逸出，她的臉頰泛了紅，眼睛卻牢牢盯住那條動力臂。

陣內開始往外爬。

左手受傷，撐不起身；右臂的剪口在鋼板上咬了一次，借液壓力量拖著他向外挪。他的視線越過雪奈，仍在找柱腳的箱子。

雪奈沒有再踢他。

她伸手，扳下壓縮機側面的手動操縱桿。

馬達的低鳴忽然加深。壓室上方的厚重鋼板開始下降，陣內抬起頭，立刻將右臂向外收。剪具本就橫卡在入口，那個匆忙的收臂反而使肘架頂住側緣；他整個人向前掙，胸口剛出壓室，動力架上方的肩座便碰到了下壓的鋼板。

金屬發出第一聲尖叫。

「快拆在左肩。」雪奈說。

他猛地抬眼。

她站在操縱桿旁，白色外套的下襬缺了一角，握住操縱桿的手很穩。壓板繼續下降，肩座往裡凹，接在他右臂外側的固定環開始拉緊。

陣內用流血的左手抓向肩帶。

第一次沒有抓住。

雪奈把操縱桿推回中位，壓板停了。男人抬頭看她，她沒有挪開腳，也沒有再說一次。他咬住牙，左手終於扣到那枚紅色拉環，用力向外一扯。

肩帶彈開，胸前連接鬆脫。他抽出右手，再把小臂從固定套裡拔出來，拖著身體滾離壓室。雪奈等他的膝蓋越過邊緣，才重新壓下操縱桿。

那具液壓剪在鋼板底下慢慢折了。

先是肩架，再是肘部，最後兩片厚重剪刃也向不同方向崩開。油沿抽盤邊緣淌出來，滴在陣內剛才趴著的地方。他用右手撐地，看著自己幾分鐘前還在使用的東西變成一塊再也穿不上的廢鐵。

雪奈讓壓板升回去，關掉機器，拔走控制鑰匙。

「好了。」

她轉身走向柱腳。

＊

黑箱還在原處。

雪奈蹲下，避開被剪壞的箱角，割開封條，解開外部鎖扣。防震層裡的結算核心沒有位移，接口蓋也仍扣著。她接上隨身檢測器，讓導航員核對原機標識與只讀測試結果。

身後有衣料摩擦聲。

她沒有回頭，白夜卻已從右腿側抽出，槍口指向聲音所在。

「那邊沒有第二把槍。」陣內說。

「希望你記得很清楚。」

他用工作服下襬壓住左臂的彈孔，靠著機台坐下。臉上的血滴到領口，說話時下顎明顯不敢張太大，右肩卻還能動。雪奈等測試燈由黃轉綠，才把核心重新固定，合上箱蓋。

她走回他面前，丟下一包止血敷料。

陣內看著它，沒有立刻拿。

「妳可以一開始就殺我。」

雪奈蹲下來，先確認那把槍已跟著動力架一起被壓毀，再撿起那只被鉗口壓裂的遙控器。她試了兩下，卸貨門沒動，只得站起來走向牆邊的控制箱。

「可以。」她說，「可是我想拿箱子，你剛才正好站在旁邊。我以為你會識趣一點。」

「現在呢？」

「現在你沒有那隻大手了。」

她打開控制箱，找到門的開關。鐵門慢慢升起，清冷的夜風從地面吹進來，將她缺了一角的衣擺掀向膝側。

陣內終於拆開敷料，用右手沿缺口撕開包裝，壓到傷口上。雪奈看見他做法沒錯，便沒再靠近。她走到攝影機旁，將鏡頭轉向壓室裡那團破碎金屬，確認它還在錄。

「這段你可以留下。」

「我的客人要看的不是這個。」

「那是你要跟他談的事。」

陣內低頭看著右臂。原本被束帶壓住的皮膚上留下幾圈深紅痕跡，他慢慢握了握拳，像不太習慣手指真的能合起來。

「箱子裡是什麼，妳知道？」

「知道我要帶走哪一台，也知道要交給誰。」

「其他的呢？」

雪奈將被剪斷的提把從金屬桶裡拿出來，對著箱子比了一下。接不回去了。她有點可惜地放下，改用一條織帶穿過箱體底部，收緊，試了試重量。

「你想告訴我，可以說。」她抬起眼，「但不要等我到了門口，再開始喊。」

陣內看了她片刻，搖頭。

「我不知道。我只拆東西。」

「嗯，我今晚不拆。」

他望向壓縮機。

雪奈也跟著看了一眼，然後笑了。這次笑得很明顯，露出一點小虎牙。

「那個不算貨物。」

她提起黑箱，沒有要求他承認失敗，也沒有等他的回答。卸貨門已升到足夠的高度，外面的空車停在冷白路燈下，擋風玻璃上還夾著一張收料單。

走到門邊時，雪奈忽然停住。

她低頭看了看外套缺掉的角，又轉身折回壓縮機。陣內的右手下意識繃緊，卻看見她從地上撿起那片被剪落的白布，小心拍掉鐵屑，放進口袋。

「還能補。」她說。

這句不是對他說的。她摸了摸裂口，像已經在想該用什麼顏色的線。

陣內的手慢慢鬆開。

雪奈再度提起箱子，走出廠房。夜風把兩束銀髮吹向身後，她跨過門口一道黑色油痕，鞋底在乾淨的水泥上留下淡淡灰印，沒有回頭。

廠房裡，男人將染血的敷料按牢，用右手拉過攝影機，關掉錄影。他在螢幕上確認最後那一格畫面，接著拿起電話，撥給付錢的人。

雪奈還沒走遠，聽見他說：「沒銷毀。」

她抬了抬手裡的黑箱，換到比較順手的位置。

身後的電話聲高了起來。陣內等對方說完，才用那副含著血、張不太開的嘴補了一句：

「不是機器壞了。」

雪奈踩下路旁的階沿，終於忍不住笑出聲來。
