# 通用小說寫作方法學

這套方法的核心是：**以創意與文字質感為目標，以設定維持人物與因果，最後用讀者實際感受到的效果驗收。**

1. **先抓住值得寫的場景。**  
   人物此刻想做什麼？彼此有什麼落差？這場相遇、衝突或日常，有哪個值得停留的瞬間？先找到故事的吸引力，再安排資訊與情節功能。

2. **把設定轉成人物的選擇。**  
   背景、性格與能力應影響她注意什麼、如何判斷、願意做什麼，以及怎樣回應別人。角色要能在新情境中產生新行為；設定表與示例台詞都不能代替這個過程。

3. **寫成連續發生的生活。**  
   讓動作、觀察、思緒與對話彼此帶動，篇幅跟著人物的注意力變化。空間、動作與所指必須清楚；留白留給情緒與意義，基本事情怎麼發生要讓人讀懂。

4. **輸出前，以中文語感重建對話。**  
   回到人物當下的意思、情緒、關係與說話目的，重新想她用中文會怎麼開口、接話、停頓、省略或改口。重建的是整段交流，不只是替句子換口語詞；長短由情境決定，人味也不能靠語助詞硬加。已自然的敘述應保留。

5. **用文字造成預期感受。**  
   想寫強，就讓行動與結果使人感到強；想寫親近，就讓互動產生親近；想寫緊張，就讓讀者在乎接下來會發生什麼。效果不足時，先修承載效果的場景，避免只追加解釋與機制。

6. **把文字品質與人物正確性分開檢查。**  
   好讀的段落仍可能寫錯人物；設定一致的段落也可能乏味。重讀時分別問：事情是否成立？這個人是否會如此行動？讀起來是否清楚、有生命、能引發預期感受？

7. **精準修正，延續已成立的部分。**  
   每次回饋都先辨認範圍，再轉成正向修改目標。局部問題局部處理；若錯的是人物動機或核心前提，才重建所有受影響的段落。已獲肯定的質感應成為基礎，避免把歷次批評累積成束縛創作的禁令表。

8. **在真正的分岔處引入人類選擇。**  
   先把眼前場景寫完整，再於會改變人物關係、故事方向或閱讀體驗的節點，提供少量有實質差異的選項。依閱讀回饋調整，讓創作保有發現的空間。

實作順序：**理解人物與情境 → 寫完整場景 → 重建中文對話 → 分別檢查因果、人物與閱讀效果 → 精準修訂 → 在必要節點交回選擇。**
