# 2. 「迴聲密室」

* 小型地下Live House。

* 錄音與混音工作室。
* 聲學實驗空間。

* 小夜的主要居所與私人領域。

它不是純酒吧，也不是只供核心角色休息的安全屋。

## 2.2 空間結構

* **主舞台**
  * 可變聲場。
  * 移動式揚聲陣列。
  * 吸音與反射面板。
  * 地板低頻傳導模組。
* **控制室**
  * 類比與數位混音台。
  * 多通道監聽。
  * 場地感測。
  * 任務聲學模擬。
* **錄音室**
  * 可調殘響。
  * 樂器、合成器與模組機。
* **休息區**
  * 沙發。
  * 舊唱片。
  * 熱飲。
  * 不要求說話的低刺激空間。
* **工坊**
  * 心嘯、響核與身體介面的維護。
* **私人房間**
  * 隔音程度比舞台更高。
  * 不是任何熟客都能進入。
* **緊急結構**
  * 隱藏出口。
  * 反竊聽。
  * 局部EMP與網路隔離。
  * 醫療與裝備存放。

## 2.3 場地規則

* 不准未經同意錄音。
* 不准騷擾表演者與工作人員。
* 不准把地下恩怨帶進觀眾區。
* 不准碰控制室設備。
* 不准以「只是玩笑」破壞他人作品。
* 違反者不一定被暴力處理：
  * 先驅離。
  * 封禁。
  * 公開證據。
  * 必要時才由小夜或協力者處理。
* 小夜保護這個地方，不是因為它是完美作品，而是：
  > 這是少數不需要先證明有用，便能暫時讓人留下聲音的空間。

* 害怕被追問「妳到底怎麼了」。

* 不是脆弱的真正本體；她只是失去舞台結構後，更難安排自己的感受。

## 4.2 真正欲望

小夜想要：

1. **創作一種能容納沉默、噪音與不同感官的音樂。**
2. **讓迴聲密室成為不被主流市場與地下權力完全控制的空間。**
3. **被人理解作品，也被人理解作品之外的自己。**
4. **保有自由協力身份，不被銜尾蛇或八咫烏收編。**
5. **證明感官敏銳不是只能被治療或武器化的缺陷。**
6. **能在不完美、沒有完成作品時仍與人建立關係。**

## 4.3 完美主義

* 她能為一個無人察覺的相位問題重做整晚。
* 優點：
  * 作品品質。
  * 戰場細節。
  * 精密聲學控制。
* 代價：
  * 延誤。
  * 過勞。
  * 合作者壓力。
  * 永遠覺得尚未準備好被真正聽見。
* 她需要學會：
  * 完成不等於背叛作品。
  * 別人以不同方式聽見，不等於沒有聽懂。

## 4.4 親密迴避

* 她擅長：
  * 替人選歌。
  * 用聲場調節情緒。
  * 聽出呼吸與心律變化。

  * 直接問「妳需要我嗎？」
  * 承認自己嫉妒。

  * 邀請試聽。

  * 要對方坐在控制室。

她區分：

  * 音樂。
  * 抗議。

  * 她有時把自己不喜歡的聲音過快定義成無意義。
* 成長需要理解：

  * 威脅。
  * 聲源。
  * 安全頻率。
* 不自動分享：
  * 私人錄音。
  * 生理反應。
  * 情感標記。
  * 未完成作品。
* 她對「被監聽」的敏感，必須在劇情中被尊重。

## 6.4 限制

* 過多聲源會增加分離難度。
* 強EMP、頻譜飽和、完全未知材料與快速改變空間會降低模型準確度。
* 運算能力高，不代表能預測所有反射。
* 失去響核後：
  * 小夜仍有優秀聽覺、格鬥與音樂能力。
  * 但大規模相位控制、保護與多節點同步顯著下降。

# 7. 心嘯／音波戰術手套

## 7.1 結構

* 覆蓋手背、指節與前臂。
* 內含：
  * 相位陣列發聲單元。
  * 震動致動器。
  * 接觸式骨傳導。
  * 局部冷卻。
  * 壓力與姿態感測。
* 左右手可：
  * 分工。
  * 合相。
  * 產生定向聲束。

## 7.2 低頻衝擊

* 以短距高聲壓脈衝造成：
  * 平衡破壞。
  * 胸腔不適。
  * 肌肉控制干擾。
  * 輕型物體位移。
* 效果隨距離快速衰減。
* 不能像無形拳頭一樣無限撞飛重型目標。

## 7.3 高頻聚焦

* 利用相位陣列形成短距高頻壓力梯度。
* 可：
  * 破壞脆性材料。
  * 切斷薄膜、線材與部分軟性結構。
  * 干擾感測器。
* 「音刃」是視覺化稱呼。
* 不能無條件切開厚重裝甲。
* 對空氣、材料與距離高度敏感。

## 7.4 接觸式音爆

* 拳腳或手掌接觸時，將震動直接耦合進目標。
* 用於：
  * 護甲接縫。
  * 義體關節。
  * 武器。
  * 人體失衡。
* 效率高，但需要近身。
* 反作用力與震動也會回到小夜手臂和骨架。

## 7.5 過熱與冷卻

* 高功率連續輸出會造成：
  * 前臂發熱。
  * 手指麻木。
  * 相位誤差。
  * 響核降級。
* 她必須安排：
  * 低功率節拍。
  * 交替使用。
  * 環境聲源。
* 不得無限連發音爆。

# 9. 戰鬥哲學：「音律鬥術」

## 9.1 核心原理

> **先讓對手聽錯時間，再讓身體錯過正確動作。**

小夜控制的不是單純音量，而是：

* 聲源位置。
* 拍點。
* 前兆。
* 反射。
* 呼吸節奏。
* 內耳平衡。
* 團隊同步。
* 空間情緒。

## 9.2 標準流程

1. 掃描聲場與材料。
2. 建立假的聲源與節拍。
3. 讓敵人提前或延後反應。
4. 以卡波耶拉、Breaking、Krump和MMA混合身法切入。
5. 用心嘯放大接觸與失衡。
6. 展開局部聲音領域。
7. 讓隊友安全進入或撤離。
8. 在空白期前結束戰鬥。

## 9.3 身法

* 卡波耶拉：
  * 低位旋轉。
  * 假動作。
  * 踢擊。
* Breaking：
  * 地面轉換。
  * 支點。
  * 非常規軸線。
* Krump：
  * 爆發。
  * 胸肩與重拍。
* MMA：
  * 實用拳腳。
  * 摔防。
  * 近身控制。
* 舞蹈不是裝飾。
* 每個動作必須：
  * 改變聲源。
  * 隱藏起手。
  * 累積振動。
  * 破壞節奏。
* 她不是純技巧近戰頂點。
* 面對雪奈等全領域頂尖近戰者，主要優勢是聲場與節拍干預，而不是單靠拳腳。

# 10. 代表性聲學技術

> 名稱是演出與戰術簡稱，不是固定遊戲技能。

## 10.1 幻音滑步

* 以相位陣列與腳步聲重建生成錯位聲源。
* 讓敵人判斷小夜仍在原位置或從錯誤方向接近。
* 所謂「0.5秒聲波殘影」不是固定數值。
* 效果取決於：
  * 環境反射。
  * 敵人感測器。
  * 聲場建模。
* 對純視覺、多光譜或封閉式感測敵人效果下降。

## 10.2 碎拍瞬步

* 短促爆發步法與低頻脈衝同步。
* 使近距目標：
  * 內耳失衡。
  * 步伐提前。
  * 重心修正失敗。
* 不是定身。
* 高階敵人可透過：
  * 視覺。
  * 接觸地面。
  * 主動降噪。
  進行反制。

## 10.3 環境共鳴

* 讀取：
  * 鋼梁。
  * 管線。
  * 玻璃。
  * 車體。
  * 房間。
  的固有頻率。
* 持續輸入能量，使：
  * 螺栓鬆動。
  * 玻璃破裂。
  * 機械噪音放大。
  * 結構疲勞。
* 需要：
  * 足夠時間。
  * 能量。
  * 模式準確。
* 不能隨手一擊震塌任何建築。
* 大規模結構破壞具有平民與自身風險。

## 10.4 寂靜殺陣

* 由多節點主動降噪、吸音材料與相位反制構成。
* 可用於：
  * 自身無聲接近。
  * 隔離單一聲源。
  * 建立局部通訊黑洞。
  * 保護平民免受高聲壓。
* 不能完全消除：
  * 爆炸衝擊。
  * 未知全頻聲源。
  * 固體直接傳導。
* 範圍越大，頻帶與抑制程度越有限。
* 高度依賴響核與環境節點。

## 10.5 B.O.S.S.／全域聲波風暴

* 是高輸出領域控制協議，不是每場必用的必殺技。
* 需要：
  * 已完成聲場建模。
  * 累積的節拍與反射資料。
  * 場地節點。
  * 脈動核心與心嘯高功率。
* 形成球形或不規則多區聲壓領域。
* 效果：
  * 物理衝擊。
  * 內耳失衡。
  * 通訊混亂。
  * 感測器與機械共振。
  * 群體節奏崩潰。
* 不直接造成抽象「精神傷害」。
* 心理混亂來自：
  * 感官過載。
  * 空間定位失效。
  * 生理恐慌。
* 使用後進入空白期：
  * 聽覺保護模式。
  * 耳鳴。
  * 頭痛。
  * 視覺模糊。
  * 心嘯與響核降級。
  * 數分鐘至更久無法使用高階聲學控制。

# 11. 戰術邊界與弱點

| 弱點 | 具體表現 |
|---|---|
| 聲學環境 | 開放空間、強風、吸音材料會削弱反射與領域 |
| 感測反制 | 純視覺、雷達、多光譜與主動降噪敵人較難欺騙 |
| 聽覺過載 | 高頻、爆音與多源飽和會傷害自身 |
| 能源與熱 | 心嘯、響核與脈動核心不能長時間滿功率 |
| 空白期 | B.O.S.S.後高階聲學能力顯著下降 |
| 節奏依賴 | 束縛、固定與失去地面會破壞身法 |
| 身體質量 | 152cm身體不適合與重型敵人長時間角力 |
| 結構風險 | 共振可能造成不可逆坍塌與平民傷亡 |
| 完美主義 | 過度準備、拒絕交付、延誤 |
| 親密迴避 | 用作品與隱喻取代直接需求 |
| 場地責任 | 迴聲密室可能被當作槓桿 |
| 維修與供應 | 改造模組依賴可信任零件與技師 |

## 11.1 不能被弱化的部分

* 無聲敵人不等於她完全失去戰力。
* 她仍具：
  * 視覺。
  * 振動。
  * 地面傳導。
  * 近身格鬥。
  * 心嘯接觸式輸出。
* 吸音空間不等於封印：
  * 她可利用固體傳導。
  * 主動聲源。
  * 身體節奏。
  * 電子戰。
* 被打亂節拍時，她能重新建立節奏，而不是立刻崩潰。
* 她是專業自由協力者，不是只在自己場地才有能力的DJ。

## 11.2 不能被神化的部分

* 不能用聲音無條件切開所有裝甲。
* 不能一鍵震塌任何建築。
* 不能完全消除所有聲音與爆炸。
* 不能靠節拍控制他人意志。
* 不能在B.O.S.S.後立刻恢復滿功率。
* 不能因聽覺敏銳而讀心。

  * 無法使用高階聲學能力。

* 她必須面對：
  * 沒有聲音時自己仍是誰。

  * 能否接受創作方式改變。

  * 「我嫉妒。」

* 她仍然挑剔、張揚、自由，不必變成溫順療癒系角色。

# 15. 聲線與狀態矩陣

| 狀態 | 聲線 | 行動特徵 |
|---|---|---|
| 舞台演出 | 張揚、穿透、節奏強 | 主動操控全場情緒與呼吸 |
| 調音工作 | 短、冷、精準 | 對細節極度專注，容錯低 |
| 與雪奈共處 | 音量降低、隱喻減少 | 允許沉默，觀察而不立刻解讀 |
| 與奏相處 | 話少、節奏平 | 一起工作，偶爾互相拆穿 |
| 與琉璃創作 | 技術密度高、好奇明顯 | 交換頻譜、審美與非人感知 |
| 與潔西卡互嗆 | 音量與速度上升 | 爭舞台、爭控制權，但合作爆發力高 |
| 與夏音競演 | 挑釁、帶笑 | 互相嫌俗與難懂，實際享受對手 |
| 被批評作品 | 先降溫 | 區分建議、誤解與羞辱 |
| 親密不安 | 隱喻增加、傳未完成音源 | 難以直接要求對方留下 |
| 標準戰鬥 | 節拍短、指令清楚 | 建模聲場、欺敵、切入、領域控制 |
| 過載前 | 更興奮、更冒險 | 容易追求最後一段完整演出 |
| 空白期 | 沙啞、耳鳴、主動降噪 | 依靠視覺、觸覺與隊友撤離 |
| 真正坦白 | 沒有比喻、停頓明顯 | 直接說出想要與害怕 |

# 16. AI寫作協議

## 16.1 場景生成邏輯

1. 判定場景：
   * 迴聲密室。
   * 演出與製作。
   * 自由委託。
   * 核心群像。
   * 感官過載。
   * 關係衝突。
2. 判定聲學環境：
   * 材料。
   * 反射。
   * 距離。
   * 風。
   * 背景噪音。
3. 判定她正在使用：
   * 音樂。
   * 技術。
   * 挑釁。
   * 沉默。
   代替哪一個直接需求。
4. 判定心嘯、響核、身體改造的能源與負荷。
5. 讓她作出自己的選擇，而不是只替雪奈配樂。

## 16.2 人格寫作規則

* 不把她寫成只會音樂比喻的人。
* 不把喧囂當成虛假面具。
* 不把私下安靜當成唯一真正人格。
* 她可以很懂別人，也可以誤判。
* 她不能靠聽呼吸與心律讀取完整思想。
* 她能直接表達，只是這件事對她困難。
* 不把每場日常都變成療癒雪奈。
* 她有工作、場地、同行與自己的創作危機。
* 她可以拒絕核心群體的任務。
* 不把完美主義浪漫化成無限熬夜仍沒有代價。

## 16.3 戰鬥寫作規則

* 聲音遵守：
  * 距離衰減。
  * 材料反射。
  * 吸收。
  * 固體傳導。
  * 相位。
  * 能量。
* 先建立聲場，再寫能力結果。
* 音刃不無條件切甲。
* 共振不無條件拆樓。
* 寂靜殺陣不消除所有衝擊。
* B.O.S.S.需要建模、節點與高功率，使用後有空白期。
* 她被克制時可使用：
  * 近身格鬥。
  * 接觸音爆。
  * 固體振動。
  * 電子戰。
  * 普通武器與撤離。
* 不用突然失去節奏或情緒崩潰製造所有危機。
* 她可以壓倒性控制適合自己的環境。

## 16.4 關係寫作規則

* 小夜與雪奈是共鳴，不是粉絲崇拜。
* 她不能自動成為最了解雪奈的人。
* 雪奈不能把迴聲密室當免費療養空間。
* 奏、琉璃、潔西卡、夏音都需要與小夜建立獨立關係。
* 不把所有互動簡化為爭奪雪奈注意。
* 允許別人不喜歡她的作品。
* 允許她在不被理解時仍維持關係。
* 她的場地、設備與感官資料需要同意與邊界。

## 16.5 絕對禁忌

* 不得把小夜寫成雪奈的專屬配樂或情緒治療工具。
* 不得把所有台詞都寫成音樂隱喻。
* 不得把她的喧囂寫成完全虛假人格。
* 不得把她的安靜寫成脆弱小女孩真身。
* 不得讓她以聽覺敏銳讀心。
* 不得讓響核遠端控制人格或身體。
* 不得未經同意存取其聲紋、感官資料與未完成作品。
* 不得讓聲波無視物理、距離、材料和能源。
* 不得讓音刃切開所有裝甲。
* 不得讓環境共鳴瞬間摧毀任何建築。
* 不得讓寂靜殺陣取消爆炸與所有固體振動。
* 不得讓B.O.S.S.無代價連發。
* 不得把身體改造寫成無限耐久。
* 不得讓動態阻尼層抵消穿刺與重型爆炸。
* 不得把瞬步寫成瞬移。
* 不得色情化16歲小夜的身體、戰鬥服、項圈、植入或過熱。
* 不得以露腰、胸腿描寫作為聲波能力的核心視覺。
* 不得把場地規則違反者一律殺害。
* 不得把「永久靜音」當成普通冒犯的合理處罰。
* 不得讓她的自由協力身份自動變成不負責任。
* 不得讓成長等同於放棄音樂、舞台或張揚。

# 17. 角色核心色彩

* **她控制的是時間，不只是聲音。**
  * 讓敵人提前、延後、誤判與失去共同節拍。
* **她是真正的音樂人。**
  * 作品、場地、勞動與同行關係不是戰鬥裝飾。
* **她自由，但不是沒有責任。**
  * 接案、場地與改造都有代價。
* **她需要沉默，也熱愛喧囂。**
  * 兩者不是真假人格。
* **她能聽見很多事。**
  * 仍不能替別人定義感受。
* **她的改造屬於自己。**
  * 不是組織資產，也不是為雪奈準備的功能。
* **她與雪奈的共鳴很深。**
  * 但真正成熟的共鳴容許不同拍、停頓與拒絕。
* **最終命題**：

> 小夜曾相信，只要把所有感受編成足夠精確、足夠震撼的作品，就不必冒險用普通語言請任何人留下；後來她才明白，真正被聽見不是所有頻率都被正確解析，而是在她說得不完整、沒有舞台、甚至只剩沉默時，仍有人願意等她把下一句說完。
