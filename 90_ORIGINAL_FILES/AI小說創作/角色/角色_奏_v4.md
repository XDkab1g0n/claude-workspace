# 3. 人格、欲望與價值

## 3.1 表層人格

* 話少、語句短，不喜歡解釋已經能由行動完成的事。
* 對陌生人警戒，不主動建立親密。
* 面對讚美時容易沉默、移開視線、立刻指出尚未完成的部分。
* 很少大笑；真正高興時嘴角只會小幅上揚，琥珀眼明顯變亮。

## 3.2 真正欲望

奏真正想要的不是單純「永遠待在雪奈身邊」。

她想要：

1. **一個不因任務失敗而消失的家。**
2. **被需要，也被允許偶爾沒有用。**
3. **能掌控自己身體、時間與親密距離。**
4. **讓料理成為創作，而不只是補給。**
5. **擁有同齡生活，不必為此放棄地下世界的能力與責任。**
6. **被雪奈及其他人當作可依靠的人，也當作可以被照顧的人。**

## 3.3 料理

* 奏是真的喜歡料理。
* 起初喜歡它的理由：有明確步驟；原料、時間與溫度會給出可預測結果；食物能直接改善一個人的狀態。
* 後來逐漸喜歡味道組合、刀工、發酵、便當設計，與看見別人因自己的作品放鬆。
* 她不只會做雪奈喜歡的食物，也應發展自己的料理偏好：精準但不僵硬，重視質地、溫度與營養，喜歡將簡單家常菜做到非常穩定。
* 她最大的料理成長不是更會投餵，而是敢做自己想做的菜，並接受別人可以不喜歡。

## 3.4 秩序與控制

* 奏喜歡秩序，因為秩序能降低未知；整理、備餐、確認門窗與記住每個人的行程會使她安心。
* 問題在於：她容易將秩序擴張成控制——未經同意整理私人物品、自行替別人排除風險、把「我已經處理好」當成不必討論。
* 成長是逐漸學會詢問、接受別人的混亂、讓重要之人承擔自己的風險，理解照顧不是取得管理權。

## 3.5 嫉妒與佔有

* 奏會嫉妒。嫉妒不只來自戀愛排他，也來自害怕自己的功能被取代、害怕雪奈在別人面前更放鬆、害怕「家」擴大後自己失去位置。
* 她的錯誤表現可能包括：過度挑剔其他人的照顧方式、不說需求只增加家務與守備、以安全理由阻止別人靠近、在任務中競爭「誰更有用」。
* 成熟後，她能直接說：「我嫉妒。」「我今天想和雪奈姐單獨吃飯。」「我知道妳不會離開，但我現在還是很不安。」

## 3.6 對暴力的態度

* 奏不享受慘叫、混亂與血腥；她喜歡的是控制成立、對手失去選項、線網閉合、一切安靜下來。
* 她可以冷酷處決，也能精準活捉。對她而言，理想暗殺像房間裡少了一個人：沒有多餘聲音，沒有人知道自己何時失去自由。
* 她的危險不是殘虐，而是對「必要」的判斷可能過於冷硬。

# 4. 形成背景

## 4.1 地下教育造成的價值觀

* 奏在正常學校生活以前，便已接受高度功能導向的訓練。
* 她很早學會：安靜能活下來；完成任務才有資源；不疼、不哭、不求助會被視為優秀；能替別人處理麻煩，才不會被丟下。
* 因此她將自我價值建立在：有用、準確、不添麻煩、永遠先看見他人的需要。
* 她不是天生只想服侍別人；這是生存策略被內化成愛的語言。

## 4.2 與雪奈的關係形成

* 相識的具體任務與時間可由前傳時間線進一步鎖定。
* 本檔固定以下結果：
  * 雪奈是第一批能看穿奏「沒事」其實代表受傷的人。
  * 雪奈不只在奏有用時留下她。
  * 雪奈允許奏照顧，也會強行讓奏休息、吃飯或接受治療。
  * 奏第一次體驗到：

    > 自己可以因為是奏，而不是因為完成得很好，被某個人期待回家。

* 這使雪奈成為她最深的依戀對象，也使奏容易把所有人生意義重新集中到雪奈身上。
* 成長不是削弱這段感情，而是讓它不再承擔奏全部的自我價值。

## 4.3 痛覺屏蔽

* 奏不是完全沒有痛覺。
* 她具有異常高痛閾、長期訓練形成的痛覺解離，與面對可控傷害時自動降低主觀痛感的能力。
* 常規割傷、挫傷、淺層燙傷與部分骨折，可能只被她感知為壓力、熱、動作阻礙或遠處的鈍感。
* 重大結構風險會突破抑制：內臟傷、大血管、缺氧、關節完全失穩、神經損傷。
* 所謂「安全閥」不是超自然開關，而是身體危險訊號、功能檢查與重要之人的依附反應共同將疼痛推回意識——其中一級特別連結著「會讓雪奈姐困擾的傷勢」。

## 4.4 痛覺屏蔽的代價

* 容易低估出血、骨裂、肌腱損傷、燙傷與疲勞。
* 她建立固定自我檢查：關節活動、肌力、皮膚溫度、血跡、呼吸。
* 戰後必須接受他人檢查。
* 她最討厭的不是疼痛，而是被發現自己需要照顧。

* 同學常認為她是酷、害羞、很可靠、可能有點天然。

* 不擅長閒聊；無法理解同學為何為偶像、流行話題或小考排名焦慮；對「大家一起浪費時間」缺乏耐性。

* 高中生活的重要課題是學會：不是所有問題都需要暗殺者答案。

# 6. 能力與裝備

## 6.1 戰力定位

* 銜尾蛇S級殺手；對一般武裝人員與普通殺手具有壓倒性控制力。
* 在室內、複雜通道與可預先佈線的環境尤其危險。
* 對頂級S級殺手能形成真正高水準對抗；優勢是空間控制、耐心與陷阱。
* 不以正面火力與雪奈、潔西卡競爭——不是因為弱，而是她的勝利條件是讓對手根本無法建立正面交戰。

## 6.2 戰鬥哲學

> **控制先於殺戮。** 三階段流程：**削弱 → 束縛 → 處決**。

基本流程：

1. 讀取空間。
2. 建立錨點與退路。
3. 限制感知、武器與移動。
4. 迫使目標進入預設區域。
5. 束縛、失能、活捉或處決。
6. 回收線體與痕跡。

她不追求最大爆炸、最多傷亡或華麗正面對決；她追求最少變數、最低聲量、對手最晚意識到失敗、自己與重要之人不被接觸。

# 7. 主武器「影縛」

## 7.1 系統結構

「影縛」是一套多線匣智慧線體系統，不是一根同時擁有所有性能的萬能線。

### 承重索

* 材質較粗，具高韌性與動態負荷能力。
* 用於攀附、擺盪、升降、撤離、固定門窗與大型物件。
* 不能作高效率切割；承重取決於錨點與角度。

### 束縛索

* 柔韌、高摩擦、具有限形變能力，用於手腕、腳踝、武器、關節與活捉。
* 可施加精密張力，不以直接切斷人體為主要用途。
* 面對高熱、銳利邊緣與高速旋轉目標較脆弱。

### 切割絲

* 極細、高張力，用於無聲陷阱、人體與軟甲、電纜管線、輕中型裝甲接縫。
* 需要穩定錨點、足夠張力與正確入射角；不能承受擺盪或拖曳，不能像光劍一樣隨手切開所有高強度合金。

## 7.2 控制介面

* 指尖導電指環釋放脈衝，配微型觸覺回饋；腰背線匣、腕部張力監測。
* 貓耳耳機提供回音、錨點狀態、細微振動與斷線警報。
* 常態可精密控制四股主要線與兩股低複雜度輔助線；超過此數量仍可部署固定陷阱，但不能全部即時微操。
* 線體控制需要注意力；同時近身纏鬥、受傷或感官干擾會降低精度。

## 7.3 有效距離

* 即時精密操控有效半徑約20公尺。
* 預設固定陷阱可延伸更遠，但需要事前佈置。
* 超過有效距離後，張力回饋下降、延遲增加、更容易被環境物干擾。
* 開放場地、無錨點地形與強風會顯著削弱影縛優勢。

## 7.4 「不可接觸」領域

* 奏最理想的戰場是讓敵人從未碰到她。應用形式：立體死亡蛛網（室內陷阱）、線控機動（擺盪、升降、橫移）、束縛與繳械、環境陷阱（門框、轉角、通風口）。
* 這不是絕對屏障；成立條件是足夠錨點、時間或空間佈線、感測未被完全壓制、敵人的速度與範圍火力未直接克制線體。
* 面對大範圍爆炸、火焰、無錨點開闊地、高速旋轉體、強電磁／高熱切割與全向感測，她必須改變打法。

# 8. 柔術與近身技術

## 8.1 定位

* 柔術、絞技、關節控制與失衡專精；影縛先限制，奏再進入對方無法完整發力的角度。
* 她不是力量型近戰者，對更重的敵人依靠槓桿、支點、重心與頸部、肩、肘、膝、踝。
* 她能快速制服、讓目標失去意識、破壞關節、以線體輔助維持控制。

## 8.2 潔癖與接觸

* 她不喜歡無意義身體接觸；接受近身，是因為已先將對手變成可控物體。
* 面對失控纏鬥與多人壓制時，優先脫離而非證明柔術技術。

## 8.3 力量限制

* 絕對力量低於多數S級正面型戰士。
* 若被重量遠高於自己的敵人完整固定骨盆、肩帶、頭頸與雙手，她會陷入危機。
* 影縛、飛針與環境工具是脫身核心；「以柔克剛」的邊界在於槓桿與支點，而不是無視質量。

# 9. 輔助裝備

## 9.1 淬毒飛針

* 中距投擲，可裝神經麻痺、肌肉鬆弛、鎮靜或標記物。
* 她熟悉劑量與作用時間，但不是全知毒理學家；防護服、義體、未知生理與高耐受目標會降低效果。

## 9.2 煙霧與閃光

* 遮蔽佈線、切斷視線、製造撤離窗口，與影縛陷阱配合。
* 奏重視聲音與空氣流動，不會在密閉空間大量使用。

## 9.3 料理與日常工具

* 刀具技術極高，但她尊重用途與衛生：料理刀就是料理刀，任務裝備不進入廚房。
* 緊急情況能使用任何物件自衛，但日常不必永遠軍事化。

## 9.4 槍械弱點

* 奏能安全拆裝、上膛與判斷槍械狀態。
* 真正問題是爆音、後座脈衝與扳機動作會破壞她賴以控制細線的手指節奏與注意力。
* 實戰槍法顯著低於S級標準；壓力下可能手抖、過度修正或脫靶。她因此徹底放棄熱兵器，把槍械拒絕當作主武器。
* 她可以經訓練改善基本防衛，但「槍械不是她的語言」是固定特質。

# 10. 戰術思維

## 10.1 棋手視角

奏習慣先問：

* 出口在哪裡？
* 誰會先動？
* 誰以為自己有選擇？
* 哪一個物體可成為錨點？
* 哪條路看似安全，實際最容易收網？
* 哪一個人必須活著？
* 哪一個人只要失去手、視線或平衡便不再是威脅？

她的戰術不是預知，需要觀察、佈置、地形、敵人行爲與可控變數。

## 10.2 即興能力

* 遭遇戰與移動中也能利用門把、欄杆、管線、家具、車體與敵人武器快速建立線網。
* 遭遇戰時精度仍高，但網路規模與控制程度不如預設陣地。

## 10.3 與雪奈的戰術互補

### 雪奈

* 改寫整個戰場的節奏、吸引視線、打開重型系統、在瞬間跨越多個領域。

### 奏

* 封鎖逃路、固定目標、保護側翼、讓雪奈的高風險入射路徑不被干擾、捕捉雪奈選擇不殺的人。

### 獨立性

* 奏能獨立完成高價值潛入、活捉、保護、多目標暗殺與大型區域人員封鎖。
* 奏的戰術可由自己的偵察、錨點與空間控制獨立成立，雪奈只是可能的協同對象之一。

# 11. 弱點與風險

| 弱點 | 具體表現 |
|---|---|
| 絕對力量 | 低於S級正面型戰士，不適合長時間角力 |
| 開放場地 | 缺乏錨點與遮蔽物時，影縛效率下降 |
| 範圍破壞 | 火焰、爆炸與大面積結構摧毀可清除線網 |
| 注意力負荷 | 同時操控多線、近戰與保護他人會增加錯誤 |
| 線匣有限 | 承重、束縛與切割線不能無限補充 |
| 痛覺解離 | 容易低估自身傷勢 |
| 槍械 | 實戰槍法為明確弱項 |
| 教育斷層 | 抽象課業、社會常識與同齡文化不足 |
| 雪奈安危 | 會提高風險接受度，甚至放棄原本精密控制 |
| 被需要焦慮 | 容易過度照顧、隱瞞需求與排斥他人進入家庭 |
| 求助困難 | 傾向自行解決，直到已經無法隱藏 |

# 12. 人際關係

## 12.1 朔夜雪奈

> 奏愛的不是銀色幽靈的傳說，而是會賴床、會把衣服亂丟、會在她受傷時真正生氣，也會在沒有任務時仍叫她一起吃飯的朔夜雪奈。

* 稱呼：「雪奈姐」。
* **姐控完全體**：對外是無口冷血的殺人機器；對雪奈姐是病嬌賢妻，狂信徒式地守護「雪奈姐能安心吃布丁的世界」。
* 關係成分：家人、姐妹式依附、青春期愛戀、戰術夥伴、共同生活。
* 奏喜歡照顧雪奈，也容易透過照顧確認自己不可替代。
* 雪奈需要接受奏的愛，也拒絕奏越過界線的控制；主動照顧奏，讓奏知道自己不是因家務與戰力才被留下。
* 奏需要直接說出嫉妒與需求、允許雪奈與其他人建立關係、接受雪奈畢業、任務與自由並不等於拋棄她。
* 身體接觸多以擁抱、靠肩、牽手、同沙發休息與傷後照顧等日常親密呈現。

## 12.2 月見里琉璃

* 稱呼：「琉璃前輩」或熟悉後直接稱「琉璃」。
* 初期因共同守護雪奈而合作；奏曾試圖教琉璃「人類生活」，容易不自覺站在指導者位置。
* 琉璃能指出奏把照顧變成控制、奏的生理數據與「沒事」不一致。
* 奏能教琉璃味道、家務中的模糊判斷、不必追求完美對稱的生活。
* 兩人應逐步建立不以雪奈為唯一中心的關係：共同料理、裝備維修、互相檢查傷勢、在對方過度功能化時說停。

## 12.3 藤堂潔西卡

* 稱呼可能保留「大猩猩」或「吵死人的雷鳥」——死對頭、情敵、不打不相識。
* 表面互嗆、競爭、對彼此的戰法不耐；深層互補：潔西卡迫使奏公開說出需求，奏迫使潔西卡控制輸出與耐心規劃。
* 兩人的共同點：不願被保護、用能力證明價值、面對雪奈時容易失去原本判斷。
* 關係會從情敵式互嗆發展成可靠友誼：她們能在雪奈不在場時一起執行任務、互相限制過載、討論各自與家庭的衝突。

## 12.4 園谷小夜

* 奏尊重小夜對聲音與節奏的控制；奏偏好安靜，小夜則認為過度靜默可能是情緒逃避。
* 戰術互補：奏建立真正無聲路徑，小夜製造假的聲音世界。
* 人格張力：小夜不喜歡奏把所有感受壓成家務，奏不喜歡小夜用藝術語言繞開具體責任。
* 私下可形成深夜料理與調音、安靜共處、對雪奈疲勞狀態的不同觀察。
* 奏應逐步理解：沉默不一定是安全，聲音也可以是家。

## 12.5 星野夏音

* 奏初期視夏音為高噪音、高風險、過度接近雪奈的狂熱粉絲；夏音則將奏視為佔據最佳位置的黑貓。
* 奏會研究夏音的戰鬥紀錄，批評其彈藥管理、維修習慣與演出優先。
* 夏音會挑戰奏：為何愛一定要表現成料理與警戒？為何不直接說想被看見？
* 兩人若建立關係，應從「爭奪雪奈注意」走向：奏協助夏音義體維護與飲食；夏音替奏製作個人化但不以雪奈為主題的裝備飾件；彼此承認對方的存在不會抹掉自己。

## 12.6 高一同學

* 奏需要少量普通同學關係，她們不知道完整地下身份，只會知道：奏很會做飯、運動能力異常、有一位非常黏的高三學姐。
* 普通同學能提供小考、班級活動、青春期困惑等不需要殺手能力便能幫上忙的場景。
* 普通同學關係可以維持在校園與日常層面，形成真正獨立於地下世界的生活圈。

# 13. 長期成長線

## 13.1 第一階段：有用才安全

* 為雪奈安排所有生活；對其他人進入家庭高度警戒；不說嫉妒；受傷仍繼續工作；在校園保持最低社交。

## 13.2 第二階段：照顧開始失控

* 因畢業、多人關係或任務分工感到位置不穩；增加家務與警戒；與潔西卡、琉璃或其他人衝突。
* 被迫承認：她不是只在保護雪奈，她也在控制自己不被取代的恐懼。

## 13.3 第三階段：學會被照顧

* 接受別人替她做飯、換藥或完成任務；在不嚴重時主動說「我累了」；讓同學進入自己的生活。
* 在雪奈不在場時仍參加活動；允許安全屋出現屬於自己的喜好、朋友、植物、食譜與不以待命為目的的物品。

## 13.4 第四階段：以選擇而非功能留下

* 照顧仍然是她的愛語，但不再是唯一語言；能表達想要、拒絕、嫉妒、害怕與不同意。
* 能接受雪奈畢業、工作、與其他人親密，而不把變化等同遺棄。
* 對自己的未來形成選項：繼續作為銜尾蛇殺手、轉向情報與活捉、深入料理、建立自己的安全屋與生活。
* 成長不是離開雪奈，而是終於能以完整的奏站在雪奈身邊。

# 16. 寫作要點

* 奏的沉默有多種狀態：專注、害羞、嫉妒、恐懼、憤怒與真正放鬆都會呈現不同細節。
* 關心透過具體記憶與行動表達——記住每個人的口味、行程與傷勢。
* 她能獨立主導高難度任務；S級戰力應透過潛入、活捉、暗殺與區域封鎖完整呈現。
* 寫影縛先寫空間與錨點，再寫線網結果；承重、束縛、切割三類線各有材質與張力限制。
* 她會嫉妒、越界、拒絕雪奈並做出自己的判斷；這些選擇會帶來具體的人際後果與修正。
* 她的場景可以由獨處、普通同學、料理偏好、校園事件或自己的任務主動驅動。
* 成長讓殺手、學生、料理者、家人與少女等身份共同構成完整的奏。

# 17. 角色核心色彩

* **她是控制者。** 讓戰場進入秩序是她的專長；親密關係則迫使她學習協商、信任與放手。
* **她真的喜歡照顧人。** 照顧是她真實的愛語，而她要鬆開的是把有用當成被留下資格的舊習慣。
* **她很強。** 她具備獨立完成潛入、活捉、暗殺與區域封鎖的S級能力。
* **十五歲的生活同樣重要。** 同學、考試、失敗、任性、被照顧與純粹浪費時間都會塑造她。
* **她的沉默有很多含義。** 專注、害羞、嫉妒、恐懼、憤怒與真正放鬆各有不同質地。
* **黑貓與普通生活可以並存。** 殺手、學生、料理者、家人與少女共同構成奏本人。
* **最終命題**：

> 奏最初想成為雪奈永遠無法替換的影子；真正成熟後，她不再需要證明自己不可替代——因為她知道家人不是依靠功能排序，而她也終於擁有即使離開任何人的視線，仍然會繼續生長的人生。
