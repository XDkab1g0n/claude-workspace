## 一、故事總綱

### 1.1 一句話故事

近百名獵人用整座城市的感測網追殺銀色幽靈，卻直到天亮才明白：她從來沒有逃跑，只是在讓他們逐層暴露指揮鏈，親自替她帶路回到獵人的巢穴。

### 1.2 真正的戲劇核心

本篇不是「雪奈被逼到絕境後爆發逆轉」。

她從察覺包圍的第一刻便在反獵。前半夜之所以仍像逃亡，是因為她需要：

1. 確認敵人從何處取得不該掌握的行動情報。
2. 讓七支互不信任的隊伍持續回報，藉延遲、權限與補給動線畫出完整指揮鏈。
3. 在敵人仍相信自己是獵人時，保留更多可觀察的節點與活口。
4. 找到總部、證據、贊助者名單與撤離備援，而不是只打散眼前追兵。

凌晨兩點的「方向倒轉」，改變的是她**公開給敵人看的意圖**，不是她突然認真，也不是她臨時改變目標。

### 1.3 故事的情緒曲線

| 段落 | 敵方感受 | 雪奈呈現 |
|---|---|---|
| 前段 | 興奮、貪婪、相信數量與程序 | 幾乎不可見，只留下能被追逐的剪影 |
| 中前段 | 困惑、互疑、開始害怕單獨行動 | 戲謔地餵假規律，控制他們的視線與回報 |
| 停車場 | 第一次理解她正面戰力的重量 | 不再只靠欺敵，以雙腿把包圍本身拆掉 |
| 甜品店 | 明明看得見，卻沒有人敢先開槍 | 公開休息、補糖、讓恐懼自行完成包圍 |
| 反追獵 | 地圖上的目標開始朝自己靠近 | 公布投降規則，有選擇地終止抵抗者 |
| 攻城 | 首領失去部下、門與敘事權 | 不再藏光，正面讓巢穴承認她的力量 |
| 清算 | 獵王活著看自己成為展品 | 不承認他有決鬥資格，以行政般的輕蔑完成羞辱 |

### 1.4 雪奈的內在弧線

本篇不需要硬塞成長課題。雪奈已是完成度極高的十八歲強者；她的角色弧線是**表達模式的逐步揭露**：

- 起初只是下班途中被打擾的慵懶與不耐。
- 發現情報外洩後產生冷靜興趣，決定把整張網拔出來。
- 享受敵人自以為學會她的過程，但始終保留回程、糖分與裝備餘量。
- 得知獵王拿部下當耗材並封死撤退後，玩心收窄，殺戮與放行規則變得明確。
- 最後不是因憤怒虐殺首領，而是讓他失去最珍視的權威、聲望與故事控制權。

導航員是整夜唯一與雪奈共享全貌的對話者。兩人可以拌嘴，但導航員不只是數據播報器；她會對雪奈的表演欲、能耗與「順路拿甜點」提出自己的判斷。

## 二、固定舞台與敵方配置

### 2.1 城市路線

本篇城市不指定既有正史地名，以「沿海巨型都市的西側商業區—舊工業帶—廢棄港區」構成一條可理解的東西軸。

1. **高架鐵道與商業區屋頂**：第一次被目視確認；監視器密集，適合製造公開假路線。
2. **舊商辦與立體巷道**：無人機、狙擊與通訊中繼戰；垂直空間豐富。
3. **立體停車場**：敵方第一次建立真正有效的重裝包圍。
4. **二十四小時自助甜品店**：玻璃外牆、無店員、凌晨沒有一般顧客；中場休息與獵人心理崩潰點。
5. **舊工業帶與貨運支線**：反追獵、截斷車輛、投降與獵群解體。
6. **廢棄港區分揀站**：貨櫃、吊車、貨運軌道與外圍火力網。
7. **地下指揮堡壘**：多層裝甲門、透明戰術地板、直播控制室與原本為雪奈準備的展示囚籠。

場景轉換必須維持方向感。前半夜所有公開痕跡看似持續向西；雪奈實際藉中繼與補給回報逐步確認位於東南港區的總部。凌晨兩點後，敵方戰術圖上的紫色目標才第一次筆直向東南移動。

### 2.2 獵殺聯盟

「獵殺聯盟」是獵王為一夜行動臨時拼出的隊伍，不是既有組織。

- 七支傭兵小隊，共約六十人。
- 三組狙擊／觀測單位。
- 無人機、感測與通訊技術人員約十餘人。
- 兩支裝甲攔截組與數名重裝戰士。
- 受高額懸賞吸引的獨立賞金殺手。
- 港區總部守衛、砲塔操作員與獵王親衛。

總數接近百人，但任何時刻都分布於不同街區、樓層、載具與後勤節點；不得把他們寫成站在同一處排隊讓雪奈清場。

敵方初始方案應顯得合理：

- 多層感測交叉確認，禁止依單一畫面追擊。
- 小隊彼此保持射界隔離，禁止單人脫隊。
- 指揮節點分層轉送，首領位置不直接向外圍暴露。
- 重裝組只在目標被壓入預設地形後出動。
- 有類比瞄具、紙本挑戰碼與離線備援，不能被一次駭入全部解決。

他們的失敗不是因為全員愚蠢，而是因為獎金制度、彼此不信任、獵王的直播表演欲，以及雪奈同時在物理、資訊與心理三層比他們更快。

### 2.3 四個功能性敵方角色

#### 獵王

- 地下掮客與行動發起人；真名不必揭露。
- 擅長整合傭兵、情報、保險與贊助，並非只會叫囂的草包。
- 相信足夠的感測器、標準流程與可犧牲人數能把任何傳說還原成統計問題。
- 以加密直播向贊助者展示獵殺，預先準備透明囚籠、戰利品台與慶功甜點。
- 致命缺陷不是單純自大，而是把部下視為替自己取得資料的消耗性感測器。

#### 灰犬

- 一支老練傭兵隊的隊長，作為前半夜主要敵方限知視角。
- 嚴格遵守程序，不輕視雪奈；因此他的恐懼最有可信度。
- 最早察覺雪奈放回來的每個人都「帶著她想讓指揮部收到的資訊」。
- 最終選擇放下武器並活到天亮，成為傳說的主要見證人。

#### 鴉眼

- 無人機與感測網主管，多數時間位於港區指揮層。
- 起初將所有異常解釋為資料問題，後來發現資料沒有壞：是雪奈在決定系統看見什麼。
- 最後被迫坐在控制席上維持直播，親眼看獵王失去敘事權。

#### 鐵棺

- 獵王最後的親衛重裝，數百公斤級人形動力甲。
- 忠誠建立在利益與共同罪責，不因獵群崩潰而投降；曾奉命向撤退者開火。
- 是終盤「昇月」的承受者。雪奈將他與動力甲整體拔離地面，撞穿透明戰術地板與指揮桌。
- 此次乾淨命中為致命終止，不以反覆爬起削弱重量感。

## 三、敘事規格

### 3.1 視角配置

- **序章至第三幕**：以灰犬、鴉眼與極少量獵王限知為主。雪奈只以畫面、聲音、痕跡與行動結果出現；不得直接揭露她已找到總部方向。
- **第四幕**：停車場交戰仍先由敵方看見，電梯補給時才第一次完整切入雪奈限知。
- **第五幕以後**：雪奈限知成為主體，必要時在場景分隔後切回獵王／鴉眼。不得在同一段落內自由穿越多人內心。
- **終幕**：回到灰犬視角，讓傳說由倖存者完成。

預設第三人稱限知。視角切換只發生於明確分場、空行或章幕交界。

### 3.2 前半夜的資訊禁區

在凌晨兩點以前，不得直接告訴讀者：

- 雪奈真正前進方向是港區。
- 她保留活口是為了測量回報鏈。
- 同時出現的幽靈中哪一個是真身。
- 她已經能進攻，只是在等節點全部現身。

可以給公平線索：她總是先動通訊、刻意讓特定人活著、每次「被迫改道」後都有一個敵方節點暴露、導航延遲不斷縮短。真相應在方向倒轉後由讀者自行拼起，再由少量對話確認，不用長篇解說。

### 3.3 戰鬥語法

- 雪奈的雙腿、踢技與夢魘舞者承擔主要決定性命中與場景破壞。
- 白夜／極夜負責打開射線、癱瘓感測、逼位與建立踢擊入口。
- 夜影負責切斷關節、纜線、武器與裝甲接縫，不用來無條件斬開所有重甲。
- 極光負責錨定、牽引、改軸與把牆面、車體、鋼梁變成新的蹬地面。
- 每一次主要命中都要改變位置、隊形、裝甲幾何、掩體或戰術選項；不得擊飛後原地重置。
- 本篇**不使用完整「彗星」**。一整夜的能源、散熱、關節與回程餘量比多展示一個大招更重要。
- 「昇月」只在第八幕完整使用一次，嚴守主設定的固定動力鏈，不提前以簡化版消耗高潮。

### 3.4 殺傷規則

雪奈不是非殺不可，也不需要被改寫成不殺主義者。

- 前三幕優先拆掉感測、指揮與專業節點；依威脅與後續用途，在死亡、失能與刻意放回之間選擇。
- 停車場後，敵人已使用明確致命火力，死亡開始變得公開且不可否認。
- 凌晨兩點，雪奈向所有頻道公布一次清楚規則：放下武器、退出火線者能活；繼續追擊、替獵王封路或向投降者開火者，會被直接終止。
- 她必須遵守自己公布的規則。這不是仁慈表演，而是她對戰場選項的控制。
- 後半段可以明確呈現她一路殺入老巢，但打擊感主要靠速度、結構破壞、聲音與結果，不靠反覆堆疊殘肢。

### 3.5 身體與裝備連續性

- 雪奈全程沒有受到有效命中，也沒有明顯外傷。
- 威脅感來自敵方確實能封鎖射線、迫使她改道、消耗時間／能源，及一次錯誤可能造成的真實後果；不得靠安排她硬吃重擊證明敵人有用。
- 幽靈斗篷只是白色 Oversized 長袖外套，不得泛指水手服、百褶裙、安全短褲、過膝襪或夢魘舞者。
- 可讓斗篷在停車場被抓住一片磁吸側襬；雪奈主動解離該片脫身。這是裝備操作，不是衣物被扯破的性感化橋段。
- 疲勞主要表現為呼吸加深、足踝與膝髖負荷、核心發熱、夢魘舞者鞋底過熱與氣壓下降、動作逐漸去除非必要裝飾。
- 她不把「還站著」當作可無限繼續的理由；每次高輸出後都更新回程餘量。

## 五、逐幕寫作腳本

## 序章｜一百對一

### 幕功能

先讓讀者相信這是一場規模完整、準備充分的獵殺；同時埋下所有終局羞辱會使用的物件。

### 場景 A：開播前五分鐘

**地點**：港區地下指揮堡壘。  
**視角**：鴉眼。  

1. 鴉眼逐一確認七隊上線、三組狙擊、無人機航線、車輛封鎖與分層轉送。
2. 牆上主畫面只有一個銀紫色目標框，標記為 `SILVER GHOST / QUARRY`；狀態仍是灰色的「未確認」。
3. 透明戰術地板下方可看見下一層守衛與親衛重裝「鐵棺」。這塊地板日後會被鐵棺撞穿。
4. 房間一側擺著透明展示囚籠。獵王向贊助者承諾，天亮前會把銀色幽靈本人與裝備放進去。
5. 冷藏櫃送進昂貴的慶功布丁。獵王不准任何人先碰，說那是「獵人分戰利品時才開的」。
6. 鴉眼對行動仍有技術信心，但不喜歡直播。直播迫使每支隊伍爭搶可見戰果，也讓獵王不願在情勢不明時撤退。

### 場景 B：目標亮起

1. 20:40，高架鐵道監視器捕捉到月光銀高雙馬尾、白色長外套與一瞬紫色鞋底光軌。
2. 多個感測器完成交叉確認。灰色標記轉紅，賞金池解鎖。
3. 獵王下令：「開始狩獵。」
4. 最後一個畫面不是雪奈逃跑，而是她隔著雨與鏡頭回頭看了一眼；鏡頭隨即黑掉。

**幕末鉤子**：鴉眼以為她發現了攝影機。讀者日後才知道，她是在確認鏡頭屬於哪一條回報鏈。

## 第一幕｜可見的獵物

### 幕功能

建立「追殺正在成功」的表象，同時讓第一個不合理之處出現：每次雪奈被看見，敵人的網就少一隻眼睛。

### 場景 A：向西逃亡

**地點**：高架鐵道、商業區屋頂。  
**視角**：灰犬。  

1. 雪奈剛完成一件與本篇主線無關的短委託，離場路線只在很小的必要範圍內存在；獵網卻精準壓上她尚未公開的回程方向。她因此判定，眼前不是一般臨時伏擊，而是一條值得反向追查的情報鏈。
2. 灰犬從地面追蹤雪奈橫越高架的身影。她故意讓白色斗篷、雙馬尾與紫色殘光在三個鏡頭裡連續成立。
3. 她的速度快，但仍給出一條可被人類理解的西行路線；這正是陷阱。
4. 灰犬遵守交叉確認，不讓隊員單獨追上屋頂。他不是笨蛋，因而能發現：三次目擊的時間差都「剛好足以成立」，像有人刻意替他們保留希望。
5. 雪奈在一面巨型廣告牆後消失。追兵趕到時只找到一枚吸附在牆背的紫色發聲器，播放遠去的鞋底脈衝。

### 場景 B：封鎖圈中央的空白

1. 另一支小隊封死百貨維修樓梯，以熱像、毫米波與實體門鎖逐層推進。
2. 燈光短暫熄滅，不超過兩秒。再亮起時，最前方兩人的武器已被夜影切斷關鍵部件，最後方的通訊員倒在轉角。
3. 雪奈沒有留在狹窄走廊與整隊人纏鬥。她利用樓梯中央井、極光與外牆維修窗垂直穿過封鎖。
4. 隊伍中唯一仍能完整通訊的人被留在原地，肩上貼著一枚小小的紫色幽靈貼紙。
5. 他向指揮部回報「目標繼續向西」。這正是雪奈需要他帶走的答案。

### 場景 C：第一個失聯節點

1. 鴉眼發現西側封鎖仍在收緊，負責東側資料轉送的中繼站卻無聲離線。
2. 因為中繼站遠離公開逃亡路線，他先判定為設備故障。
3. 灰犬盯著地圖，第一次問：「如果她不是在逃呢？」
4. 獵王用賞金加碼壓下疑問，命令所有隊伍繼續西移。

**雪奈狀態**：無傷；只使用低功率移動、一次短促極光與少量聲學道具。尚未補糖。  
**幕末鉤子**：城市西側的紅色封鎖圈變厚，東側卻出現一條沒有人注意的黑色資料缺口。

## 第二幕｜城裡有三個幽靈

### 幕功能

摧毀敵人對「確認目標」的信心，優先拔掉眼睛、耳朵與能維持共同現實的人。

### 場景 A：三次同時確認

**視角**：鴉眼。  

1. 三個相距數個街區的單位，在十二秒內同時完成雙重確認：白色斗篷、銀色雙馬尾、霓虹紫光軌、匹配步態。
2. 三個畫面都不是廉價全像。其一是穿著簡化輪廓的誘餌無人機；其一是被鏡面與延遲影像重組的殘光；其一才是雪奈本人。
3. 鴉眼刪除兩個假目標時，真身已借他重新分配無人機的瞬間切入狙擊組樓下。

### 場景 B：先拔眼睛

**視角**：灰犬所在頻道，只聽見結果。  

1. 狙擊手透過類比鏡仍保有射擊能力，證明敵方備援不是擺設。
2. 雪奈不從正面攀樓。她先讓無人機群在玻璃幕牆投下錯誤影子，再從清潔軌道上方倒懸切入。
3. 白夜只開一槍，打碎觀測器與牆面固定；夜影切斷槍機和通訊線；最後一記短促側踢把狙擊手連同折疊掩體送離射位。
4. 命中要讓窗框變形、腳架翻飛、整個射擊空間失去功能。不要把它寫成抽象「擊倒」。
5. 一名觀測員活著被放回。他無法回答雪奈從哪裡來，只記得她在耳邊問：「下一個中繼在哪裡？」

### 場景 C：借來的眼睛

1. 雪奈劫持一輛無人機控制車，不需要長時間坐下駭入。她以預先取得的中繼憑證、現場接觸與導航員並行處理，在短時間內奪走部分影像路由權。
2. 她不讓全部無人機反過來開火；那會太早暴露控制深度。她只讓它們在錯誤時間看向錯誤轉角。
3. 灰犬的小隊數次抵達剛剛離開的空間，逐漸發現自己不是慢，而是每次都被允許看見上一拍。
4. 雪奈取出第一顆糖錠，在一架墜落無人機的陰影裡咬碎。這是極短、沒有脆弱化的身體管理畫面。

### 場景 D：會傳話的人

1. 被放回的觀測員、樓梯通訊員與一名失去武器的賞金殺手，對「幽靈在哪裡」給出互相矛盾但都真誠的答案。
2. 灰犬意識到雪奈選擇了誰能回來，也就選擇了指揮部會相信什麼。
3. 他要求整隊改用近距口令。獵王准許，並認為這代表獵網正在逼她消耗更多手段。

**雪奈狀態**：無傷；腦力與電子戰消耗上升，以一顆糖錠維持。夢魘舞者溫度仍低。  
**幕末鉤子**：鴉眼在系統日誌裡發現，三次假目標都曾短暫經過不同層級的合法權限。

## 第三幕｜教會他們錯誤答案

### 幕功能

讓敵人以為自己終於歸納出雪奈的習慣，再由第四次重複把整套模型折斷。這一幕必須同時證明敵人會學、雪奈知道他們如何學。

### 場景 A：可以被歸納的幽靈

1. 雪奈連續三次在受壓時採取近似節奏：高處現身、向左下折返、以紫色聲源掩護穿越封鎖。
2. 第一次像偶然，第二次像偏好，第三次足以讓鴉眼建立預測模型。
3. 每次路線細節不同，不能像遊戲重播；相同的是敵方能提取的決策骨架。
4. 灰犬不完全相信，卻承認如果不利用規律，他們永遠追不上。

### 場景 B：第四次

1. 敵方把兩支小隊埋伏在「左下折返」的預計出口，並以紙本挑戰碼確認身份。
2. 雪奈沒有靠一個駭入指令讓所有人互射。她先用實體發聲器逼第一隊提早轉槍，再讓一架被劫持的無人機帶著正確挑戰碼進入第二隊視線，最後以極夜脈衝熄掉唯一能看清全場的照明。
3. 兩隊在半秒內互相指向。第一發誤射不是雪奈憑空控制，而是某名緊張隊員真實扣下扳機。
4. 雪奈從兩條火線之間穿過，只對仍能恢復指揮的隊長與重武器手出手。槍火打開姿態，兩次踢擊分別把人送進柱面與掩體，使交叉火力再也無法重新建立。
5. 她留下一個沒有爆炸的紫色盒子。拆彈手花了數分鐘確認，打開後只有一張紙：`學得很快。`

### 場景 C：敵方改用人工

1. 獵王下令關閉共享標記、改用短距離類比通訊、封閉隊形與人工回報。這確實使雪奈的遠端欺敵效率下降。
2. 灰犬第一次感到包圍真正變緊：隊伍減速，卻不再被假標記隨意拉走。
3. 雪奈不硬穿。她改為跟隨補給車與傷員後送的實體動線，從「人必須回去哪裡」重建指揮層級。
4. 這裡可讓讀者看見她的頂尖並非只靠裝備：系統關閉後，她仍從換班時間、車輛油量、醫療標記與誰有權改口令判斷網路形狀。

### 場景 D：重裝出動

1. 午夜，鴉眼報告目標活動範圍正在被壓縮。這個結論在局部資料上完全正確。
2. 獵王啟用裝甲車與重裝攔截組，把所有「可用出口」導向一座立體停車場。
3. 灰犬看著目標最後一次依預測向西折返，卻發現她在進入停車場前，朝東南港區的方向看了一眼。

**雪奈狀態**：無傷；使用少量糖錠與水。資訊目標已接近完成，但正文仍不明說。  
**幕末鉤子**：停車場的防火門在她身後同時落下。這一次，敵人真的建立出一個值得正面回答的包圍。

## 第四幕｜第一次正面回答

### 幕功能

讓敵人第一次完整看見銀色幽靈的正面破壞力，證明前半夜的消失不是因為她不能打，而是因為那不是最有效率的答案。

### 場景 A：包圍成立

**地點**：九層立體停車場。  
**視角**：灰犬。  

1. 敵方以兩輛裝甲車封住上下坡道，重裝兵控制中央車道，狙擊手占據相鄰樓層，干擾器壓低外部通訊。
2. 車輛與混凝土柱形成彼此支援的射界，敵人不追進視線死角，而是逼雪奈穿過預定火線。
3. 一次定向電磁脈衝使樞紐與導航員短暫降級。雪奈沒有失去能力，只失去部分並行資訊；她立刻把戰鬥縮成肉眼可裁決的距離。
4. 第一輪射擊沒有命中，卻切斷她原本的上行路徑，迫使她在一個節拍內改軸。威脅應由此成立。

### 場景 B：他們終於看懂的戰鬥

以下動作必須形成連續因果，不拆成招式清單：

1. 極夜先以短點射打掉前方重裝的膝部感測與裝甲車右側視鏡，製造半秒盲區。
2. 雪奈沿車側低切，低掃直接摧毀已失去修正的承重膝軸；數百公斤重裝不是跪一下再站起，而是整個左側坍向車體。
3. 她以極光錨住上方管線，把重裝倒下的質量轉成擺盪拉力，從裝甲車射界上方翻過。
4. 白夜精準打斷第二具重裝的穩定器。雪奈落在車頂，短距蹬踏與轉髖後踹同時成立，把那具重裝踢進裝甲車側門；車身明顯橫移，另一側輪胎離地。
5. 第一輛車被撞得偏轉，堵住下坡道。第二輛車為避撞急轉，正好進入雪奈預先留下的濕滑與錨線區，撞上混凝土護欄並封死上坡道。
6. 一名重裝抓住幽靈斗篷的磁吸側片。雪奈不是靠布料硬扯，也不是被抓住身體；她主動解離側片，讓對方拉走一塊空白輪廓，再借其後仰動作切進胸前死角。
7. 夜影切斷外骨骼胸側傳動，膝撞使上身離軸，最後一記迴旋踢把人與破損裝甲一同送入車頭。引擎蓋、擋風結構與重裝外殼同時變形。
8. 灰犬只看見一道白色衣襬落在兩輛車之間；背景裡，坡道、隊形與重裝支援已全部失去原本形狀。

雪奈不使用完整彗星，也不在此使用昇月。高潮來自常規踢技本身就足以把人、重裝、車體與空間一起重排。

### 場景 C：四十七秒

**視角切入雪奈。**

1. 雪奈進入一部仍可運作的貨梯，按下樓層。門合上後，戰場聲被切成沉悶震動。
2. 導航員報告鞋底熱量、剩餘高壓氣體、腿部負荷與血糖下降趨勢。不要報遊戲式百分比，可用「仍在安全區／下一輪高輸出前必須補充」等專業判斷。
3. 雪奈在四十七秒下降時間內喝掉一份能量凝膠與水，短暫開啟夢魘舞者散熱，轉動足踝並重新固定腿環。
4. 導航員質問她為什麼選擇一間仍亮著燈的店作下一站。
5. 雪奈看著地圖上最後一條回報線，懶洋洋回答：「因為那裡有布丁。」

**雪奈狀態**：零有效命中；高輸出後呼吸與核心溫度上升，鞋底偏熱、氣壓下降。凝膠與水完成第一次主要補給。  
**幕末鉤子**：貨梯門打開，她沒有繼續躲進暗處，而是穿過街道，推開一間整面玻璃都亮著的甜品店。

## 第五幕｜五分鐘休息

### 幕功能

全篇心理逆轉點。雪奈沒有用更強的武器，而是坐下；敵人第一次在擁有清楚射線時發現，真正被包圍的是自己。

### 場景 A：玻璃盒裡的幽靈

1. 店內為自助營業，凌晨無店員與一般顧客，避免把平民當作天然護盾。
2. 雪奈正常付款，買一份焦糖布丁與一瓶運動飲料；可再帶一份未開封布丁作後備，不把補給寫成狂吃。
3. 她坐在玻璃旁最顯眼的位置，摘下一側紫電耳罩，讓夢魘舞者散熱，緩慢活動足踝。
4. 追兵沿廣場、屋頂、車後與對街窗戶形成包圍。獵王把她坐下的畫面推上所有直播頻道，命令就地射殺。

### 場景 B：沒有人開槍

1. 多數聯網瞄具被雪奈污染敵我標記，使用者無法確信自己瞄到的是她還是隊友反射。
2. 一名使用純類比鏡的狙擊手仍有乾淨射線，不能用「全部被駭」帶過。
3. 他將準星移到雪奈額前。雪奈沒有抬槍，只在舀起第一匙布丁前，隔著數十公尺與玻璃準確看向他的藏身窗。
4. 狙擊手明白兩件事：她早已知道他的位置；第一發若不能命中，自己與整組人都會失去掩護。他的手指停住。
5. 其他隊伍也在等別人先開火、先暴露、先承擔她的反擊。獵王一再下令，頻道裡卻只剩呼吸與互相確認。
6. 雪奈對著店內攝影機說：「休息五分鐘。你們也可以休息。」

### 場景 C：倒數

1. 五分鐘不可純粹跳過。用敵方瞄具、雪奈的進食節奏、鞋底冷卻聲、廣場雨水與獵王愈來愈失控的命令累積壓力。
2. 雪奈吃完布丁、補充電解質，檢查雙槍與極光，確認足踝無傷，只是負荷累積。
3. 一支外圍小隊在倒數結束前主動撤退。獵王威脅取消報酬並追究，他們仍關閉頻道。
4. 五分鐘到，雪奈把空杯放回托盤，重新戴好紫電。
5. 她看向攝影機，語氣仍甜而平靜：「休息結束。接下來換我追。」
6. 敵方戰術圖上的紫色目標不再向西，而是第一次筆直轉向東南港區。

**雪奈狀態**：主補給完成；無傷，足踝活動正常，鞋底熱量下降。體力未恢復成開場滿值，但重新取得一段高輸出窗口。  
**幕末鉤子**：鴉眼看著目標直指總部，終於明白前半夜所有「逃跑路線」都在替她測量同一個終點。

---

## 第六幕｜換我追

### 幕功能

把前半夜的都市恐怖片改成明確反追殺。雪奈開始縮短距離，敵方則第一次需要思考怎樣從自己的獵場逃出去。

### 場景 A：目標正在靠近

**視角**：鴉眼。  

1. 主畫面上的 `QUARRY` 標記沿最短路徑接近港區；外圍小隊回報不再是「目標離開」，而是「她在我們後面」。
2. 獵王仍試圖把它解釋為垂死突圍，要求所有車輛回收兵力、在港區外建立第二道線。
3. 鴉眼從資料看出雪奈正在優先處理車輛、燃料、通訊與有權改變路線的人。她追的不是最近的肉體，而是整支聯盟的撤退能力。

### 場景 B：先拆退路

1. 雪奈利用貨運支線、道岔與已被劫持的施工載具，把兩條主要車道切成彼此不相通的區塊。
2. 她不製造不可控的大爆炸。白夜打掉輪軸／控制單元，極光改變車頭方向，主要踢擊使領頭車橫移或翻覆，讓後車無法維持隊形。
3. 一輛撤退車試圖撞開封鎖。雪奈借車頭前衝踏上引擎蓋，以短促轉身後踹把方向軸與前輪結構一同打歪；車身擦過她原本的位置，撞入空置貨架。
4. 命中後她不留在原地欣賞，直接利用車體反彈進入下一條追擊線。

### 場景 C：投降條款

1. 雪奈接管各隊頻道，只說一次：

   > 「槍放地上，退出火線，別替他關門。做到的人，我不追。」

2. 一支已失去隊長的小隊決定測試。成員放下武器、關閉瞄具，沿照明區離開。
3. 雪奈從高處越過他們，沒有回頭也沒有補槍。她的規則因此成為可信選項。
4. 另一名賞金殺手假裝放下武器後抬槍。雪奈在他完成瞄準前以白夜打開護具，再以一腳將他送進車門，直接終止。規則同樣因此具有重量。

### 場景 D：追的是指揮鏈

1. 雪奈逐一截取資料攜行員、臨時財務節點、懸賞託管金鑰與贊助者清單。
2. 她不需要在正文解釋所有駭客細節；以她每取得一個實體節點，港區某一層門禁、砲塔或帳戶便失去控制來表現。
3. 導航員確認情報來源並非單一洩密者，而是一條販售、驗證、加價再轉手的鏈。本篇只處理這條鏈，不擅自指向既有角色或組織內鬼。
4. 雪奈在進入港區前吃下第二份葡萄糖凝膠，喝少量水，保留最後攻城所需的高壓與腿部餘量。

**雪奈狀態**：無傷；持續移動使腿部與核心疲勞累積，動作比前半夜更短。完成第二次補糖，仍保留一輪明確高輸出。  
**幕末鉤子**：獵王命令港區關閉所有入口——包括仍在外面的自己人。

## 第七幕｜獵群咬向獵王

### 幕功能

讓敵軍戰意不是被一句威嚇憑空摧毀，而是被首領親手切斷。雪奈只需把他原本藏在分層頻道裡的命令交還給每個人。

### 場景 A：關門

**視角**：灰犬。  

1. 灰犬帶著殘餘隊員抵達港區外門，門禁拒絕他們的有效識別。
2. 內部守衛收到命令：任何試圖強行入內的外圍人員視為遭幽靈控制，可直接射殺。
3. 獵王在公開頻道承諾「正在安排撤離」，在內線卻要求砲塔用外圍人員測量雪奈的接近角度。
4. 灰犬終於完整理解：他們從來不是獵人，只是散布在城市裡、會流血的感測器。

### 場景 B：原音重播

1. 所有頻道同時傳出獵王剛才的內線原音，包括封門、射殺撤退者、延後報酬與犧牲外圍隊伍的指令。
2. 雪奈不替內容加上長篇評論，只說：「他剛才替我省了很多話。」
3. 獵王指控錄音偽造。鴉眼知道簽章、時間戳與權限全是真的，卻沒有立刻替他說話。
4. 灰犬命令隊員卸下彈匣、放低槍口；內部守衛的槍仍對著他們。

### 場景 C：獵群解體

1. 一名死忠守衛向已投降的外圍人員開火。雪奈從側上方切入，以槍火打掉掩體與瞄具，再以兩次沉重踢擊讓守衛和固定槍位一起失去功能。
2. 灰犬看見她從自己身旁經過。她沒有停下，只提醒：「你答應過不替他關門。」
3. 灰犬讓開服務通道，並指出內部守衛剛才使用的輪替入口。雪奈本來已定位總部；這項情報只確認入口狀態與剩餘人數，不把勝利建立在偶然告密上。
4. 其他隊伍陸續投降、逃離或彼此斷開。少數死忠退向總部，沿途替雪奈確認最後幾層防線。

**雪奈狀態**：無傷；步幅開始主動縮短以節省足踝負荷。紫色光效仍維持低亮度。  
**幕末鉤子**：她站在港區外緣，關閉所有欺敵影像，反而把夢魘舞者與樞紐的霓虹紫全部點亮。

## 第八幕｜正門

### 幕功能

完成「幽靈攻城」。前半夜她用不可見支配戰場；現在她故意讓所有鏡頭看清，一個三十八公斤的身體如何正面拆掉獵王賴以安全的整座堡壘。

### 場景 A：不再消失

1. 雪奈沿貨櫃頂、吊車鋼梁與貨運軌道前進，保留清楚紫色光軌。
2. 她不是失去潛行能力，而是要讓仍在直播的贊助者、倖存者與獵王看見：總部的位置一旦被找到，剩下的門與火力沒有敘事作用。
3. 外圍砲塔集中射擊。雪奈使用貨櫃高度差、極光承重錨點與每一次砲塔轉向的慣性穿越射界；不能只寫成「快到子彈打不到」。

### 場景 B：拆掉門的成立條件

1. 極夜先癱瘓砲塔感測；極光纏住炮管，在轉台急修正時把扭矩拉向錯誤方向。
2. 雪奈踏上砲塔基座，完整側踢落在已經偏軸的固定環。轉台與底座產生可見錯位，炮身砸向另一座火力點。
3. 第一層裝甲門不靠夜影直接切穿。夜影只切斷外露致動與鎖定線，白夜打掉內部保險；雪奈沿門縫正面踹入，使整塊失去均勻受力的門板向內折彎。
4. 門後隊伍本來依門體建立射界，門板變形後反而成為撞入他們陣形的巨大掩體。
5. 雪奈順著門板滑下，在它撞地以前已從側面進入第二層。

### 場景 C：最後一層人

1. 剩餘精銳採用離線武器、實體陷阱與狹窄交叉射界，不再依賴已被污染的網路。
2. 雪奈此時也不再大量使用花哨誘餌；她用更短的預讀、槍口偏轉、踢擊破軸與牆面折返，逐個讓防線失去支援。
3. 每個主要敵人只需一個清楚結果：被踢出射界、撞毀同伴掩體、承重腿被破壞後遭下一腳終止、武器與身體被送進不同方向。
4. 她會殺死仍持續開火與守住通往獵王道路的人，也會越過明確棄械者。不要停下來逐一宣判。
5. 導航員提示夢魘舞者熱量與氣壓已接近本夜預定上限。雪奈回答：「夠一腳。」

### 場景 D：昇月

1. 鐵棺從指揮層下方降下，以數百公斤動力甲封死垂直通道。他的重量、錨定與火力是真正的最後障礙。
2. 雪奈先以白夜打掉一側視覺，極夜逼迫他抬起前臂，夜影切斷腹側一條輔助錨索；這些動作只為建立下側軸線。
3. 鐵棺向前重踏，試圖以整個質量封死她的切入。雪奈反而進入他近身下側，瞬間壓低重心。
4. **嚴守昇月固定鏈條**：支撐腿、臀髖與深層核心同步爆發；她沿貼近鐵棺軸線的高速後空翻向後上方翻入；身體接近倒懸、髖部穿過目標軸線的瞬間，攻擊腿沿近乎垂直軌跡猛烈上甩。
5. 夢魘舞者釋放本夜最後一段高壓。雪奈的腿、鐵棺前衝的動量、被切斷後失衡的錨定與向上的軸線疊在同一拍。
6. 鐵棺與整具動力甲被從地面秩序裡拔起，撞穿指揮層的透明戰術地板，再砸碎獵王面前的戰術桌。
7. 後空翻與上踢是同一條連續動力鏈，不得寫成普通上踢或翻完再踢。
8. 雪奈沿剩餘角動量翻上破口，輕巧落在滿地透明碎片與重裝殘骸之間。背景結構晚一拍才完成崩裂。
9. 鐵棺於此乾淨終止，不再爬起進入第二階段。

**雪奈狀態**：零有效命中；腿部、足踝、膝髖與深層核心已明顯疲勞，夢魘舞者鞋底過熱、高壓接近耗盡。她仍能穩定站立與自行回程，但不再安排第二輪同級輸出。  
**幕末鉤子**：獵王隔著飛散的透明碎片看見她，卻發現她根本沒有看他——她先走向仍在運作的主控台。

## 第九幕｜獵物

### 幕功能

徹底羞辱獵王，但不把高潮降格為長時間虐打。雪奈奪走的是他最重視的四件事：命令權、敘事權、獎金與「獵人」身份。

### 場景 A：這不是決鬥

1. 獵王試圖從殘破高台取出私人武器，宣稱要用最後決鬥替直播收尾。
2. 雪奈甚至不讓姿勢成立。白夜打掉武器，極夜封住退路；她仍在查看主控台與證據鏈。
3. 獵王質問她是否不敢正面接受挑戰。
4. 雪奈可用一句短答終止他的自我神話：

   > 「你不是對手。你是地址。」

5. 他撲向控制台時，雪奈一腳踢斷華麗指揮椅的支座。她控制力量，不直接重創他；椅面翻轉，把他送進自己預先準備的透明展示囚籠。

### 場景 B：用他的權限拆掉他的獵場

1. 雪奈以獵王仍有效的活體認證開啟管理權，導航員同步完成證據封存。
2. 她依序執行：
   - 解鎖外圍撤離門與醫療通道。
   - 取消懸賞並凍結尚未支付的託管資金。
   - 將獵王整夜犧牲部下、封鎖撤退與說謊的原音推上所有仍連線頻道。
   - 把主追蹤系統中的目標名稱由 `SILVER GHOST` 改成獵王代號，狀態改為 `QUARRY`。
3. 這些動作必須各自產生可見後果：外門打開、倖存者收到撤離指示、贊助者斷線或撤回支持、牆上唯一紅框移到囚籠裡。

### 場景 C：親口宣布

1. 雪奈把直播麥克風轉向囚籠，要求獵王說出三件事：狩獵失敗、懸賞取消、外圍人員可以撤離。
2. 他一開始拒絕。她不以酷刑逼供，只讓他看見贊助者、部下、帳戶與門禁已全部脫離控制；沉默只會讓她播放更多原音。
3. 獵王最終親口念出。這不是被洗腦，而是他在仍想活命、仍想保留最後一點談判可能時作出的屈服。
4. 鴉眼留在控制席，確認直播沒有被剪接。獵王因此無法日後把失敗改寫成英勇戰死或遭人背叛。

### 場景 D：慶功甜點

1. 雪奈打開冷藏櫃，拿出獵王為自己準備的慶功布丁，坐到殘破戰術桌邊補完最後一份糖分。
2. 導航員可以冷淡提醒：「那是證物。」雪奈回答：「拍完照就是點心。」讓兩人的拌嘴把她從傳說拉回本人。
3. 她走到囚籠前，在獵王額頭貼上一枚紫色幽靈貼紙。夢魘舞者在透明牆外投出簡單的 `WEAK`。
4. 雪奈最後留下：

   > 「你們追了我一整晚，只是替我畫出一條回家的路。謝謝帶路。」

5. 她不回頭確認表情，直接從獵王原本只打算讓勝利者使用的正門離開。

**雪奈狀態**：無傷；高輸出已結束，疲勞、飢餓與睡意開始明顯。她仍能自己走、仍有最低自衛與撤離能力，不被任何人抱走或以昏倒收束。  
**幕末鉤子**：主畫面上只剩囚籠裡的紅框，以及一個不斷閃爍的單字：`QUARRY`。

## 終幕｜銀色幽靈沒有逃過追殺

### 幕功能

把勝利從戰果提升成傳說。傳說不是旁白替她吹捧，而是倖存者在親眼看過整夜因果後，無法再用原本的語言描述她。

### 場景 A：正門外

**視角**：灰犬。  

1. 黎明開始染亮港區。倖存者在道路兩側替雪奈讓開，不是受命列隊，也不是崇拜，而是沒有人願意再站在她選定的路徑上。
2. 她的高雙馬尾有些鬆，白色斗篷缺了一片主動解離的側襬，夢魘舞者不再拖出長光軌。這些是整夜使用痕跡，不是重傷。
3. 她一手拿著未喝完的運動飲料或第二份布丁，步伐仍穩，只比開場慢。導航員在耳邊催她回家補眠。
4. 灰犬回頭看港區，再想起每一名被放回的人、每一道向西的假路線與每一次被迫回報。
5. 他終於明白，沒有任何一刻能被稱為「逆轉」；從第一個鏡頭亮起開始，他們就在替她工作。

### 最後文字

> 後來地下世界說，銀色幽靈沒有逃過那場追殺。  
> 她只是讓近百名獵人追了她一整夜，親自帶她找到了獵人的家。

全文到此結束，不在結尾追加道德總結、戰績統計或角色集體稱讚。

## 十、完成後的審稿順序

1. 先檢查章幕是否完整，尤其第二幕沒有在續寫中遺失。
2. 檢查前半夜是否過早揭露雪奈的全盤計畫。
3. 檢查每次主要命中是否造成不可忽略的空間或戰術變化。
4. 檢查敵方是否有能力與適應，而非只靠愚蠢維持雪奈的強。
5. 逐幕核對資源表，確保糖分、飲水、熱量、氣壓與足踝負荷連續。
6. 檢查雪奈是否零有效命中；若正文臨時加入擦傷或裝備碰撞，必須確認不會推翻「無明顯傷勢」與後續動作。
7. 檢查死亡、投降與放行是否遵守第六幕公布的規則。
8. 檢查獵王的羞辱是情節回收與權力剝奪，不是拖長的肉體虐待。
9. 最後才視需要載入 `/Skills/Charles/independent-creative-review.md` 做獨立審稿；審稿意見必須回到本腳本與現行主設定逐項核對，不能自行改寫正史。
