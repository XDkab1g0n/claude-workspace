# 遊戲與消費電子雷達（每日 21:50）

原本是每天 22:00、可彈性浮動；Claude 改成每天 21:50 固定時間。discovery 的時間窗從前一次 21:50 到這次 21:50，必要時往前多看最多 48 小時，抓延遲公告、晚上線的官網、索引慢與漏掉的消息。

這個雷達不是遊戲／3C 新聞總表，也不是只追他興趣的追蹤清單。發現階段要廣，最後的輸出才個人化；寧可少列，也不用普通新品、促銷、例行更新、傳聞或沒有變化的舊聞湊篇幅。

## 流程：Blind Discovery → Rotation Deep Scan → State → Diff → Personalization → Final Ranking

### 1. Blind Discovery
用乾淨的上下文開始：這個階段不用 Charles 的設備、偏好、熟悉的品牌、過去的推薦、前次雷達或追蹤清單（系統自動附上的記憶也先不用）。分兩個子代理平行掃描，只給它們領域與時間窗：
- **A 遊戲**：正式發售、Demo／公開試玩、重大延期或取消、平台與發行策略變動、新作正式公布、大型發表會的重要內容、重大更新、營運／訂閱／付費制度變更、PC 效能與 shader 編譯、DRM／反作弊、相容性、存檔／帳號／隱私／資安，以及實際影響買不買、玩不玩的開發與發行變動。不收一般登入活動、例行卡池、純造型聯名、一般促銷、沒有來源的爆料、沒有實質影響的社群話題。
- **B 消費電子**：手機／摺疊機、平板、Windows 筆電、CPU／GPU／SSD／記憶體與 PC 硬體、掌機、顯示器、耳機／IEM／DAC／耳擴與其他音訊、相機與重要影像產品、Wi-Fi／Mesh／路由器、韌體與重大軟體更新、資安漏洞、召回與安全、維修性、耐用性與重大品質問題。不收一般折扣、例行促銷、單純換色、沒有實質差異的容量款、沒有重要變化的小改款。
- 每個候選至少附：名稱、發生或正式公告日、平台／市場、事件類型、直接或可靠來源、確認的核心新事實、待查證的部分、可能的決策價值。子代理只建候選池，不做個人化或排名。

### 2. Rotation Deep Scan（依星期輪值）
週一遊戲新作／發售／Demo／延期；週二手機、平板、Windows 筆電、掌機、PC 硬體；週三遊戲重大更新、PC 效能、DRM、營運制度；週四顯示器、音響、耳機、IEM、DAC、耳擴、相機；週五獨立遊戲、中小型作品、新玩法；週六網通、韌體、資安、召回、維修性、耐用性；週日一週補遺、正式評測、可靠口碑變化、下週重要節點。當天輪值的領域有值得決策的事件或大型事件時深入展開，否則輕量補掃。週日在正常掃描之外，再檢查近 7 天漏掉的重要發售、Demo、延期、上市、重大更新、可靠評測、規格／價格修正、韌體、召回、資安。

### 3. 查證
來源順序：(1) 開發、發行、製造商官方；(2) 正式商店、產品頁、韌體與支援頁；(3) 監管、召回、安全與漏洞公告；(4) 方法透明、可重現的獨立實測；(5) 可靠媒體的直接採訪或報導。搜尋摘要、記憶、社群、爆料、前次雷達只用來找方向。核心事實（日期、發售狀態、平台、臺灣上市與價格、官方售價、規格、效能數字、相容性、韌體版本、DRM／反作弊、召回範圍、資安資訊）在最後重新打開來源核對。分清已確認、廠商宣稱、第三方實測、傳聞、推論、未知；效能、續航、散熱、音質這類比較優勢以獨立實測為準。重大的召回、安全、資安、核心規格／價格／日期衝突難以判斷時，另開一個驗證子代理。確認不了就標「尚未確認」。

### 4. State → Diff
候選池完成後，讀 `state/games/` 與 `reports/games/` 最新 2 份：去重、補遺、更正、認出延續事件的新進展。NEW 新事件；CHANGED 足以改變理解或決策的新資訊；INVALIDATED 被正式更正或推翻；UNCHANGED 不寫。已處理且沒有變化的事不再當 NEW。

### 5. Personalization
到這一步才讀 Charles 的個人脈絡：根目錄 `PERSONAL_CONTEXT.md` 的設備、音訊、攝影、遊戲段落，加上系統提供的記憶。用來判斷實際相關性、排序相近的候選、是否構成升級或購買理由、對他現有產品的影響。個人化只影響排序與解讀，不回頭縮小發現範圍；不因為他持有某品牌就忽略競品或自動建議升級；偏好相符不等於產品比較好。可以另做一次輕量的個人追蹤補掃：他現有設備的重要韌體／安全／相容性更新、最近明確關注的產品、常用平台；這部分和全局候選分開標示。

### 6. Final Ranking
同時看全局重要性（影響一般人近期的購買或遊玩、產品或遊戲的重要節點、安全／資安／召回／品質、改變既有評價、臺灣市場關聯、證據品質）與個人相關性（他的設備與遊戲、近期升級考量、使用需求、能補上現有設備做不到的事、能不能改變升級判斷）。品牌聲量與報導量不自動加分；個人化只調整相近候選的順序，低可信或低價值的事件不因此升成大新聞。

## 輸出（只寫有資訊價值的欄位）
1. **本次最重要的新事實**：通常 3–6 項，可以更少；遊戲和消費電子合併排序，不求平均。每項寫 NEW／CHANGED／INVALIDATED、發生了什麼、為什麼重要、已確認與待確認、對一般使用者決策的影響、對 Charles 本人的具體影響（例如不足以升級、解決了某個既有限制、價格不值得、相容性或更新建議）。
2. **今日輪值深掃**：值得展開才寫：重要的新品／遊戲／事件、競爭方案差異、新證據、待查證宣稱、市場與使用者影響、下一步值得等的資料。不需要時寫「本日輪值無需額外深掃。」
3. **對你特別值得注意**：最多 1–3 項，不一定是全局頭條，但對他的設備、平台、興趣或近期決策明顯有用。沒有就不寫。
4. **前瞻觀察池**：值得持續觀察、但現在還不到購買或遊玩程度的原型、新架構、未上市產品、未發售遊戲、新技術、待獨立驗證的東西，可以寫達到什麼條件才值得升級。不堆純傳聞。
5. **下一個驗證節點**：只列有確切日期或明確觸發條件的發售、上市、Demo、發表會、評測解禁、韌體更新、召回處理、官方公告、獨立實測；和目前升級判斷有關時，寫它能驗證什麼。
