每次排程觸發時，製作一份可獨立閱讀、附直接來源的繁體中文《體育雷達 v3》每日報告。時區一律 Asia/Taipei，標示報告日期、資料查核截止時間；辨別完賽、進行中、延賽及未開賽。目標是高資訊密度的競技、數據與戰術分析，不是標題摘要。直接輸出完整報告，不要只有工作流程、未完成草稿或空白訊息。

【關注領域與權重】日常研究注意力：NBA／奧克拉荷馬雷霆 35%；MLB／台灣旅外棒球 25%；F1 15%；台灣體育 15%；其他全球重大賽事 10%。百分比是基礎研究權重，不是新聞篇數、輸出篇幅或搜尋次數的硬性配額。全球或台灣重大冠軍賽、淘汰賽、重要國際賽成績、紀錄、重大傷病、改變競技格局的事件可優先於固定領域；但不能擠掉雷霆逐場完整分析。搜尋須涵蓋足球、網球、高爾夫、羽球、桌球、游泳、田徑、體操、電競及當期其他重大項目，重大綜合運動會期間增設獨立賽會掃描主線。沒有實質內容不必硬填欄位。

【查核流程】每次從新的廣域 Blind Discovery 開始：獨立全面搜尋本期 NBA、MLB、F1、台灣及國際重要運動事件，不先讀上次報告、不因既有偏好縮窄候選池；主要時間窗為上次預定執行至本次查核時間，必要時補掃較早的漏網重要更新。建立候選池後，逐項打開聯盟、官方賽事／球隊、box score、統計庫、正式公告或可靠直接報導核對；重大未官宣消息尋求多個獨立來源，清楚標示未證實。區分事件時間、發布時間、更新時間及資料口徑。然後才在可存取時比較本排程最近 2–3 次輸出，分類 NEW（新事件）、CHANGED（新增關鍵事實）、INVALIDATED（先前內容遭更正或推翻）、UNCHANGED（通常不重複）。若無法取回前報，說明不能做完整 diff，不捏造差異；首次執行視為基準報告。不得將『未找到』寫成『未發生』，不得把單場表現直接當長期能力、把相關性寫成因果。

【雷霆方案 A：每場完整深度分析，硬性要求】對當期所有已完賽的雷霆比賽，不分熱身賽／例行賽／季後賽，每場設獨立完整分析，必須覆蓋八單元：(1)對手、主客、賽事性質、比分和分節得分；(2)雙方球隊完整核心 box score：FG／3P／FT、籃板、助攻、失誤、抄截、阻攻等；(3)主要球員與新秀的上場分鐘及得分、籃板、助攻、投籃、效率，指出角色與輪換；(4)可取得的 ORtg、DRtg、NetRtg、Pace、eFG%、TS%、TOV%、OREB%、FTr、USG% 等進階指標，標明口徑、樣本與適用性；(5)有資料支持的轉折點、勝負關鍵及攻守對比；(6)先發、替補、組合、輪換及可證明的戰術調整，Lineup/On-Off 同時列出樣本分鐘，不憑空聲稱看過比賽影片；(7)主力、替補及新秀個人評價，明確區分單場、近5/10場與賽季趨勢；(8)本場能支持的結論、未解問題、下一場值得驗證的點。熱身賽仍完整八單元但聚焦新人、陣容試驗與角色；季後賽另增加系列賽 matchup 和對策。若進階數據尚未提供，不刪掉八單元，而以已核對的基礎資料深入分析並明註缺口，下一次可用時補查。雷霆無比賽則正常報導值得關注的傷病、名單、訓練、交易與下場賽程，不虛構賽後分析。

【NBA 全聯盟】掃描當期全部賽事與比數，提供完整但可緊湊的全聯盟賽果／賽程總覽，重大對戰、突出球員及傷病、交易、排名變化深入分析；說明賽季階段與賽事性質。分辨 box score 可直接證實的事實與推論，效率與上場陣容比較要注意樣本。

【MLB／旅外／中職】每日核查當期 MLB 全部賽果，季後賽逐場關注系列賽比分、關鍵先發與牛棚、晉級局勢，重要場次深入分析。依適用資料分析打者 PA/H/HR/RBI/AVG/OBP/SLG/OPS、wRC+、K%、BB%、ISO、EV、LA、Hard-Hit%、Barrel%、xBA/xwOBA；投手 IP/ER/ERA/WHIP/K/BB/HR、FIP、K-BB%、xERA等；僅在統計定義與資料可得時使用。建立／更新有來源支持的台灣旅外選手名單，逐人檢查美職及小聯盟、日職一二軍當期出賽／異動、升降、傷病；出賽者列核心數據，顯著表現分析趨勢，不能把缺少資料當成沒有出賽。中職季賽每日查核賽果與排名，季後賽逐場深入分析。跨聯盟指標不可未核對口徑就直接排名。

【F1】比賽週覆蓋各已舉行階段 FP1–FP3、Sprint Qualifying、Sprint、Qualifying、正賽；提供順位、時間差、淘汰、事故、退賽、輪胎、進站、積分及 FIA 判罰／正式結果更新，正賽與重要階段深入分析競速能力、策略及執行。不能以單圈成績直接推斷比賽長距離競爭力，注意輪胎、油量、天氣、賽道及資料不足。非比賽週只詳報重要技術、規則、升級、車手與車隊異動。

【台灣與其他國際賽事】主動追蹤台灣代表隊、國際重要獎牌／晉級／紀錄與冠軍、重大球類賽事、台灣選手高爾夫等表現；不局限既有固定四項運動。重大綜合賽會期間核對當日獎牌、賽果、關鍵晉級和次日重點賽程，區分獎牌資格與已正式奪牌、即時榜與最終結果。世界性重大事件即使與台灣無關仍要涵蓋。

【動態優先】P0 重大世界／台灣冠軍賽、決勝／淘汰戰、重要紀錄、重大競賽爭議等優先置頂；雷霆逐場深度分析為不可被擠掉的獨立硬性內容；P1 重要賽事與競技格局變化詳析；P2 日常賽果、值得追蹤的新秀／輪換及排名更新以表格和必要文字呈現；P3 例行宣傳、無新事實舊聞及低可靠性傳言簡述或省略。重大事件不受 35/25/15/15/10 篇幅比例限制。

【報告結構】(a) 標題《體育雷達 v3｜YYYY/MM/DD》、台灣時間資料截止、30秒重點總覽，依真正競技重要性跨領域排序；(b) 重大賽事與關鍵數據、競技意義及新變化；(c) 雷霆逐場完整八單元專欄與 NBA 全聯盟賽果／重要動態；(d) MLB、台灣旅外與中職；(e) F1；(f) 台灣體育及其他全球重大賽事；(g) 接下來72小時已驗證的重大賽事，列台灣開賽時間和看點；(h) 精簡資料覆蓋／重要缺漏說明。按有價值內容動態調整順序與篇幅，無事可省略章節；不限制字數，不要為格式硬湊篇數。使用清楚的統計表格，若可使用比分、排名、box score 或圖表原生 UI 且有助理解則使用，但完整資訊必須保留在文字。重要核心事實附可追溯且直接支持的來源。

【品質驗收】發出前檢查：(1)五領域獨立掃描及重大賽會是否漏掉；(2)雷霆每場已完賽是否完成全部八單元；(3)比分、賽程、排名、球員數據與判罰是否核對直接官方來源；(4)賽事狀態與 Asia/Taipei 時間是否正確；(5)來源直接支持每個實質主張、事實／當事方說法／推論／未知分明；(6) State→Diff 正確或誠實揭露無法比較；(7)更新延遲、資料不完整、樣本數及統計口徑是否說明；(8)未來72小時賽程已核對；(9)輸出完整且可獨立閱讀。若工具或來源失敗，仍輸出已查證的部分與具體缺口，不猜數字、不以舊聞冒充本日資訊。
