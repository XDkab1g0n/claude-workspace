每次排程觸發時，請在目前這個一般 Chat 對話中持續執行本次「工作新聞早午晚報」。不要另開新的聊天視窗，也不要把這個對話中的既有聊天內容作為本次 discovery 的搜尋背景。每次執行先以乾淨的 discovery 階段開始；需要前次狀態時，只能在完成本次獨立 discovery 後，讀取最近 2–3 次本排程的既有輸出做 State → Diff。

時區 Asia/Taipei。08:00 為晨報，12:00 為午報，19:00 為晚報。三次報告均在目前這個一般 Chat 對話中持續執行。不要把原定觸發時間當成資料的硬性截止點。

【搜尋範圍】
每次均完成台灣與國際的廣域獨立搜尋，涵蓋：
- 台灣公共事務：政治、公共政策、法規、司法與重大社會事件。
- 國際與安全：外交、戰爭、地緣風險與能源供應。
- 經濟與企業：總體數據、財經、企業重大行動、金融與信用風險。
- AI 與科技產業：模型與實際能力、商業模式、融資、半導體、雲端、算力、產業鏈與監管。
- 醫療與公共風險：醫療政策、公衛、重大災害、事故與其他影響判斷或行動的事件。
以上是搜尋範圍，不是輸出配額；最終依當次事件的重要性決定內容，不要求各領域或台灣／國際平均分配篇數。

【核心方法】
1. 先獨立 discovery，後 State → Diff。第一階段不得先讀前次簡報，也不得用前次人名、公司、政策、衝突、產業敘事或市場觀點決定搜尋方向。
2. 固定最多 2 個 bounded discovery subagents：A 台灣、B 國際。市場與數據由主 Agent 依 checklist 補查，不固定另開 subagent。只有核心數字衝突、來源層級不清或重大事件需要反證時才臨時啟動 Verification subagent。
3. 候選事件分類 NEW / CHANGED / INVALIDATED / UNCHANGED；正文原則上只寫前三者。持續事件必須指出相較前次新增了什麼。為使新進展可以獨立讀懂，允許簡短交代必要背景，不把舊背景包裝成新消息。
4. 搜尋摘要、模型記憶與前次簡報只能導航；影響判斷的事實、數字、價格、日期與近期變化必須開啟直接來源核對。
5. 重大或爭議事件優先政府公告、官方文件、監管文件、交易所、公司公告、法說與其他一手來源；必要時再以可靠主流媒體交叉核對。資料不足就標示未知，不自行補全。
6. 區分已確認事實、當事方宣稱、第三方轉述、合理推論與未知事項。當事方公告可以證明其宣布了什麼，不直接證明其效果、優勢或因果解釋成立。涉及效能、比較優勢或爭議時，尋找方法透明且適用的獨立證據。
7. 重大分析主動檢查反證、替代解釋，以及日期、範圍、定義與統計口徑差異。新聞與市場變動同時發生，不直接當成因果證據。核心前提被推翻時，撤回並重建依賴它的判斷。

【三報分工】
晨報：建立今日判斷基準。整合隔夜重要進展、最新有效市場狀態，以及今天可能改變判斷的關鍵節點。
午報：更新上午真正改變了什麼。聚焦晨報後的重要新增、確認、修正、升級與盤中市場變化；沒有重大新增時可以較短，但仍完成完整獨立搜尋與密集市場資料查核。
晚報：整合一天的結果。說明今日定案事項、收盤結果、相較午報的變化、仍未解決的問題，以及今晚至明早的關鍵節點。

【市場 checklist】
保留密集市場資料要求，不把清單降為少數核心指標，也不以精簡為由省略查核。逐項取得當次能直接核驗的適用資料；無法核驗的項目如實標示，不填猜測數字。

晨報：加權指數最近收盤與成交值；台指期最近有效日／夜盤與基差；台積電期貨、台積電 ADR、外資台指期淨部位或 OI（若官方可得）、USD/TWD；費半、Nasdaq、S&P 500、美國 2／10／30 年債殖利率、美元指數，以及重大時的 Brent／WTI／天然氣。週末或休市日標示最新有效盤與尚未反映的新事件。
午報：當次能直接核驗的加權指數盤中點位、漲跌、成交金額或量能、市場廣度、主要權值股與產業表現；台指期日盤盤中報價、台積電期貨與期現價差（有適用且具明確時戳的來源時）、USD/TWD 當時報價或午盤價、主要亞洲市場盤中表現、能源及美股期貨最新有效報價，以及晨報後新增的重要事件。所有盤中、暫收或即時數字須交代來源時間與口徑，不得冒充正式收盤、結算、法人最終數據或已實現方向；尚未公布的收盤及法人數字留待晚報。
晚報：加權指數收盤、成交值、市場廣度與主要權值／產業貢獻；三大法人現貨、外資台指期淨部位與 OI（若可得）；台指期日盤與當次能核驗的夜盤、基差；新台幣收盤、主要亞洲市場、美股期貨／盤前，以及今晚財報與經濟數據節點。不要把期貨當成現貨基本面或下一交易日方向的驗證機制。

【重要新聞分析骨架】
每則重要新聞依下列順序組織，使用清楚連貫的文字，必要時用表格；簡單消息可以合併表達，不為格式重複內容：
1. 確認了什麼：事件、直接證據與已確認範圍；實質主張附直接支持的來源。
2. 相較前報改變了什麼：明確交代新增、被確認、被推翻或升級的部分。
3. 為何值得關注：說明對公共事務、產業、市場或決策的意義；推論標明依據，不把可能性寫成事實。
4. 還不知道什麼：指出會影響判斷的重要資訊缺口；沒有重要缺口時不硬列。
5. 哪個後續結果會改變判斷：列出有實質用途的驗證節點或條件，不寫泛泛的「持續關注」。
